# 부대 키우기 개인정보 운영 매뉴얼

2026-10-09 · 4단계 · 운영자 김동환 · 문의 dong760630@naver.com

정식 출시 후 혼자 운영하는 상황을 기준으로 한다. 공개 방침을 대체하지 않는 내부 업무 안내다. 앱은 0.72.3, 방침은 개정 6 그대로다. 실제 고객 정보·메일·첨부파일·접수대장은 공개 Git에 올리지 않는다. 이 문서에는 절차와 빈 예문만 둔다.

## 평소에는 이렇게 한다

- 하루 한 번 문의함·스팸함을 확인하는 것을 내부 운영 목표로 삼는다. 법정기한을 놓치지 않게 접수일을 확인한다. 자동 알림이 설정된 것은 아니다.
- 일반 문의는 답변 후 더 보관할 필요가 없어지면 지체 없이 삭제한다. 주간 점검은 누락 확인용이며 삭제를 주말까지 미루는 기준이 아니다.
- 매주 남은 문의·첨부 다운로드·휴지통·불필요한 사본을 확인한다. 접근 가능한 받은편지함, 보낸편지함의 인용 내용, 다운로드 폴더, 동기화 폴더도 포함한다.
- 매월 로그인 기기·복구 수단·모르는 자동 전달 및 앱 접근 권한을 확인하고 OS·브라우저를 업데이트한다. 비밀번호·인증번호·복구 코드는 공유하지 않는다.
- 개인정보가 있는 화면을 공개 이슈나 AI 대화에 그대로 붙이지 않는다. 문의 분석에 필요한 최소 내용만 개인을 알아볼 수 없게 제거하여 사용한다.

## 문의나 삭제 요청이 왔을 때

1. 접수일과 요청 종류를 확인한다. 일반 오류 문의인지, 열람·정정·삭제·처리정지·동의 철회인지 구분한다.
2. 필요한 범위에서 요청자의 권한을 확인한다. 본인이 보낸 문의의 삭제는 기존 메일 대화·발신 주소 등으로 우선 확인한다. 불일치나 대리 신청이면 필요한 최소 증빙을 별도로 검토한다. 신분증이나 주민등록번호를 관행적으로 요구하지 않는다.
3. 아래 표로 실제 보유 위치와 조치 범위를 정한다. 운영자 서버에 게임 저장이 있다고 오해하게 안내하지 않는다.
4. 조치 후 무엇을 했는지, 하지 못한 부분과 이유, 이의제기 방법을 답장한다. 요청 전체를 거절하지 말고 가능한 범위부터 처리한다.
5. 필요가 끝난 개인정보와 사본을 삭제한다. 보관 예외는 실제 법률 근거·대상·종료 시점을 확인하고 분리한다. 향후 유료결제의 보존기간을 현재 모든 문의에 일괄 적용하지 않는다.

| 요청 범위 | 처리 방법 |
|---|---|
| 휴대폰의 게임·연령 구간·선택 기록 | Android의 해당 앱 데이터 삭제 방법을 안내한다. 진행 기록도 없어짐을 먼저 알린다. 원격 삭제 완료라고 답하지 않는다. OS 백업은 별도 관리이며 복원될 수 있다. |
| 운영자가 받은 문의·첨부파일 | 확인된 메일·첨부·인용·별도 사본을 찾아 정정/삭제/이용 중단한다. 삭제 완료 답장을 보낸 후 그 답장에 재포함된 불필요한 개인정보도 정리한다. |
| 새로운 광고 요청을 원치 않음 | 게임 설정의 광고 이용 선택을 끄도록 안내한다. 철회가 과거 Google 자료 삭제까지 뜻하지는 않는다. |
| Google 광고 데이터 열람·삭제 | 운영자가 보유한 자료 여부부터 확인하고 Google 공식 권리 행사 경로를 안내한다. 운영자가 직접 조치할 법적 의무가 있는 범위는 별도로 검토한다. Google에 대한 모든 권한이 없다는 이유만으로 요청을 일괄 거절하거나 삭제를 보장하지 않는다. |

### 기한을 관리하는 법

접수 당일 내부 마감일을 적는다. 일반 문의의 '2영업일 안에 첫 회신'은 운영 목표이며 법정기한이 아니다. 권리 요청은 가능한 즉시 조치하고, 10일 기한이 적용되는 열람·정정/삭제 결과·처리정지 결과 통지를 놓치지 않는다. 10영업일로 늘려 해석하지 않는다. 열람 연기에는 정당한 사유와 안내가 필요하며, 모든 요청을 임의로 연장할 수 있다는 뜻이 아니다. 접수 확인 답장만으로 결과 통지를 대신하지 않는다. 특별법·거절 사유·대리 요청 등 애매한 경우 마감 전에 118 또는 전문가에게 확인한다.

근거: 개인정보 보호법 제35~37조, 시행령 제41~44조. [열람 절차](https://law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1029331279), [정정·삭제 결과 통지](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0043&lsiSeq=283503&urlMode=lsScJoRltInfoR), [시행령 공식 본문](https://www.law.go.kr/법령/개인정보보호법시행령), [권리 행사 안내](https://www.privacy.go.kr/front/contents/cntntsView.do?contsNo=41).

## 복사해서 쓸 답장

대괄호 부분을 실제 사실로 바꾼 뒤 발송한다. 이 작업에서 고객에게 메일을 발송하지 않았다.

**접수**

> 안녕하세요. 부대 키우기 운영자입니다. [접수일] 보내주신 [요청 종류]를 접수했습니다. [확인할 범위]를 확인하여 조치 결과를 안내하겠습니다. 추가 정보가 필요하면 필요한 항목만 별도로 요청드리겠습니다. 비밀번호·인증번호·주민등록번호는 보내지 말아 주세요.

**운영자가 가진 문의 자료 삭제 완료**

> 요청하신 자료 중 운영자가 보유한 [정확한 범위]를 [처리일] 삭제했습니다. [남는 자료가 있다면 항목·근거·기간 / 없으면 해당 문장 생략]. 이 처리는 휴대전화의 게임 저장이나 Google이 별도로 처리하는 광고 데이터의 삭제를 의미하지 않습니다. 처리 결과에 이의가 있으면 이 이메일로 알려 주세요.

**기기 기록 삭제 안내**

> 게임 저장은 이용자 기기에 있어 운영자가 원격으로 지울 수 없습니다. Android 설정에서 부대 키우기의 저장공간 → 데이터 삭제를 선택하면 게임 진행 기록도 지워집니다. 기종에 따라 메뉴 이름이 다를 수 있습니다. 운영체제 백업이 켜져 있다면 백업 관리도 별도로 확인해 주세요. 앱 삭제만으로 모든 백업까지 없어지는 것은 아닙니다.

## 최소한의 업무 기록

요청이 진행 중일 때만 필요한 기록을 비공개로 관리한다. 공개 Git·공개 Google 문서·게임 소스에 고객 정보를 기록하지 않는다. 아래는 빈 양식이며 법정 보존기간을 정한 것이 아니다.

| 접수번호 | 접수일 | 종류 | 통지 마감 | 필요한 조치 | 결과 통지일 | 삭제/보관 예외 확인 |
|---|---|---|---|---|---|---|
| | | | | | | |

주소·문의 전문·첨부는 별도 대장에 중복 복사하지 않는다. 메일과 연결되는 접수번호도 개인정보가 될 수 있다. 처리 증빙을 남길 필요가 있으면 최소 항목·근거·기간을 따로 정하고, 목적이 끝나면 연결 정보도 지운다. 고객을 식별할 수 없는 점검 날짜와 건수만 남기는 방법을 우선 검토한다.

## 계정 도용·메일 오발송·기기 분실이 생기면

1. 발견 시각·확인된 사실·영향받은 자료를 비공개로 기록한다. 의심과 확인 사실을 구분한다.
2. 안전한 기기에서 비밀번호 변경, 모르는 세션·전달 규칙·접근 권한 차단 등 추가 노출을 막는다. 증거를 무작정 삭제하거나 분실 기기를 즉시 초기화하여 조사 자료를 없애지 않는다.
3. 로그인 기록·오발송 범위 등 필요한 증거를 최소 범위로 확보하고 118에 상담한다. 상담 자체가 법정 신고나 이용자 통지를 대신하지 않는다.
4. 정보주체 통지와 기관 신고를 별도로 판단한다. 유출이 확인되면 법 제34조·시행령 제39조의 통지 요건·기한을 즉시 확인한다. 기관 신고는 1천 명 이상, 민감/고유식별정보, 외부 불법 접근에 의한 유출 중 하나라도 해당하면 72시간 이내 신고 기준을 적용한다. 소수 고객의 메일 계정 침해도 신고 대상이 될 수 있다. 예외는 임의 판단하지 않는다.
5. [공식 신고 안내](https://pipc.go.kr/np/default/page.do?mCode=D030040000)의 현행 경로로 신고한다. 조사 완료를 기다리며 기한을 넘기지 말고, 미확정 사실은 미확정으로 알리고 보완한다. 항목·시점/경위·피해 최소화·조치·문의처를 준비한다.
6. 원인과 재발 방지를 기록하고 필요 시 방침·접근 권한·운영 절차를 갱신한다. 모든 증거를 영구 보관하지 말고 사고 처리와 법정 보존 필요를 구분한다.

## 방침과 스토어를 다시 확인해야 하는 변경

실제 결제, 새 광고/분석 SDK, 로그인·서버·클라우드 저장, 배포 국가, 문의 담당자/서비스, 처리 목적·기간이 바뀌면 [동기화 절차](PRIVACY_MANAGEMENT.md)를 따른다. 공개 방침과 앱 배포는 별개의 작업이다. 결제는 2026-10-12 이후, 광고 계정·앱 승인은 별도 보류한다. 알림 예약은 하지 않았다.

이 단계는 운영 절차 마련이다. [남은 출시 검토](store/PRIVACY_RELEASE_REVIEW.md)의 국외 처리·연락처·처리 근거·동의/신고 해석을 해결했다는 뜻이 아니다. 실제 계정 보안은 사용자 확인 기준이고, 삭제·사고 대응을 실행한 사례는 없다. 마지막 5단계에서 완료/미완료를 구분해 최종 점검한다.
