기존 지휘 사관학교 Lv.5 이후 건설한다. 계급과 골드 조건을 모두 충족해야 확장한다. 새 병력 1명의 전력은 해당 계급 목표 전력의 1/64로, 직전 계급 최소 전력에서 새 병력 56명으로 다음 계급에 도달한다. 정확한 모집 가격·수입은 `src/galactic-officers.js`가 기준이다.

신규 군사 장비는 최대30강을 유지한다. 최초 가격은 0.1/0.4/1.6/6.4/25.6경, 새 장비의 강화비는 기본 가격의25%에 단계별1.18배(1만 골드 단위 올림)다. 신규 강화비·구매 합계는 BigInt로 계산하고 지갑 상한은 저장 버전34부터1,000해(10²³ G)로 확대한다. 해 단위에서는 해·경 두 단위로 표시하고, 보유액은 버림·구매 가격은 올림하되 실제 계산·저장은1G까지 보존한다. 이전 버전 저장은 기존 상한1,000경으로 검증한 뒤 보유액을 그대로 이전하며 골드를 추가 지급하지 않는다.

병력 기본 모집 가격은12/42/147/514.5/1800.75경(단계별×3.5), 수입은 단계별×2로 조정했다. 진급에 필요한56번째 모집도 지갑 상한 이내다. 비교용 성장 시뮬레이션(하루3회×7.5분, 시설 강화·전투 포함)에서 부사령관15.334일, 이후 은하 계급은16.337/17.001/17.334/18.001/19.001일에 도달했다. 지갑 상한 확대에 맞춰 모집 가격을 재조정한 결과다. 시설 건설만 하고 전투를 제외한 비교에서는 은하 계급31.333/32.667/34.667/37.334/42일이며, 실제 소요 기간을 보장하는 값은 아니다.

## 에테리온 대륙

아스테라80개 지역 완료 후 열린다. 나라별20개 지역, 이전 나라 전체 점령 후 다음 나라가 열린다. 대륙 전환과 나라 위·아래 이동을 유지한다.

| 국가 | 수도 권장 전력 기준 | 기준 전력 시뮬레이션 승리 시간 |
|---|---|---:|
| 엘리시아 연맹 | 은하 준장 | 약106초 |
| 바르키온 동맹 | 은하 소장 | 약92초 |
| 세라피스 왕조 | 은하 대장 | 약130초 |
| 녹타리스 제국 | 은하 원수 | 약98초 |

새 수도는 권장 전력의1/4에서 패배,2배에서 더 빠른 승리를 확인했다. 이는 시뮬레이터의 자동 출격 기준이며 수동 전략이나 장비 구성에 따른 승리를 금지하는 계급 제한은 없다. 실제 플레이 균형은 테스트 의견에 따라 조정한다.

- 기존 지역 초당 수입+1%, 신규 지역+2%. 전체160개 지역 완료 시 +240%.
- 지역 최초 점령 수입 보너스는 중복 적용하지 않는다. 별·첫 승리 보상은 기존 규칙을 유지한다.
- 기존·새 편제20종은 전투용 위에서 본 별도 그림을 사용한다. 아군은 최대 보유 편제, 적은 지역의 편제와 수도 요새 표시를 사용한다.
- 좁은 연병장에서도 은하 상위 본부는84 native/168 CSS px를 유지한다. 작은 화면에서 하위 편제를 추가 행으로 배치하고 같은 연병장을 스크롤한다.
- 새 편제·국가 훈장을 포함해 총30개 훈장을 표시한다.

## 연출·저장·출처

17종 장비의 반동·포탄·연속 로켓·기총·함재기·폭탄·축전 광선 등을 구분한다. 수송기는 공격 대신 보급·회복 연출을 사용한다. 본부 파괴 후 결과창을 표시하며, 승리 보상은 기존처럼 한 번만 정산한다. 동작 줄이기 설정에서는 짧은 연출을 사용한다.

저장 키는 유지하고 저장 버전은33→34로 올린다. 이전80개 별 기록을 보존하고 새80개를0으로 확장한다. 기존 장비·개인 장비·자동터치 보유 기록을 유지하며 은하 학교·병력은0에서 시작한다. 실제 사용자 저장은 검수용으로 덮어쓰지 않는다.

새 도형·픽셀 그림·합성 효과음은 프로젝트에서 직접 작성했다. 외부 에셋·새 라이브러리·생성 음원을 추가하지 않았다. ElevenLabs 신규 음원 생성은 사용자의 선택에 따라 진행하지 않았다. Figma에는 실제 신규 계급장 도형을 옮긴 편집 가능한 보드를 만들었다: [은하 확장 디자인](https://www.figma.com/design/lsZXZU9i702p5150UOA0Wv?node-id=3-2).

SDK·권한·광고 ID·결제·개인정보 처리에는 이번 확장으로 인한 변경이 없다. 스토어 소개 로컬 초안은 새 콘텐츠로 수정했으며 Play Console에 직접 제출하지 않았다. 기존 공개 개인정보처리방침 개정7 동기화 미완료 사항은 별도다. 최종 테스트·빌드·미확인 사항은 루트 `검증결과.md`에 기록한다.
