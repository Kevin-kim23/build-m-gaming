# 1단계 보안·삭제 보완 · 작성 중 초안 (2026-10-12)

**게시용 최종본이 아니다. 방침11·약관8을 유지하며, 최종 문안 승인 전 번호를 올리지 않는다.** 0.77.1·0.79.0 AAB는 모두 중간 검증용이다. 아래의 과거 버전 기록보다 이 항목과 사용자 최신 지시를 우선한다. 현재 단계는 로컬 코드·문서 검증이며 운영 배포, 실제 Google 로그인, 실제 계정 삭제, 실기기는 미완료다.

- [ ] 결제 없이도 끝까지 갈 수 있는지(현재 부사령관까지)와 결제가 그 속도를 어떻게 바꾸는지 밸런스를 점검한다.

문서·설정
- [ ] 방침: 구매 기록 저장 여부, 결제는 Google이 처리한다는 사실을 적는다.
- [ ] Play Console: 상품 등록, 가격, 상품 설명, 데이터 보안 양식, 콘텐츠 등급 재작성.
- [ ] 한국 소비자 보호: 가격·상품 표시, 환불 안내, 청약철회, 미성년자 결제 안내 (확인 필요).
- [ ] 수익이 생기면 사업자 등록, 통신판매업 신고, 세금 (세무사·관할 기관 확인).

## 4. 배포 직전 마지막 점검
- [ ] `npm test`, `npm run build`, `npm run audio:verify` 통과
- [ ] 앱 안 방침(정보 → 개인정보처리방침 보기)과 웹 공개 글이 같다
- [ ] 스토어 설명에 "광고 포함", "앱 내 구매" 표시를 맞게 했다
- [ ] 실기기에서 광고·결제를 직접 한 번씩 해 보았다 (테스트 계정 사용)
- [ ] 문의 이메일로 실제 메일이 오는지 확인했다

## 5. 계속 해야 하는 것
- Google Play 정책 변경 메일을 읽는다 (놓치면 앱이 내려갈 수 있다).
- SDK를 업데이트할 때마다 그 회사의 안내 변경을 읽는다.
- 방침 날짜가 1년 넘었다면 내용이 지금 앱과 맞는지 읽어 본다.
- 이용자 문의 메일에는 정해 둔 기간 안에 답한다.
