# 오프라인 복귀 보상 · 0.53.0

## 플레이 규칙

- 오프라인 수입은 기존과 동일하게 **최대 8시간**입니다. 마지막 수입 정산 시각을 기준으로 계산합니다.
- **1시간 미만**: 기존처럼 접속 시 자동 지급합니다.
- **1시간 이상**이고 수입이 있으면: 중앙에 “병사들이 골드를 모았어요!”와 정산 시간·골드를 표시합니다. ‘받기’로 지급하며, ‘두 배 받기’는 광고 보상 연결 지점입니다.
- 병력·배치 장비·점령/개인 장비 보너스와 남아 있던 자동 터치 수입은 기존 계산을 재사용합니다. 온라인 수입은 계속 자동 지급합니다.
- ×·뒤로가기·Esc로 닫으면 미수령 보상을 보관합니다. 다음 접속/앱 복귀 때 다시 표시하며, 미수령 상태에서 추가로 비운 시간은 보관분과 합쳐 최대 8시간까지만 인정합니다. 수령하면 다음 오프라인 보상의 8시간 한도가 새로 시작됩니다.
- 두 배도 보유 골드 상한 **1,000경**까지만 지급합니다. 남은 수용량보다 큰 보상은 초과분이 버려집니다. 받기 버튼에 실제 지급 가능한 금액을 표시합니다.

## 광고 미연결 상태

사용자 선택: 개발 테스트에서는 광고 없이 두 배 지급.

- `npm run dev` 등 Vite 개발 서버에서만 ‘개발 테스트 · 광고 없이’로 표시하고 두 배를 지급합니다.
- 출시용 웹 빌드/APK에서는 ‘광고 시청 · 준비 중’입니다. 누르면 미연결 안내를 보여주고 보상은 그대로 남깁니다. 일반 받기는 동작합니다.
- `src/rewarded-ads.js`의 `showOfflineRewardAd`를 실제 보상형 광고 어댑터로 교체할 수 있습니다. 성공은 `{status:'rewarded'}`, 취소는 `{status:'cancelled'}`, 미준비는 `{status:'unavailable'}`입니다. 창 닫기와 보상 획득 완료를 구분해야 합니다.
- 광고 SDK 도입 때는 광고 화면으로 인한 앱 pause/resume과 비동기 보상 콜백 순서를 추가 구현·실기기 검증해야 합니다. 현재 비활성 상태의 늦은 콜백은 보상을 소비하지 않고 재시도하게 합니다. 현재 어댑터만으로 실제 광고 연동이 완료된 것은 아닙니다.

## 코드 위치와 저장

| 파일 | 역할 |
|---|---|
| `src/offline-rules.js` | 8시간 상한·1시간 팝업 기준 |
| `src/offline-reward.js` | 오프라인 보관/한 번만 수령하는 순수 계산 |
| `src/session.js` | 복귀 정산, 저장 성공 후 수령 확정, 창 간 소유권 |
| `src/offline-reward-controller.js` | 광고 대기 중 연타 차단·완료/실패 처리 |
| `src/offline-reward-ui.js`, `.css` | 중앙 팝업·버튼·안내 |
| `src/rewarded-ads.js` | 개발 지급/출시 미연결 어댑터 |

저장 키는 유지하고 형식을 **23**으로 올렸습니다. `offlineReward`는 `null` 또는 `{id, durationMs, amount}`입니다. 형식 2~22는 미수령 보상 없이 이전되며 기존 병력·골드·강화·진행을 유지합니다. 큰 금액은 기존 `money.js`와 십진 문자열 저장을 사용합니다. 보상 생성과 수령은 즉시 저장하며 수령 저장 실패 시 보상과 잔액을 복구합니다. 화면 터치마다 저장하는 방식은 추가하지 않았습니다.

## 권리·출시 확인 범위 (2026-10-07)

이번 변경에는 외부 에셋·광고 SDK·네트워크 요청·개인정보 수집을 추가하지 않았습니다. 광고 수익 기능은 아직 없습니다. 실제 SDK 도입 시에는 개인정보처리방침/Play 데이터 보안, 동의·대상 연령 설정, 실제 사용 SDK의 공식 조건을 다시 확인해야 합니다.

Google 공식 [Android 보상형 광고 안내](https://developers.google.com/admob/android/rewarded)는 보상 획득 콜백 `OnUserEarnedRewardListener`를 별도로 제공하며 개발 중 테스트 광고 사용을 안내합니다. 실제 연결 시 이 콜백에서만 보상을 확정하고 광고 닫기만으로 지급하지 않습니다.

자동 검사에는 경계 시간·8시간 상한·재접속·중복 수령·저장 실패·큰 금액·복수 창·광고 실패/늦은 콜백·모의 DOM 팝업·실제 Vite 출시 변환 결과가 포함됩니다. 모의 DOM은 실제 화면 배치나 Android 기기 검증을 대신하지 않습니다.
