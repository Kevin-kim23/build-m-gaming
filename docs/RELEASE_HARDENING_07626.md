## 실제 크기

MB는 1,000,000바이트 기준. 웹 자료는 파일 합계, AAB는 ZIP 압축된 업로드 파일이다. Play의 기기별 다운로드·설치 용량과 다르다.

| 항목 | 이전 바이트 | 이후 바이트 | 감소 |
| --- | ---: | ---: | ---: |
| 캐릭터 5장 + 제목 그림 | 11,611,912 | 8,010,606 | 3,601,306 |
| Black Han Sans 전체 글꼴 | 998,424 | 190,720 | 807,704 |
| 중복 배포 TXT | 864,520 | 0 | 864,520 |
| 웹 자료 전체, 음악 포함 | 31,043,898 | 25,770,369 | 5,273,529 (약 17.0%) |
| 서명 AAB | 35,604,084 | 31,832,499 | 3,771,585 (약 10.6%) |

PNG 원본은 `assets/source-images/`에 보관한다. 같은 디코더로 읽은 PNG/WebP의 크기·RGBA 배열이 완전히 같고, 투명 픽셀 내부 RGB도 보존했다. 파일별 해시와 재현 정보는 `image-encodes.json`, 검사 도구는 `tools/verify-image-encodes.py`이다. 이 엄격한 보존 설정의 크기를 외부 리뷰의 다른 압축 설정 예상치와 동일하다고 표시하지 않는다.

글꼴은 2,734개 글리프·2,733개 유니코드 매핑과 윤곽·폭·힌팅·배치를 유지한다. 빈 서명 테이블 제거와 압축용 체크섬 변경만 있다. 원본 TTF/OFL은 `assets/source-fonts/`, 배포 WOFF2/OFL은 `public/fonts/`에 있다. `font-conversion.json`, `tools/convert-font.py --check` 참고. 기존 저작권·OFL 전문을 유지하며 상업용 앱 번들 및 웹폰트 변환 조건은 [공식 OFL FAQ](https://openfontlicense.org/ofl-faq/)를 확인했다. 새 외부 폰트·그림·음원은 추가하지 않았다.

## 고지·문서·구조

- 설정 → 게임 정보 → 오픈소스 라이선스는 기존 JSON을 계속 사용한다. 실제 production 고지 청크가 원본의 **190개 항목·44개 전문과 동일**함을 검사했다. AdMob·UMP·Billing·AndroidX·Capacitor·OFL을 포함한다.
- 루트 `THIRD_PARTY_NOTICES.txt`는 남겼고 배포용 중복만 삭제했다. 생성기도 중복을 다시 만들지 않는다. 원문 라이선스를 줄이거나 개발 도구 고지를 앱에 추가하지 않았다.
- README / CONTINUE / 검증결과 합계는 182,416바이트 → 기록 분리 직후 39,238바이트. 여기에 이번 요약을 추가했다. 과거 본문은 `history/`의 세 이력 파일에 옮겼고 원문 재구성 비교를 통과했다. `version-sync` 검사 통과.
- 기준 시점 main 대비 UI만 29커밋, 200파일(+27,335/-20,310줄), main만의 커밋은 0개. 옛 UI 126커밋/서버 129커밋은 기반과 기능 범위가 달라 높은 버전 번호만으로 출시 기준을 바꾸면 안 된다.
- UI 브랜치에도 구매·저장42·자동터치10회/초·성장 변경이 포함된다. 단순 그림 변경만 있는 브랜치가 아니다.
- AGENTS의 400줄 규칙은 **초과 시 분리를 제안**하는 규칙이다. 한 줄에 코드를 몰아 쓸 필요가 없다. 200자 초과는 src JS188줄, 저장소 JS243줄/MJS102줄, 최장 `campaign-hq.js`1,852자였다. 검사 범위에 따라 외부 수치와 다르다.
- CSS 색상은 알파 포함 집계880개, `style.css`1,654줄이었다. UI 역할별 색은 토큰으로 합치되 그림·효과의 팔레트까지 기계적으로 바꾸지 않는다.
- 후속 구조 정리는 화면 캡처 → 해당 화면 CSS 분리 → 색/간격 토큰 연결 → 작은 화면 비교 → 커밋 순서가 적합하다. 포맷 변경과 게임 규칙 변경도 분리한다.
