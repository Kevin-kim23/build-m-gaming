# 하단 메뉴·상점 UX 근거와 검증 · 0.76.23

2026-10-15. 사용자 요청: 7개 메뉴의 그림 크기·직관성·자간·색상 통일, 상점 골드 제거, 스타터팩 주변 효과, 자동터치 실제 초당10회와 혜택 표시.

그림은 자체 작성한 SVG이며 외부 에셋·SDK·새 폰트 추가 없음. 아이템 그림은 기존 게임 물약의 색상/금속 재질을 따르되 메뉴 크기에 맞춰 다시 그림. 이름을 제거하지 않고 보조 그림은 접근성 트리에서 제외해 중복 낭독을 막는다.

대표 불투명 색 조합을 sRGB 상대 휘도로 계산한 글자 대비: 메뉴 글자/밝은 배경 끝7.86:1, 자동터치 혜택/배경8.35:1, 상품 본문/배경10.17:1. 전체 그라데이션·모든 상태·모든 기기의 접근성 전수 검증과는 구분한다.

## 읽은 연구와 적용의 한계

1. Isherwood, McDougall & Curry (2007), *Icon Identification in Context: The Changing Role of Icon Characteristics With User Experience*, Human Factors 49(3),465–476. DOI10.1518/001872007X200102.
   - 출판사 초록을 확인했다. 유료 본문 전체를 읽었다고 주장하지 않는다. 30명 반복 식별 연구는 초기에는 그림과 기능 간 의미적 거리가, 경험이 쌓인 뒤에는 친숙성이 중요함을 보고한다.
   - 적용 판단: 병사/전차/천막 상점/건물/개인 장구/물약/교차검처럼 기능을 구분하는 그림과 이름을 함께 유지. 작은 픽셀 그림의 실제 식별률은 이번 게임에서 아직 측정하지 않음.
   - https://journals.sagepub.com/doi/10.1518/001872007X200102
2. Przybylski, Rigby & Ryan (2010), *A Motivational Model of Video Game Engagement*, Review of General Psychology 14(2),154–166. DOI10.1037/a0019440.
   - 공식 저자 연구 자료실의 논문 PDF에서 동기 모델/유능감/자율성 논의를 확인했다. 게임 참여에 대한 이론·연구 검토이며 상점 색상이나 매출을 시험한 논문이 아니다.
   - 적용 판단: 알아볼 수 있는 조작, ON/OFF 선택권, 구매·보유 상태 피드백을 유지한다. 특정 색이나 효과로 구매/지속 플레이가 보장된다고 해석하지 않는다.
   - https://selfdeterminationtheory.org/SDT/documents/2010_PrzybylskiRigbyRyan_ROGP.pdf
3. Nielsen Norman Group, *Icon Usability* — 연구 논문과 구분한 UX 실무 연구 자료. 그림은 의미가 모호할 수 있으므로 글자 레이블을 유지하는 데 참고.
   - https://www.nngroup.com/articles/icon-usability/
4. W3C WCAG2.2 SC2.5.5 Target Size (Enhanced) —44×44 CSSpx 확대 기준(AAA)을 디자인 목표로 참고. AA 최소 크기라고 혼동하지 않는다. 메뉴 버튼 높이78px/전투52px, 짧은 화면에서는64px/46px. 일반 가격 버튼44px.
   - https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html
5. W3C WCAG2.2 SC2.2.2 Pause, Stop, Hide —5초 넘는 자동 움직임의 정지 수단 안내 참고. 이번 스타터팩 장식은4.2초1회로 종료하고 reduced-motion을 존중한다. 자동터치 기존 소개 애니메이션 전체에 대한 접근성 인증을 했다는 의미는 아니다.
   - https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html

관련 자료의 제한된 검토이며 모든 논문을 확인한 것은 아니다. 색감과 픽셀 미술은 위 연구를 고려한 디자인 판단이다. 구매율·장기 잔존율·편안함 향상은 사용자 실험 전 미확인이다.
