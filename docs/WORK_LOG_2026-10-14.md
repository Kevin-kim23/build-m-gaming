## 시간순 작업

1. 사용자 결정과 저장소 규칙을 읽고 로컬·원격 브랜치 및 변경 상태를 확인했다.

6. AGENTS.md, CONTINUE.md, 검증결과.md에 첫 출시 범위와 이어서 작업할 위치를 기록했다. 서버 관련 문구 목록은 별도 보고서에만 작성했다.
7. npm test 721개 통과, npm run build 성공. 빌드의 기존 큰 청크 및 시간 측정 경고를 확인했다. 기능·의존성·정책 버전 변경은 없다.

- 목록은 [첫 출시 서버 문구 목록](FIRST_RELEASE_SERVER_TEXT_INVENTORY.md)에 기록했다. 서버 스냅샷과 main 내용을 구분하고 광고 서비스의 Google 서버 처리도 별도로 분류했다.
- 기존 서버 기반 로컬 UI 미리보기(4196)는 혼동 방지를 위해 종료했다. 새 미리보기는 아직 실행하지 않았다. 브라우저 게임 기록은 변경하지 않았다.
- 미확인: 실제 공개 방침·스토어 게시본, 현재 클라우드 함수·예약·과금 상태, 실폰 동작. 클라우드·인증·배포에 접근하지 않았다. 이미 배포된 서버는 이 작업으로 중단되지 않는다.
- 푸시 대상은 새 UI 브랜치뿐이다. 커밋·푸시 성공 및 원격 차이 0/0 여부는 작업 종료 시 Git으로 확인해 최종 보고한다. main·기존 두 브랜치에는 쓰지 않는다.

## 0.76.7 자동터치 상품 소개 개선

- 사용자 설문에 따라 새 상품/부스터팩은 추가하지 않는다. 기존 스타터팩 구성과 가격을 유지하고 자동터치 소개를 개선했다.
- 자동터치는 편의 기능·초당5회·영구 보유·손가락 병용·홈 전용 조건을 명확하게 표시한다. 상점과 홈 독립 팝업은 같은 소개를 재사용한다.
- 커서/빛/파동은 CSS의 transform·opacity만 사용하고 실제 입력이나 골드를 발생시키지 않는다. 닫힌 창에서는 정지하며 기기 모션 줄이기 설정에서는 정지 그림이다.
- 직접 확인함: 코드/정책 자료 읽기 → 새 상품 추가 취소 설문 반영 → 소개/효과 변경 → 전체 검사 → 좁은 화면의 버튼 위치 개선 → 집중 재검사/빌드 순서로 진행했다. 오류·실패한 자동 검사는 없었다.
- 직접 확인함: npm test 764/764 통과. 이후 미보유 토글 숨김/중복 설명 정리를 반영한 관련13개 재검사 통과, 최종 npm run build 성공. 기존 라이선스 고지 청크 크기 경고는 유지한다.
- 직접 확인함:320×720/412×915에서 페이지와 창의 가로 넘침 없음. 412px에서는 가격/구매 버튼까지 한 화면에 표시된다. 320px에서는 구매 버튼까지 조금 스크롤해야 한다. 소개 그림을 줄이고 작동 예시와×5 간격을 보정했다. 보유 전 켜기/끄기 숨김, 보유 후 표시, 취소 무지급, 무료 확인 지급, 닫힌 상점의 animation-play-state=paused를 별도4207 시험 기록에서 확인했다.
- 직접 확인함: 상품은 기존 자동터치/스타터팩2종뿐이다. 효과는 opacity(투명도)와 transform(그림 이동/크기)만 바꾸고 입력·골드 거래를 호출하지 않는다. 모션 줄이기 CSS 규칙은 코드로 확인했으며 실제 기기 설정 검사는 미확인이다.
- 미리보기 재시작 중4208의 임시 모듈 불러오기 실패가1회 발생해 새로고침으로 다시 연결했다. 실제 게임/대령 기록을 시험용 지급 데이터로 덮어쓰지 않았다. 4207 시험 서버는 정리하고4196/4208만 유지한다.

- 은행 비유: 기존 상품의 안내판과 진열을 고쳤으며 상품 가격이나 예금 장부(저장39)는 바꾸지 않는다. 서버·SDK·정책 원문/번호 변경 없음.
