## S9+ 디버그 토큰 로그 필터 정정 · 2026-10-14

사용자가 짧은 DebugAppCheckProvider 필터 명령에서 로그 구역 제목만 확인했다고 보고했다. 앱 프로세스 로그를 메모리에서 정해진 표식만 검사해 네이티브 App Check 존재, Firebase 초기화 성공, 디버그 시크릿 생성 안내 존재를 직접 확인했다. 토큰 값/로그 원문은 출력·저장하지 않았다. SDK의 실제 로그 태그는 com.google.firebase.appcheck.debug.internal.DebugAppCheckProvider여서 짧은 태그 필터와 맞지 않았다. 처음 태그 판별 정규식은 괄호 표기를 가정해 불일치했고 tag 출력의 콜론도 처리해 정확한 클래스 이름만 추출했다.

사용자 직접 명령: adb logcat -d -s com.google.firebase.appcheck.debug.internal.DebugAppCheckProvider. 로컬 출력만 확인하며 채팅/스크린샷에 토큰을 보내지 않는다. 콘솔에는 개발 Android 앱의 디버그 토큰 관리 입력창과 별명만 준비했고 실제 토큰 저장은 미완료다. 코드/설정 변경 없음, 테스트·빌드 재실행 없음. 문서만 갱신·푸시한다. 은행 비유: 이미 발급된 시험 단말기 등록번호를 잘못된 분류에서 찾고 있었던 상황이다. 앱 초기화/토큰 재발급/보호 우회 없음. 정책 영향 없음.
