- 목록은 [첫 출시 서버 문구 목록](FIRST_RELEASE_SERVER_TEXT_INVENTORY.md)에 기록했다. 서버 스냅샷과 main 내용을 구분하고 광고 서비스의 Google 서버 처리도 별도로 분류했다.
- 기존 서버 기반 로컬 UI 미리보기(4196)는 혼동 방지를 위해 종료했다. 새 미리보기는 아직 실행하지 않았다. 브라우저 게임 기록은 변경하지 않았다.
- 미확인: 실제 공개 방침·스토어 게시본, 현재 클라우드 함수·예약·과금 상태, 실폰 동작. 클라우드·인증·배포에 접근하지 않았다. 이미 배포된 서버는 이 작업으로 중단되지 않는다.

## 0.76.7 자동터치 상품 소개 개선
