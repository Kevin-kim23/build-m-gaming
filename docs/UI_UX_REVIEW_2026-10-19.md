# 홈·전투 사용성 검토 · 2026-10-19

이번 구현은 대원 얼굴을 검정 단색으로 정리하고 전투의 이모지·문자 그림을 자체 SVG(크기에 맞게 그리는 도형 그림)로 바꾸는 범위다. 아래 흐름 변경은 **제안이며 아직 적용하지 않았다**. 밸런스·저장·서버는 변경하지 않는다.

## 확인 범위

- 직접 확인함: 홈·세계/지역 지도·편성·전리품 상점 화면, 별도 4233 합성 기록의 390px 전투 진입·카드 선택·일시정지. 사용자 4213 기록은 테스트 기록으로 덮어쓰지 않았다.
- 직접 코드 확인함: 닫기/뒤로가기 종료 경로, 다음 지역 즉시 출전, 부스터 이름 숨김과 추가 소비, 보급 알림 점, 카드 크기·가로 스크롤.
- 추가 화면 확인: 320×568에서 실제 가장 긴 지역명과 긴 장비명6종을 사용한 읽기 전용 표시. 가로 넘침은 없었으나 제목이 두 줄로 끊기고 카드 글자가 여러 줄로 매우 작게 보임. 전장/카드 그림을 그리지 않는 크기 점검용 화면으로, 실제 전투 성공 검증과 구분한다.
- 문서로만 확인함: Android의 터치 영역 권장 기준.
- 미확인: 실제 Android 폰의 엄지 조작·시스템 뒤로가기·화면 읽기 프로그램. 코드 위험과 실기기에서 재현된 결함을 구분한다.

## 색과 정보의 우선순위

- 기본 틀은 현재의 어두운 청록을 유지. 금색은 ‘다음 작전/획득 보상/선택한 카드’에 제한해 강조끼리 경쟁하지 않게 한다.
- 마나는 청색, 아군은 청록, 적·위험은 채도 낮은 적색. 색만으로 구분하지 않고 이름·상태·외곽선도 함께 사용한다.
- 준비 화면에서는 선택됨(금색 테두리)과 상성 유리/불리(글자 배지)를 별도 표현해 같은 테두리에 여러 의미가 겹치지 않게 한다.
- 홈 기존 메뉴 순서(전투·전리품 위, 기존6개 아래)와 진급 바 40/60/80% 색은 사용자 결정이므로 유지한다. 메뉴 수를 줄이는 대신 받을 보급·다음 전투 등 실제 행동만 작은 배지로 강조한다.
- 반복되는 영어 장식 문구는 ‘작전 지도 / 국가 지도 / 지역’ 등 한글 정보로 줄이는 것을 제안한다. 제목·숫자·실행 버튼의 글자를 우선 확보한다.

## 권장 기준과 한계

Android 공식 문서는 상호작용 요소의 터치 영역을 최소48×48dp로 권장한다. 작은 그림의 주변 여백을 늘려 확보할 수 있다. CSS px 실측을 Android dp 충족으로 단정하지 않고 APK 실기기로 확인한다.

출처: [Android Developers — Make apps more accessible](https://developer.android.com/guide/topics/ui/accessibility/views/apps-views?hl=en), 2026-10-19 확인. 외부 게임 그림·폰트·화면을 복제하지 않았다.

은행 비유: 창구 간판을 예쁘게 만드는 것에 더해, 어떤 창구로 가야 하는지와 버튼을 누르면 무엇이 처리되는지를 일치시키는 작업이다. 다음 추천 순서는 ‘실수로 전투 종료 방지 → 출격 안내 → 조작부 고정’이다.
