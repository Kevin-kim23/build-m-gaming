# 출시 전 점검 · 중요도 순위 (2026-10-22, 앱 0.79.1 기준)

근거: `docs/RELEASE_POLICY_AUDIT_2026-10-19.md`(콘솔 상태는 10-19 기록), 현재 main 코드 대조.
이 문서는 계획용 순위표다. 방침·약관·스토어 원문이나 콘솔을 바꾸지 않았다. 법률 검토를 대신하지 않는다.

## 기본 방침 · AdMob 승인 지연 대응

- AdMob 승인을 출시 조건으로 묶지 않는다. **광고를 끈 채 먼저 출시 → 승인 후 업데이트로 실광고 켜기.**
- 출시본에 Google 샘플(테스트) 광고 ID로 광고를 띄우지 않는다. 수익이 없고 이용자에게 "Test Ad"가 보인다.
- 광고 끄기는 버튼만 숨기는 것이 아니라 광고 SDK·UMP 초기화와 광고 요청도 하지 않게 한다. 그래야 "광고 거부/미사용 시 전송 없음" 설명과 맞는다.
- 오프라인 보상은 일반 받기로, 부스터는 보급·전리품·스타터팩으로 계속 얻을 수 있다.
- 방침·약관은 **한 번만 개정**한다. 문구를 "광고 기능을 켠 버전에서만 광고를 요청한다"처럼 써서 광고를 켜도 재개정이 필요 없게 한다. 약관 번호를 올리면 기존 이용자에게 재동의 화면이 뜬다.
- 광고 개인정보 안내는 지우지 않는다(작업 규칙). Play "광고 포함" 선언을 광고를 끈 출시본에서도 유지할지는 Play 안내로 확인한다.

## P0 · 출시 차단 (이것 없이는 출시하지 않음)

| 순위 | 항목 | 이유 | 담당 |
|---|---|---|---|
| 1 | 광고 끄기 스위치 구현 + 시험 | 테스트 광고 출시 방지, AdMob 대기와 출시 분리 | 코드 |
| 2 | 방침·약관 1회 개정 (부스터 이름, 광고 상태 문구) + 공개본 동기화 | 현재 "물약", "빨강·파랑·금빛", "테스트 광고" 문구가 실제와 다름 | 문안 → 사용자 승인·게시 |
| 3 | Play 상품 설명 수정 (자동터치 5회→10회, 스타터팩 부스터 이름) | 결제 정책의 정확한 상품 표시 | 사용자 콘솔 |
| 4 | 테스트 결제 전 과정 (성공·취소·대기·중복·강제종료·복원·환불) | 실제 돈이 오가는 기능, 지금까지 0건 | 사용자 실폰 |
| 5 | 출시 AAB 확정 (음악 4곡 복원, 서명, `playBillingRelease=true`, 광고 꺼짐) | 결제 설정 없이 빌드하면 구매 버튼이 잠긴 채 출시됨 | 집 PC |
| 6 | 콘텐츠 등급 설문 재검토 (폭력 문항, 디지털 구매 문항) | 실제 전투(유인 장비 교전)와 신고 내용 차이 | 근거표 → 사용자 제출 |
| 7 | 유료 판매 판매자 정보·사업자/통신판매 확인 | 한국 유료 판매 요건 | 사용자·전문가 |
| 8 | 프로덕션 신청 자격 (비공개 테스트 기간·인원) | 신청 버튼이 열려야 출시 가능 | 사용자 콘솔 |

## 추천 작업 순서

1 광고 끄기 스위치 → 2 방침·약관 문안(사용자 승인) → 3 상품 설명 → 6 등급 근거표 → 5 출시 AAB → 4 테스트 결제 → 9~16 → 프로덕션 신청.
실폰 검증은 사용자가 스토어 업로드본으로 계속 진행 중(10-22 사용자 확인).
