# 게임 음원 복원과 검증

0.51부터 배경음악 18곡과 효과음 40개를 사용한다. 공개 Git에는 음원 파일이 없으므로 처음 받은 컴퓨터에서는 비공개 음원 묶음을 한 번 복원해야 한다.

## 집 컴퓨터에서

1. 최신 코드를 Git에서 받는다.
2. 본인에게 전달한 최신 `budae-kiugi-audio-0.51.1.zip`을 **프로젝트 최상위**에 푼다. `package.json` 옆의 `public/audio/music/home.mp3`가 생겨야 한다. 예전0.51.0 묶음의 음악은 무거운 버전이므로 새 묶음으로 교체한다.
3. `npm ci`를 실행한 뒤 `npm run audio:verify`로 58개 파일과 해시를 확인한다.
4. 웹 미리보기는 `npm run dev`, Android 복사는 `npm run android:sync`로 실행한다.

음원이 없어도 코드 테스트와 일반 `npm run build`는 가능하다. 음원 없는 개발 환경에서는 기존 합성 효과음이 대신 나고 BGM 오류가 진단 기록에 남을 수 있다. **출시용 `npm run build:release`와 `npm run android:sync`는 파일 누락·변조 시 먼저 실패한다.** Git만 받아 출시 패키지를 만드는 실수를 방지한다.

## 구성과 재생

| 구간 | 사용 음악 |
|---|---|
| 홈 / 작전 지도 | 각각 전용 음악 |
| 국가별 1~6지역 | 초반 |
| 국가별 7~13지역 | 중반 |
| 국가별 14~19지역 | 후반 |
| 국가별 20지역 | 수도전 |

0.51.1은 밝은 칩튠·팝으로 제작했다. 홈은 편안한 리듬, 세르딘은 기타, 벨로크는 전자 펑크, 이스트라는 벨·피아노, 노르가드는 청량한 신스 팝이며 수도는 빠르고 신나는 도전 분위기로 구분한다. 각 음악은 약59.2초 반복용이며 앞·뒤0.8초를 겹쳐 반복 경계를 완화했다. 브라우저 MP3 반복의 완전한 무간격 재생을 보장하지는 않는다.

상단 소리 버튼 하나로 음악·효과음을 함께 켜고 끈다. 첫 사용자 입력 후 재생하며, 앱이 뒤로 가거나 전투가 일시정지되면 정지한다. BGM은 오디오 요소 1개로 재생해 18곡 전체를 메모리에 풀지 않는다. 효과음은 필요할 때 로드한 버퍼를 재사용하고 동시 10개까지 재생한다. 로딩 완료 후 지난 동작을 늦게 재생하지 않는다. 기존 합성음은 파일 로딩·실패 시 대체 용도로만 유지한다.

## 담당 파일

- `src/audio-catalog.js`: 음악 구간·효과음 ID·음량·최소 간격.
- `src/audio.js`: 홈·상점·전투가 호출하는 공통 창구.
- `src/music-player.js`: 음악 전환·첫 입력·일시정지·음량.
- `src/sound-player.js`: 효과음 캐시·동시 음수·노드 정리.
- `src/audio-synth.js`: 기존 합성 효과음 대체 수단.
- `src/battle-audio-events.js`: 같은 시각에 생긴 출격·공격도 정확히 한 번 처리.
- `tools/audio-plan.mjs`: 생성 프롬프트와 제작 목록.
- `tools/audio-source.mjs`: 새 제작 버전의 원본 선택과 가공 캐시 판정. 새 원본이 있으면 같은 파일명이어도 다시 가공한다.
- `public/audio/manifest.json`: 출처·선택 결과·길이·해시.

## 원본을 다시 가공할 때

`private-audio/`에 원본 `.source`와 `sources.json`이 있을 때만 사용한다. FFmpeg는 개발용 외부 실행 도구이며 게임에 포함하지 않는다.

```powershell
node tools/audio-process.mjs 'C:/path/to/ffmpeg.exe'
npm run audio:verify
```

가공기는 이미 같은 해시로 처리한 파일을 건너뛰므로 중단 후 이어서 실행할 수 있다. 추가 생성·유료 호출을 하지 않는다. 실제 청취·저가 안드로이드·잠금/복귀·블루투스 전환 테스트는 별도로 해야 한다. 권리 관련 조건은 [AUDIO_RIGHTS.md](AUDIO_RIGHTS.md)를 참고한다.
