# 전투 화면 개편 계획서 · 스테이지 A + 편성 A (0.76.42 기준)

작성: Claude(2026-10-19). **이 문서는 계획서이며 아직 실제 게임 화면을 바꾸지 않았다.** 사용자가 승인하기 전에는 전투·지도·편성 코드를 수정하지 않는다.

## 1. 한 줄 요약

시안에서 고른 두 가지를 실제 게임에 넣는다.

- **스테이지 A · 진격 경로 지도**: 지금의 "대륙→국가→지역 지도(끌기·확대)" 대신, 번호가 한 줄로 이어진 경로를 따라가며 고르는 화면.
- **편성 A · 카드 덱**: 출전 장비를 "위에는 선택한 칸, 아래에는 보유 카드" 화면에서 누르는 방식.

은행 비유: 지금은 큰 지도를 펴 놓고 손가락으로 끌며 지점을 찾는 방식이고, 바뀌는 방식은 번호표가 순서대로 놓인 한 줄 안내판을 따라가는 방식이다.

## 3. 새 화면의 모양

### 스테이지 A (시안 기준)
- 위쪽: 대륙 탭(아스테라 / 에테리온 / 에레보스), 진행 `23 / 80`.
- 가운데: 번호가 구불구불 한 줄로 이어진 경로. 완료(체크), 현재 도전(큰 표시), 잠금(자물쇠). 현재 번호 주변을 먼저 보여 주고, 멀리 가려면 구간 단위로 넘긴다.
- 아래 고정: 선택한 스테이지 이름, 권장 계급·장비 +N, 보상, "출전 장비 선택" 버튼.

### 편성 A (시안 기준)
- 위쪽: "내 출전 장비 N / 칸수", 선택한 칸이 슬롯으로 나란히 표시(누르면 해제).
- 아래: 보유 카드 목록(그림·이름·마나·강화). 누르면 추가/해제.
- 아래 고정: 평균 마나, "이 편성으로 출전" 버튼. 하나도 고르지 않으면 버튼 비활성.
- 흐름: **스테이지 고르기 → 편성 화면 → 전투**(지금은 두 단계가 한 화면).
