# 상점 시각·구매 흐름 검토 · 0.76.22

2026-10-15. 이번 변경은 상품 조건이나 구매 처리 변경이 아닌 표현/배치 개선이다.

## 적용
- 핵심 순서: 알아볼 수 있는 그림 → 상품명/구성 → 정확한 가격 버튼. 상세 제약과 복원은 접힌 안내에서 열 수 있다.
- 스타터팩은 하나의 대표 광고로, 자동터치는 짧은 목록으로 구분한다. 리본은 특별혜택!, 1회 구매 표기는 별도로 유지한다. 계정당 지급 보장이나 가짜 할인/판매량/마감은 표시하지 않는다.
- 실제 Play 응답 가격만 활성 버튼에 사용한다. 원화 기호를 금액 뒤로 옮기며 외화는 그대로 표시한다. 버튼의 접근성 이름에는 상품명·가격·구매를 포함한다. 가격을 못 읽으면 비활성화한다.
- 먹청색 #17262e, 표면 #243a45, 아이보리 #f2ede0, 구매 황동 #e2bc69. 빨간 리본은 작은 영역에만 사용한다. 상품 자체 색상이 묻히지 않도록 배경 장식을 줄인다.
- 한글 제목은 Black Han Sans, 본문/가격은 가독성을 위해 기존 시스템 폰트. 공식 원본/OFL 및 앱 고지: FONT_ASSETS.md.
- 가격 버튼 최소44px. 자동터치 한 줄 상품 줄64px, 구매 안내 포함99px. 불필요한 상시 설명은 접고 핵심 구매/소유 상태를 유지한다.

## 확인한 연구·공식 지침
- NN/g의 상품 페이지 연구: 상품명, 알아볼 수 있는 이미지, 가격, 명확한 구매 수단과 간결한 설명이 핵심이라는 결과를 참고했다.
  https://www.nngroup.com/articles/ecommerce-product-pages/
- Material typography의 제목·본문·레이블 역할 구분을 참고했다.
  https://m3.material.io/styles/typography/applying-type
- W3C 일반 텍스트 대비4.5:1, 큰 텍스트3:1 기준을 기준 삼는다. 모든 실제 화면·장애 유형에 대한 접근성 인증을 했다는 뜻은 아니다.
  https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum.html
- 대표 불투명 색 조합의 sRGB 상대휘도로 계산: 가격 글자/버튼 가장 어두운 부분7.77:1, 본문/자동터치 표면10.17:1, 상세 글자/표면7.10:1, 리본 글자/밝은 쪽 배경4.96:1. 실제 모든 화면을 전수 검사한 결과와는 구분한다.
- 광고가 실제 구매율을 올렸는지는 아직 사용자 실험/지표로 확인하지 않았다. 특정 색/문구가 뇌과학적으로 구매를 보장한다고 주장하지 않는다.

## 다음 UX 제안
1. 홈7개 메뉴: 동일한 먹청색 계열에 선택 상태만 밝게, 구매 강조색은 상점/가격에 제한. 아이콘 크기와 라벨 기준선을 통일한다.
2. 상품 상세 첫 화면: 상품 구성과 영구/소모 차이는 짧게, 재설치·복원 한계는 펼침 안내와 결제 전 흐름에서 찾을 수 있게 유지한다.
3. 구매/취소/대기/보유 상태 피드백을 일관되게 유지하고, 실제 Play 설치 앱에서 조회가격→결제창가격→보유표시를 확인한다. 이번에는 실제 결제하지 않았다.
