
## 0.76.29 진급 진행률 색상

- UI 브랜치에서 현재 갱신 경로와 테마 우선순위 확인 후 적용. 경계 및 진급 후 색상 복귀 테스트 추가. 전체 테스트·빌드 검증 진행 중.

- 전체 npm test 833/833 통과(175.13초), npm run build 성공. 기존 고지 청크 크기 경고 유지. 브라우저에서 실제 62% 게이지의 주황 그라데이션 적용 직접 확인. 화면 닫기 시도는 사용자가 화면을 전환해 대상 없음으로 끝났으며 저장 변경 없이 DOM 읽기로 확인. 실기기 미확인. 정책 영향 없음.
- 사용자 기록·서버·정책·약관 변경 없음. UI 브랜치에 커밋 및 푸시 예정.
