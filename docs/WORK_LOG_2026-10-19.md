## 0.76.32 설정·게임 정보 정리

설정은 소리·게임·이용 안내로 묶고 게임 정보는 버전·저장 상태·문의 진입 중심으로 정리. 오류 기록·실행 환경·저장 형식·문의용 복사는 별도 상세보기로 이동. 저장 장애 안내는 첫 화면에 유지. 팝업 제목 고정, 본문 스크롤 가능·막대만 숨김. 복사 중 닫기/화면 이동 비동기 오류 방지. 저장42·방침12·약관9·서버 불변.
- 검증 완료: 전체 npm test 851/851 통과(191.50초), npm run build 성공. 기존 라이선스 고지 청크 크기 경고만 유지.
- 직접 확인: 별도 미리보기 390×780 설정·320×520 정보 화면, 소리 조절 50→51%, 광고/약관 하위 메뉴·방침 원문 복귀·게임 안내·라이선스 연결. 캡처 docs/ui/0.76.32/settings-info.jpg. 실제 게임 저장 사용/변경 없음.
- 재현/수정: 문의 복사 도중 화면 이동·닫기 시 이전 요소를 조작하는 문제와 정보 첫 화면의 불필요한 오류 기록 읽기를 먼저 재현(3개 실패), 수정 후 관련24개 통과 및 전체851개 통과. 오류 상세 원문 이스케이프·저장 경고·재시도 유지.
