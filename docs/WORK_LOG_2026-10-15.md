## 공개 방침·Play 데이터 보안 동기화 · 2026-10-15

- 사용자 신규 승인: Codex가 Chrome에서 공개 정책과 Play 데이터 보안을 직접 반영. 과거의 '공개 문서는 사용자가 게시' 제한은 이번 요청 범위에서 해제됨.
- 기존 Google Docs 원본을 내보내 로컬 백업한 뒤 승인된 개인정보처리방침 개정12(2026-10-14) 전체 문안으로 갱신. 기존 웹 게시 및 자동 재게시 설정 유지, 주소/공유 권한 변경 없음. 공개 페이지에서 모든 본문을 공백·목록 표식 정규화 후 저장소 문안과 대조하여 일치 확인.
- Play 데이터 보안: 기존 광고 4종(대략적 위치, 앱 상호작용, 진단, 기기 또는 기타 ID)의 수집/공유, 선택적 처리, 분석·광고·부정행위 방지 목적을 직접 확인하여 유지.
- 구매 내역 추가: 수집됨, 비임시, 선택적, 앱 기능 및 사기 예방/보안/규정 준수. 앱은 Play 구매 결과를 받아 지급/복원을 판단하고 구매 토큰을 Play 전달 확인 호출에 사용한다. 게임 서버 저장과는 구분한다. Google 결제창과 사용자가 요청한 구매/복원에 한정된 전송은 공식 사용자 주도 전송 예외에 따라 별도 공유 항목을 선택하지 않음. Play 외 분석/광고에 구매 내역을 보내지 않는다.
- 카드번호 등 사용자 결제 정보는 앱이 접근하지 않는 Google Play 직접 결제 정보이므로 추가하지 않음. 이름/이메일/UID/게임 진행의 서버 수집도 추가하지 않음. 정확한 나이와 게임 진행의 기기 내 처리만으로 외부 수집을 신고하지 않음.
- 삭제 요청 방편을 '예'로 갱신하고 기존 공개 방침 URL 연결. 방침의 문의/권리 요청, 기기 삭제, Google 정보 처리 안내를 근거로 함. Google 구매 기록을 운영자가 직접 삭제하거나 앱 삭제로 자동 환불한다고 약속하지 않음. 계정 생성·로그인 없음 및 전송 암호화 답은 유지.
- 데이터 보안 1건만 저장/검토 전송 요청. 게시 개요에 '검토 중인 변경사항' 및 빠른 검사 실행 중 표시. Google 검사·심사 승인 및 실제 스토어 표시 완료는 미확인. 다른 출시/스토어 변경 제출 없음.
- CSV 내보내기 시도는 브라우저 다운로드 대기 시간 초과로 백업 확인 못 함. 재접속 후 화면 답변을 직접 검토. Google 문서 변경 전 백업은 확보함.
- 앱/AAB/서버 코드, 버전0.76.18, 저장42, 방침12/약관9 유지. 별도 공개 이용약관 페이지는 이번에 만들지 않음; 약관9는 기존 앱/저장소 상태 유지.
- 위험/되돌림: 공개 방침은 Google Docs 버전 기록 또는 이전 내보내기 문서로 복원할 수 있음. 콘솔 신고 정정은 사실에 맞춰 다시 제출하며, 구매 기능이 존재하는데 구매 내역을 임의로 숨기지 않음.
- 미확인: 실제 결제·환불/복원, 네트워크 패킷 전수 감사, Google 심사 완료. 외부 SDK 내부 모든 처리나 법률상 완전한 적합성을 보증하지 않음.
- 정책 동기화: 공개 개인정보처리방침 완료, Play 데이터 보안 검토 전송 요청 완료/Google 검사 및 심사 대기.
