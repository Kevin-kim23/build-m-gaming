# Play 결제 AAB · 0.76.18

2026-10-14 사용자 승인: 실제 판매용 연결과 AAB 생성, 자동터치4,900원/스타터팩 기존5,900원 구성, 스타터팩 재설치·다른 기기 재지급 가능성 수용. 최종 문안 승인 후 방침12·약관9 반영. 실제 구매 시험 전 판매 준비 완료로 표시하지 않는다.

## 앱 설정

- 패키지 `com.dongramco.budaekiugi`, versionCode76018. 광고는 요청대로 Google 샘플 ID 유지. 서버/로그인/랭킹 추가 없음.
- 두 상품 ID: `auto_tap_permanent`, `starter_pack_once`. 각각 별도 일회성 INAPP 구매 옵션1개로 등록. 스타터팩은 consume하지 않는 일회성 상품이며 사용한 부스터를 자동 충전하지 않는다.
- 자동터치 영구 해금4,900원. 스타터팩5,900원은 빨강30·파랑30·금빛10이며 자동터치 미포함. 실제 화면 가격은 Play 반환 값을 사용.
- `-PplayBillingRelease=true`를 명시할 때만 release에 Billing8.3.0과 플러그인을 포함. 로컬 설정3항목이 없거나 ID가 같으면 빌드 거부. 공개키 RSA 형식은 값 출력 없이 확인. 로컬 설정/서명/원본 음악은 Git 제외.
- 기존 업로드 키로 서명하며 새 키 생성/교체 없음. 승인 음악4곡을 기존 로컬 사본에서 해시 검증 후 새 작업 폴더에 복원. 서버 브랜치 파일 변경 없음.
- SDK 최종 release 의존성93개를 고지에 반영. XML namespace 없는 javax.inject POM은 namespace를 정규화해 원문 라이선스를 읽도록 고침. 임의 라이선스 추정/고지 삭제 없음.

## 콘솔에서 확인할 위치

1. 부대 키우기 → 테스트 및 출시 → 테스트 → 내부 테스트 → 새 버전 만들기 → App Bundle 업로드. AAB 파일을 넣고 버전76018/패키지/권한을 확인한다. 이 문서 작성 시 업로드하지 않았음.
2. 테스트 및 출시 → 최신 버전 및 번들: 업로드한 파일을 확인하는 곳. 현재 화면에서는 최신76000/0.76.0만 확인.
3. Play를 통한 수익 창출 → 제품 → 일회성 제품: 위2개 상품 ID로 등록하고 구매 옵션/대한민국 가격·판매 가능 지역을 확인. 현재 화면은 '결제 권한 포함 앱 먼저 업로드' 안내로 상품 등록이 막혀 있음.
4. 라이선스 테스터 설정 및 내부 테스트 설치. 구매창에 테스트 결제수단이 표시되는지 확인한 뒤 성공/취소/대기/복원/환불·스타터팩 저장 실패와 재확인 시험. 테스트 결제수단이 아니면 중단. 실제 카드 결제는 이 작업에서 실행하지 않는다.
5. 공개 정책·스토어 정보·지급수단·판매자 정보와 프로덕션 액세스를 확인한 후 출시. AAB 파일 생성이 상품 활성화나 판매 개시를 뜻하지 않는다.

## 정책과 데이터 안전

앱과 생성 문서에는 승인한 결제 문안 적용. Google 공개 문서/Play 양식은 미수정. 게시용 문서는 `docs/store/PRIVACY_POLICY.md`, `docs/store/SERVICE_TERMS.md`.

과거 작업보고의 '방침11·약관8 유지'는 서버 브랜치 값과 혼동한 기록이다. 실제 UI 코드 이전 값은7/4였음. 이번에는 사용자가 명시적으로12/9 승인했으며 재동의가 발생한다.

Billing 사용이 카드번호를 앱에서 직접 수집한다는 뜻은 아니다. 구매 토큰·서명은 기기에서 검증하고 게임 저장/문의용 로그/개발자 서버에 기록·전송하지 않는다. 상품 상태 확인/전달 확인은 Google Play와 통신한다. 구매 이력 처리와 SDK 진단을 별도로 검토해 데이터 보안 양식에 반영해야 한다. 광고 SDK의 기존 정보 처리 안내를 제거하지 않는다. 계정 전체 중복 지급 방지·즉시 환불 통지는 서버 없이 보장하지 않는다.

공식 참고: [제품 등록](https://support.google.com/googleplay/android-developer/answer/1153481), [결제 시험](https://developer.android.com/google/play/billing/test), [SDK 데이터 공개](https://developers.google.com/android/guides/play-data-disclosure), [결제 보안](https://developer.android.com/google/play/billing/security).
