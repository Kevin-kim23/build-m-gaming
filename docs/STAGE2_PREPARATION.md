# 2단계 준비 · 0.81.0 (2026-10-12)

이 문서는 코드와 로컬 검증을 준비한 기록이다. 개발·운영 Firebase 배포, Blaze 전환, 예산 알림, IAM, App Check/Play Integrity 콘솔 설정은 변경하지 않았다. 최종 AAB 생성과 Play 업로드도 진행하지 않는다. 아래 설정 후보를 실제 서버에 적용하려면 비용 보고 후 사용자의 별도 승인이 필요하다.

## 사용자 결정

- **기기 백업은 최대 10개**다. 구버전 단일 백업도 포함하며, 이미 상한을 넘은 백업은 보존한다. 자동 삭제하지 않고, 이용자가 확인한 백업만 개별 삭제한다. 현재 진행 중인 저장은 지우지 않는다.
- **신고는 신고자별 한국 시간 하루 5건**이다. 같은 대상의 닉네임이 바뀌기 전에는 사유와 무관하게 1회만 접수한다. 기존 계정별 분당 변경 10회 제한도 함께 적용한다.
- **사용자 본인만 비공개 관리자 도구로 신고를 검토**한다. 이번 조치는 경고와 강제 기본 닉네임 부여다. 자동 제재, 랭킹 제외, 계정 정지는 이번 범위에 포함하지 않는다.
- 이의제기는 기존 앱 문의 이메일로 받는다. 일반 닉네임 변경권은 아직 미정이며, 이번 강제 변경 절차로 일반 변경권을 만들지 않는다.
- 신고 원문과 처리·복원 기록은 **처리 완료 후 90일** 보관한다. 미처리 신고는 검토가 끝날 때까지 유지한다. 원문을 삭제한 뒤에도 최소 중복 방지 값은 닉네임 변경 또는 신고자·대상 중 한 계정의 탈퇴까지 유지한다. 이 별도 보관 기준은 추가 설문에서 승인받았다.
- **삭제 재시도는 6시간마다, 만료 정리는 하루 1번**이다. 예약 함수는 코드만 준비하며 실제 배포·실행은 하지 않았다.
- **월 비용 계획 상한은 20만 원**, 예산 알림 기준은 5만·10만·15만·20만 원이다. 이는 실제 설정 승인이 아니며, 예산 알림만으로 지출이 차단되지는 않는다.
- 삭제 완료 확인 기록 90일, 방침 11·약관 8, 테스트 광고 ID, 저장 형식 38, 기존 저장 키와 큰 금액 처리를 유지한다.
