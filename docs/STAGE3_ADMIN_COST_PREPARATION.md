## 파트A 진행 조건

- 사용자가 콘솔에서 한 단계씩 직접 진행한다. 매 단계 프로젝트 확인 요청 후 화면을 확인한다. 현재 화면을 아직 받지 않았으므로 버튼 위치를 추정하지 않는다. 다음 한 동작은 **민감 정보를 가린 현재 개발 콘솔 화면 확인**이다.
- 사용자 이메일, 서비스 계정 숫자 고유 ID, 토큰/키, 결제계정 번호, 예산 ID를 화면에서 가리고 공유한다. 실제 값은 기록하지 않는다.
- 호출 계정에는 프로젝트 전체 Owner/Editor/Firestore 권한을 부여하지 않는다. 사용자의 Service Account Token Creator(임시 인증 발급 권한)는 호출 계정 하나에만 적용한다.
- 실행 계정은 Firestore(DB) 작업에 필요한 권한만 검토한다. 서버 DB 권한을 컬렉션별 보안 규칙으로 제한된다고 오해하지 않는다. Auth 계정 삭제 권한은 부여하지 않는다.
- 호출 계정 Cloud Run Invoker(함수 호출 권한)는 실제 관리자 서비스 배포 후 그 자원에만 준다. allUsers/allAuthenticatedUsers에 관리자 권한을 주지 않는다.
- 두 계정 모두 키 생성/다운로드 금지. API 사용 설정은 상태 확인 후 필요할 때 사용자 승인·사용자 직접 진행이다.
- 로컬 설정 파일은 아직 변경하지 않았다. server/.env.<프로젝트ID> 등에 값을 넣기 전에 파일 위치·값의 종류·Git 제외 확인을 설명하고 별도 승인받는다. 숫자 ID 등을 예제에도 실제 값으로 쓰지 않는다.
- 프로젝트 불일치·키 요구·프로젝트 전체 권한 요구·예상 밖 비용·이해 못 한 단계면 중단한다. 잘못 부여한 권한은 정확한 대상 권한만 제거하는 계획을 먼저 검토하며, 계정 삭제로 임의 복구하지 않는다.

### PASS 체크리스트 — 전부 미확인

1. 호출 계정과 실행 계정이 별개로 존재한다: 미확인.
2. 두 계정 키 탭이 비어 있다: 미확인.
3. 사용자 대리 인증 권한이 호출 계정 하나에만 있다: 미확인.
4. 실행 계정에 필요한 Firestore 권한만 있고 Auth 삭제 권한이 없다: 미확인.

## 파트B 검토 및 보류

운영도 월 한도 초과 시 중단·다음 청구 월 복구한다는 방향은 승인됐다. **운영 한도 금액은 아직 미정**이다. 사용자에게 금액을 확인하기 전 운영용 코딩하지 않는다. 개발/운영 각각10만원·합산20만원으로 가정하지 않는다. 운영 콘솔·예산 생성·배포는 별도 승인 대상이다.

현재 policy.js뿐 아니라 index.js의 실행 계정, 설정 검사·읽기 도구도 개발 전용이다. 단순히 프로젝트 이름만 바꾸면 개발 대상과 운영 통지/권한이 섞이거나 운영을 거부할 수 있으므로 함께 검증해야 한다.

일반화 설계 검토: 허용 목록은 개발/운영 두 프로젝트만, 승인된 한도는 프로젝트별 코드 정의와 실제 예산을 대조한다. 주제·실행 계정·예산·로컬 환경 파일·DB 연결·복구 상태를 프로젝트별 분리한다. 통지가 임의의 프로젝트/자원을 선택하게 하지 않는다. 운영 enforce는 환경 파일만으로 켤 수 없도록 별도 승인 전 차단한다. 금액 확정 뒤 기존 개발 회귀 검사에 프로젝트 혼동·금액 불일치·개발 통지의 운영 중단 거부 검사를 추가한다. 아직 구현/검증한 운영 지원이 아니다.

운영 절차 문서화의 남은 항목: 사용자 직접 단계, 실제 알림 도착 확인, 중단 시 서버 저장/복구/관리/삭제 예약 불가 범위, 문의 이메일을 통한 삭제 접수와 권한 있는 담당자의 수동 처리·완료 확인, 기록 보존 비용과 청구 지연, 개발+운영 승인 한도 합계. 실제로 멈추지 않는 기능까지 중단된다고 쓰지 않는다. 방침 초안·스토어 안내의 반영 항목을 정리하되 방침11·약관8 번호는 올리지 않는다.

공식 검토 자료: [임시 인증 권한](https://docs.cloud.google.com/iam/docs/service-account-permissions), [Firestore IAM](https://docs.cloud.google.com/firestore/native/docs/security/iam), [임시 인증 발급 사전 조건](https://docs.cloud.google.com/iam/docs/create-short-lived-credentials-direct). 공식 안내 확인은 실제 콘솔 권한 검증을 대신하지 않는다.

이번 변경은 승인·절차·검증 기록뿐이며 게임/설정/콘솔/배포는 바꾸지 않았다. 기존 공개 정책 동기화 미완료는 별도 유지한다. 정책 영향 없음.
