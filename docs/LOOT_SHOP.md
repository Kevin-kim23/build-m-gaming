# 전리품 상점 · 0.76.33

## 사용자 결정과 범위

전투 승리의 즉시 골드 보상을 전리품으로 교체한다. 지역 점령의 영구 초당 수입, 별 기록, 전투 진행은 유지한다. 이미 깬 지역의 첫 승리 전리품은 저장 형식 43으로 이전할 때 한 번 보충한다. 기존 골드를 회수하지 않는다. 서버·현금 거래·확률 뽑기·대원 레벨은 추가하지 않는다.

## 대원 5명

| 대원 | 전리품 가격 | 효과 |
| --- | ---: | --- |
| 당직병 | 300 | 홈에서 자동터치 초당 1회 추가. 켜기/끄기 가능 |
| 정찰병 | 900 | 영입 후 24시간마다 초당 부스터 1개 |
| 보급장교 | 900 | 영입 후 24시간마다 터치 부스터 1개 |
| 병참관 | 2,400 | 오프라인 수입 보관 상한 8시간 → 12시간 |
| 특수공작원 | 6,000 | 영입 후 72시간마다 맥스 부스터 1개 |

종류별 1명 영구 보유. 당직병은 기존 유료 자동터치 10회/초와 합산해 11회/초가 되며 손가락 입력·수동 터치 통계를 바꾸지 않는다. 팝업/전투/백그라운드에서는 멈추고 누락 시간을 몰아서 지급하지 않는다.

보급은 대원 영입 시각을 기준으로 계산한다. 앱 종료 중에도 시간이 흐르고, 대원별 최대 3회분을 보관한다. 사용자가 받기를 눌러 아이템에 넣으며 자동 사용하지 않는다. 수령 시 다음 생산 시각을 새로 미루지 않는다. 아이템 가방이 가득 찼으면 보급을 보존하며, 일부만 받을 수 있으면 남은 보급을 보존한다. 장기 미접속에서 3회분을 초과한 생산은 버린다.

## 보상·초기 가격 근거

- 첫 승리: `100 + (지역 번호 - 1) × 5`. 20의 배수인 수도는 3배.
- 재전투: 첫 승리 전리품의 20%, 한국시간 하루 합산 10회. 기존 하루 제한을 유지한다.
- 별은 기록용이며 보상 배율에 영향을 주지 않는다. 골드 보유량·초당 수입·현금 상품으로 전리품을 늘리지 않는다.
- 1~3지역 첫 승리 합계 315개로 당직병을 얻을 수 있다. 1~20지역 합계 3,340개로 당직병과 24시간 보급 대원 두 명을 영입할 수 있다.
- 전리품 지갑 상한 10억, 안전한 정수 범위에서만 계산한다. 골드의 기존 큰 정수 계산은 유지한다.
- 아직 실제 장기 플레이 밸런스 검증은 하지 않았다. 가격/주기/능력은 `src/loot.js` 한 곳에서 관리한다.

## 홈 배치

첫째 줄: 군대 모집 / 군사 장비 / 상점

둘째 줄: 시설 / 개인 장비 / 아이템

마지막 줄: 전리품 상점 / 전투

0.76.34부터 보유 전리품은 상점 내부 지갑에만 표시한다. 홈에는 상점 이름과 아이콘, 보급 준비 시 작은 점만 표시한다. 전리품 상점과 전투 버튼은 같은 크기다. 대원은 별도 상점 카드에서 보여 주고 연병장 공간을 더 줄이지 않는다. 상점은 제목/보유량/닫기를 고정하고 카드만 스크롤한다. 기존 게임 창 높이 제한과 320px 화면에 대응한다.

## 구현과 저장

- `loot.js`: 보상, 대원 구매, 보급, 검증. `operative-art.js`: 자체 픽셀 도형 캐시. `loot-ui.js`/`loot.css`: 상점과 홈 표시.
- 기존 `battle-progress.js`에서 보상 종류만 전환. 기존 자동터치 루프를 재사용하며 새 타이머를 추가하지 않음.
- 저장 키 유지, 저장 형식 43. 42 이하의 유효한 기록은 누적 클리어 수로 첫 보상을 보충하고 43부터 재보충하지 않는다. 대원·보급 시각·수령 잔여량을 함께 저장한다.
- 병참관 영입 전에 기존 수입을 정산하여 과거 버려진 4시간을 소급 지급하지 않는다. 복귀 팝업도 실제 8/12시간 상한을 표시한다.
- 저장 실패 때 메모리 상태를 유지하는 기존 세션 흐름을 재사용한다. 재시도/재접속 중복 지급을 테스트했다.
- 기기 시계 역행은 저장 시각을 하한으로 처리한다. 서버 없는 게임이므로 미래 시계 조작을 완전히 막는 기능은 아니다.
- 되돌림: 코드 커밋 되돌리기는 가능하지만 저장 43을 이전 앱에서 읽을 수 있다고 보장하지 않는다. 실제 기록을 삭제하거나 예전 버전으로 강제 덮어쓰지 말고 필요한 경우 역변환을 별도 설계한다.

## 출시 전 정책·상품 설명 동기화 목록

1. 전투 즉시 골드 보상 → 전리품, 점령 초당 수입은 유지된다는 소개·도움말 정합성.
2. 오프라인 최대 8시간 안내에 병참관 보유 시 12시간 예외 추가.
3. 맥스 부스터가 스타터팩 전용이라고 표현된 곳은 특수공작원 보급도 가능함을 안내. 게임 아이템 화면의 획득 경로는 이번에 수정했다.
4. 유료 자동터치 10회/초와 무료 당직병 +1회/초를 구분. 기존 콘솔 상품 설명 5회/초 불일치는 이전 출시 점검 항목으로 여전히 남는다.
5. 전리품은 전투로만 획득하고 현금·골드로 교환하지 않으며, 대원은 원하는 종류를 확정 영입한다. 새로운 결제·개인정보 전송·외부 SDK 없음.
6. 새 그림은 직접 작성한 도형이며 외부 폰트/그림/보호 표장을 추가하지 않았다. 법적 무위험 보장은 하지 않는다.

정책 원문·공개 게시본·콘솔은 수정하지 않았다. 방침 12/약관 9 유지. 출시 전 사용자에게 위 변경과 기존 출시 점검 미완료 항목을 다시 안내한다.
