# 시설과 지휘 사관학교 · 0.67.0

실제 수치의 기준 파일은 `src/facility-catalog.js`, `src/late-facilities.js`, `src/command-officers.js`입니다. 사용자 승인을 받은 학교 시작 계급은 준원수입니다.

## 학교와 모집

고급 사관학교는 사관학교 Lv.5와 대장이 필요합니다. 이제 Lv.1~5 모두 대장에서 골드로 확장할 수 있습니다. 건설·확장비와 기존 병종 능력은 유지합니다. 지휘 사관학교는 고급 사관학교 Lv.5 이후 건설합니다.

| 지휘 학교 | 필요 계급 / 해금 병종 | 건설·확장비 | 1명 전력 | 기본 초당 / 터치 | 첫 1명 가격 | 100명 모집 지휘봉 |
|---|---|---:|---:|---|---:|---|
| Lv.1 | 준원수 | 1경 | 655,360 | 9억 / 60억 | 200조 | Lv.16 |
| Lv.2 | 소원수 | 4경 | 1,310,720 | 27억 / 180억 | 800조 | Lv.17 |
| Lv.3 | 중원수 | 16경 | 2,621,440 | 81억 / 540억 | 3,200조 | Lv.18 |
| Lv.4 | 대원수 | 64경 | 5,242,880 | 243억 / 1,620억 | 1경 2,800조 | Lv.19 |
| Lv.5 | 특전원수 | 256경 | 10,485,760 | 729억 / 4,860억 | 5경 1,200조 | Lv.20 |

모집 가격은 해당 병종의 기존 인원만 사용합니다. 첫 가격을 B, 보유 인원을 n이라 할 때 `B + (B×8/1000)×n + (B/10000)×n²`입니다. 상한을 넘는 1명 가격은 기존 모집 규칙대로 1,000경으로 제한합니다. 100명 가격은 각 1명 가격 100개의 정확한 합계이며 합계가 지갑 상한을 넘으면 구매할 수 없습니다. 지휘봉 Lv.16~20 할인은 원수 모집 능력으로 대체됩니다. 강화한 레벨과 Lv.1~15 기능은 유지합니다.

## 시설

기존 10종의 Lv.1 보너스는 3→5%, 2→3%, 5→8%로 상향했습니다. 건설·강화비는 유지합니다. 모든 시설은 Lv.20까지이며, 레벨당 기본 보너스의 20%를 추가합니다. 예: 취사장 Lv.1 +5%, Lv.2 +6%, Lv.20 +24%. 서로 다른 시설의 보너스는 합산하고, 다른 종류의 효과와는 기존 순서대로 곱합니다. 전투 공격력에는 적용하지 않습니다.

| 새 시설 | 해금 계급 | 건설비 | Lv.1 초당 / 터치 |
|---|---|---:|---|
| 국방연구소 | 소장 | 200억 | +8% / +5% |
| 통합군수센터 | 중장 | 800억 | +12% / — |
| 합동훈련센터 | 대장 | 3,500억 | — / +15% |
| 전략정보원 | 준원수 | 1조 5,000억 | +10% / +10% |
| 우주항 | 소원수 | 6조 | +16% / +5% |
| 궤도관제센터 | 중원수 | 24조 | +8% / +18% |
| 융합발전소 | 대원수 | 96조 | +24% / — |
| 성간보급기지 | 특전원수 | 384조 | +12% / +24% |
| 은하통합지휘소 | 부사령관 | 1,200조 | +20% / +20% |

신규 시설의 첫 강화비는 건설비의 1.5배, 이후 단계마다 1.5배입니다. 기존 시설은 첫 강화비 1.5배, 이후 2.5배를 유지합니다. 비용은 정확한 정수 연산 후 1,000G 단위로 올림합니다. 새 시설은 각 단계 비용뿐 아니라 1종의 건설~Lv.20 총 비용도 지갑 상한 안에 들어갑니다. 19종 모두 Lv.20이면 시설 합계는 초당 +720%, 터치 +619.2%입니다.

## 계급·그림·연병장

- 은하사령부 4개 = 은하단 사령부 1개, 전력 1,342,177,280에서 부사령관. 기존 일반병 5,000명·하사 300명 조건도 유지합니다. 은하단 사령관 훈장은 자동 지급합니다.
- 최대 전력은 은하단 사령부 4개인 5,368,709,120으로 확장합니다. 골드 상한은 1,000경을 유지합니다.
- 소원수~부사령관은 같은 사파이어 배경이며 백색 별 1~5개로 구분합니다. 사단~집단군은 현대 콘크리트·유리 외벽으로, 은하단 사령부는 큰 성채와 위성 타워로 차별화했습니다.
- 부대 → 학교 → 시설 → 장비 순서를 유지합니다. 가로는 화면 1.5배 이하에서 공간을 쓰고, 더 많은 건물은 아래 행에 추가합니다. 이름표 최소 폭과 큰 본부를 유지합니다.
- 모든 새 그림은 직접 작성한 도형입니다. 외부 이미지·상표·SDK·수집·과금 요소를 추가하지 않았습니다.
