# 시설과 가로 연병장 · 0.58.0

시설은 상점 → 시설에서 종류별 한 번 건설한다. 상사부터 준장까지 실제 계급을 기준으로 해금하며, 바로 이전 계급에서 잠금 미리보기가 보인다. 군사학교와 별개이고 전력/전투 공격력은 올리지 않는다.

| 해금 계급 | 시설 | 건설 골드 | 초당 보너스 | 터치 보너스 |
|---|---|---:|---:|---:|
| 상사 | 취사장 | 12만 | +3% | — |
| 원사 | 체력단련장 | 30만 | — | +3% |
| 준위 | 풋살장 | 80만 | +2% | +2% |
| 소위 | 사지방 | 200만 | — | +3% |
| 중위 | 의무실 | 500만 | +3% | — |
| 대위 | 사격장 | 1,200만 | — | +5% |
| 소령 | 정비고 | 3,500만 | +5% | — |
| 중령 | 보급창고 | 1억 | +5% | — |
| 대령 | 통신소 | 3억 5,000만 | +2% | +2% |
| 준장 | 작전지원센터 | 15억 | +5% | +5% |

- 같은 수입의 시설 보너스는 합산: 모두 Lv.1로 건설하면 초당 +25%, 터치 +20%. 시설끼리 곱하지 않는다.
- 초당: 병력+배치 장비의 기본 수입 → 시설 → 점령 → 언월도 순서. 터치: 기본 터치 → 시설 → 장군검 순서. 각 비율 연산은 정수 골드 아래를 버린다.
- 자동 터치도 같은 기본 터치 수입을 사용한다. 오프라인 최대 8시간과 보상 한 번 받기 규칙은 그대로다.
- 건설 직전 시간은 이전 수입으로 먼저 정산한다. 중복 구매와 부족한 골드 요청은 시설을 추가하지 않는다.
- 정의는 src/facility-catalog.js 한 곳. 규칙은 facilities.js, 구매 동작은 game.js, 화면은 facility-panels.js, 자체 제작 그림은 facility-art.js. 건설 때 소유 배열, 강화 때 레벨 객체를 새 객체로 교체해 보너스 캐시를 무효화한다.

## 시설 강화

- 종류별 1개, 건설 상태 Lv.1부터 최대 Lv.20까지 골드로 확정 강화. 개인 장비도 0.66부터 확정 강화이며 최대 Lv.20입니다.
- Lv.L 효과 = 기존 효과 × (100 + 15 × (L−1)) / 100. Lv.20은 3.85배. 작은 증가량을 버리지 않도록 내부 백분율은 1/100% 정수 단위로 합산한다.
- 전체 Lv.20 합계: 초당 +96.25%, 터치 +77%. 풋살장은 각각 +2% → +7.7%.
- 현재 Lv.L의 다음 강화비 = 건설비 × 1.5 × 2.5^(L−1), 1,000G 단위 올림. BigInt 유리수 계산으로 부동소수 오차를 피한다.
- 풋살장 Lv.2 비용120만, Lv.10 비용18억3,105만5,000, Lv.20 비용17조4,622억9,827만5,000G. 가장 비싼 작전지원센터 Lv.20 비용3경2,741조8,092억6,382만6,000G.
- 전체10종 건설+Lv.20 누적비72,949,478,635,642,000G. 최대소지골드1,000경 범위 이내다.
- 매단계 그림에 조경·장식이 추가되고 Lv.5/10/15/20에 증축한다. 풋살장은 관중석·조명·캐노피·지붕/VIP석/전광판 경기장으로 발전한다. 실제 구단 이름이나 문장은 사용하지 않는다.

## 가로 연병장

0.57.2부터 위쪽은 큰 부대 본부, 그 아래 학교, 그 아래 시설, 맨 아래 장비 순서로 배치한다. 종류별로 모이지만 별도의 페이지로 나누지 않는다. 학교/시설/장비는 각각 최대3줄을 사용하고 수량이 늘면 종류별로 크기를 조절한다. 큰 본부 영역을 먼저 확보하고 이름표가 겹치지 않는 조건에서 필요한 최소 가로 폭을16px 단위로 늘린다.

폰은 스와이프, PC는 드래그, 키보드는 방향키80px 이동. 아주 낮은 화면에서는 읽을 수 있는 본부/이름표 크기를 유지하기 위해 연병장 내부에 세로 스크롤도 허용한다. 헤더와 메뉴는 고정이다. 페이지 이동 버튼과 구역 제목은 없으며 가로로 넘칠 때 스와이프 안내를 표시한다.

- 홈 장비 4종 배치 제한을 제거했다. 구매 시 모든 종류를 자동 배치할 수 있고 수동 보관도 유지한다.
- 기존에 보관한 장비는 자동으로 꺼내지 않는다. 보관품은 장비 탭에서 배치하면 된다.
- 전투 출전 칸 제한과 장비 추가 구매 잠금은 이번 변경 대상이 아니다.
- 골드는 손을 뗐을 때 지급한다. 8px를 넘는 움직임/스크롤/취소는 터치 골드를 주지 않는다. 동시 4손가락 터치, 키보드 터치를 지원한다.
- 스크롤은 기존 그림을 이동하며 재생성하지 않는다. 보유 목록/계급 지형/크기가 바뀔 때만 다시 그린다. 시설 그림은 상점과 연병장에서 같은 SVG 캐시를 쓴다.

## 저장 및 검증

저장 형식26에 facilityLevels 객체 추가. 기존 형식25의 facilities 배열을 유지하고 보유시설은Lv.1로 이전한다. 형식2~24는 빈 시설/레벨로 이전하고 자산, 장비 강화/배치, 스킬, 미수령 오프라인 보상은 보존한다. 중복/알 수 없는 시설 ID는 저장 손상 진단으로 처리한다. 실제 사용자 기록을 테스트용으로 바꾸지 않았다.

자동 검증: 순차 해금/계급 별도 인원 조건, 중복 건설, 부족 골드, 안전 정수 경계/1,000경 직전/저장 복원, 자동 터치/장군검/오프라인 정산, 전체 장비 배치, 288~480px 폭 및 짧은 높이 배치 경계, 스와이프·키보드·취소·다중 터치, 화면 크기 변경 시 스크롤 범위 보정.

0.57.0 기준 성장 모델(시설 강화 미포함; tools/growth-sim.mjs --battles): 하루3회, 회당7.5분, 초당3터치, 방문당 첫 점령1회, 광고/개인장비 강화/반복 전투 없음. 시설 구매와 배치 제한 해제 반영: 대령2.333일, 준장3.001일, 대원수21.001일. 기존 시설 없는 모델 대원수24.667일 대비 빨라진다. 실제 체감과 실기기 조작은 별도 확인이 필요하다.

새 그림은 코드 도형으로 직접 제작했으며 외부 이미지/음원/SDK/네트워크 서비스를 추가하지 않았다. 의무실 표식은 녹색 십자로 그렸다. 0.57.1에서 현재 브라우저 화면은 실제로 확인했다. 실기기 화면과 실제 APK/AAB 재빌드 및 설치는 확인하지 않았다.
