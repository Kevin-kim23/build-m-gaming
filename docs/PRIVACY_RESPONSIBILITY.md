# 개인정보 책임과 운영 관리 안내 (광고·결제 도입 기준)

법률 자문이 아닙니다. "확인 필요"는 출시 전에 공식 자료(개인정보보호위원회, 법제처, Google Play·AdMob 정책)나 전문가로 확인하세요. 이 문서는 사용자가 놓치지 않기 위한 점검용입니다.
함께 보는 문서: [PRIVACY_MANAGEMENT.md](PRIVACY_MANAGEMENT.md), [MONETIZATION_CHECKLIST.md](MONETIZATION_CHECKLIST.md), [store/LEGAL_RISKS.md](store/LEGAL_RISKS.md)

## 1. 누가 책임지나
- 개인정보에 대한 책임은 **운영자(동람코, 사용자 본인)** 에게 있습니다. Google AdMob이 정보를 처리해도 "이 앱을 통해 이용자에게 어떤 일이 일어나는지"를 이용자에게 알릴 책임은 운영자에게 남습니다.
- 한국 개인정보보호법은 개인정보를 처리하는 사람에게 **개인정보 보호책임자 지정**과 **처리방침 공개**를 요구합니다. 직원 없이 1인으로 운영하면 대표 본인이 책임자가 되는 경우가 많습니다. (확인 필요)
- 광고 ID, IP 주소 같은 정보가 "개인정보"에 해당하는지는 상황에 따라 판단이 갈립니다. **판단이 애매하면 처리방침에 적고 신고하는 쪽**이 안전합니다. 이미 그렇게 하고 있습니다.

## 3. 광고를 운영할 때 생기는 문제와 관리법
| 문제 | 왜 생기나 | 관리법 |
|---|---|---|
| 방침과 실제가 다름 | SDK가 업데이트되며 처리 항목이 바뀜 | SDK 버전을 올릴 때마다 Google의 데이터 공개 안내를 다시 읽고 방침·데이터 보안 양식과 비교 |
| 동의 없이 광고 요청 | UMP 설정 누락 | AdMob 콘솔에서 동의 메시지를 만들고 지역별로 확인. 앱은 동의 확인 전에는 광고를 요청하지 않음 (현재 구현) |
| 어린이 문제 | 만 14세 미만(한국), 13세 미만(미국 등)은 별도 동의·광고 제한 | 대상 연령을 "어린이 대상 아님"으로 정하고 그대로 운영. 어린이가 많이 쓴다고 판단되면 정책 재검토 (확인 필요) |
| 광고 계정 정지 | 직접 클릭, 광고 유도, 정책 위반 | 개발 중에는 테스트 광고만 사용. 이용자에게 광고 클릭을 요구하지 않음 |
| 보상 지급 오류 | 광고 중 강제 종료 | 베타에서 빈도를 보고 보상 복구를 검토 |
| 광고 ID 선언 불일치 | 매니페스트의 AD_ID 권한 | Play 광고 ID 선언과 데이터 보안 양식을 SDK 실제 동작과 일치시킴 |
| 수익 정산·세금 | 광고 수익이 생김 | 8장 참고 |

**운영 광고 ID로 바꾸는 날**: 새 버전을 빌드하고, 이 문서와 방침을 다시 읽고, Play Console 선언이 그대로 맞는지 확인합니다.

## 4. 유료 결제를 넣을 때 생기는 문제와 관리법
| 문제 | 설명 | 관리법 |

| 결제 정보 취급 | 카드번호는 Google Play가 처리합니다. 앱은 받지 않습니다. | 카드·주소를 앱에서 받는 화면을 만들지 않음 |

| 환불·청약철회 | 한국 소비자 보호법상 고지 필요 | 상품 화면에 가격·내용을 정확히 표시하고 환불 안내를 Play 정책과 맞춰 안내 (확인 필요) |
| 미성년자 결제 | 청소년 구매 분쟁 | 결제 전 확인 화면, 문의 대응 절차 준비 |
| 확률형 아이템 | 유료로 판매하면 확률 정보 공개 의무 | 가능하면 유료와 확률 요소를 섞지 않음. 팔면 확률을 공개하고 광고·스토어 문구와 일치시킴 (확인 필요) |
| 가짜 결제 화면 | 지금 남아 있는 자동터치 4,900원 "테스트" | 정식 출시 전 실제 Play 결제로 교체하거나 숨김. 무료로 받은 테스트 보유자 처리 방침을 정함 |
| 구매 복원 | 기기 변경·재설치 | Play 결제 복원 기능을 구현. 지금은 없음 |
| 사업자·세금 | 8장 참고 | |

## 5. 개인정보 사고가 났을 때 (미리 정해 두기)
- 이용자가 보낸 문의 메일, 테스터 이메일 목록, 구글 계정·AdMob 계정·키스토어가 유출되면 **즉시** 아래를 합니다.
  1. 해당 계정 비밀번호 변경과 2단계 인증 확인
  2. 유출 범위 확인 (누구의 어떤 정보인지)
  3. 영향받은 이용자에게 알림 (한국법은 인지 후 짧은 기한 안에 통지를 요구함 → 정확한 기한과 신고 대상은 확인 필요)
  4. 방침과 이 문서에 사고 기록 추가
