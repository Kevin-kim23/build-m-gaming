# 상점 출시 준비 · 0.76.5 · 2026-10-14

## 승인된 개발 구현
- 스타터팩: 터치 부스터 30개 + 초당 부스터 30개, 예정 가격 5,900원. 최종 설문 답변에 따라 자동터치를 제외했다.
- 자동터치: 기존 영구 보유 단품, 예정 가격 4,900원. 아이템에서 상점으로 이동. 홈 빠른 안내와 켜기/끄기는 유지한다.
- 스타터팩은 현재 기기 게임 기록당 1회 개발 테스트 지급. 자동터치 보유 여부에 영향받지 않는다. 물약은 즉시 사용되지 않고 아이템에 쌓인다.
- 개발 화면에서만 명시적 무료 테스트 확인 후 지급. 출시 빌드는 두 상품 모두 신규 구매 준비 중으로 잠긴다. 실제 결제 SDK·과금·영수증·서버 검증은 연결하지 않았다.
- 금색 상품 카드와 빨강/파랑 구성으로 꾸몄으며 근거 없는 할인율·마감 시간·한정 수량은 넣지 않았다. 상품 구성·가격·자동터치 미포함·실제 결제 없음·기기 내 기록 한계를 함께 표시한다.

## 직접 확인과 한계
- 두 상품과 홈 자동터치 구매는 확인창과 중복 요청 방지 처리를 공유한다. 상품별 지급은 한 번의 상태 변경으로 적용한다.
- 저장 형식 39에 스타터팩 테스트 수령 상태만 추가. 형식 38 이하는 미수령으로 이전하며 기존 물약 시간·수량·자동터치 보유·골드·진행을 유지한다.
- 로컬 기록을 지우거나 다른 기기로 옮겼을 때 1회 제한/잔여 물약/구매 복원을 보장하지 않는다. 이 구현을 실제 결제 검증 완료로 간주하면 안 된다.
- 저장 실패는 기존 게임 저장 경고로 안내한다. 향후 유료 지급에는 구매 검증·지급 기록의 지속 보관·재처리 설계가 추가로 필요하다.
- 현재 시행 중 방침·약관·스토어 원문과 개정 번호는 변경하지 않았다.

## 실제 판매 연결 전 별도 작업
1. Google Play Billing 상품을 등록하고 화면 가격을 결제 서비스가 반환하는 실제 가격과 일치시킨다. 자동터치와 스타터팩의 상품 유형·구매 횟수·복원 범위는 실제 구현 시 확정한다.
2. 구매 상태 PURCHASED 검증 후 지급, 중복 지급 방지, 3일 내 지급 확인 처리, 재접속 시 구매 재조회를 구현한다. 소모품 구매 조회만으로 사용 후 남은 물약 기록이 복원되는 것은 아니다.
3. 취소·보류 후 승인/거절·중복 콜백·통신 끊김·앱 종료·재설치·환불 시험. 자체 무료 테스트와 Google Play 테스트 결제를 구분해 기록한다.
4. 기기 간 복원을 약속하기 전에 실제 저장/지급 장부를 설계한다. 첫 출시 서버 제외 결정을 이번에 변경하지 않는다.
5. 가격/구성/지급 시점/복원 한계/환불·청약철회 문의/미성년자 구매 안내를 약관·상품 안내·스토어에 반영할 사용자 게시 목록을 작성한다.
6. 한국 유료 판매자에 요구되는 사업자·통신판매 정보 충족 여부 확인. 실제 개발자 계정 충족 여부는 미확인이다.
7. 결제 기록 처리와 실제 SDK 동작을 기준으로 개인정보방침·Play 데이터 보안 답변을 재검토한다. 현재 방침·약관 번호는 유지한다.
