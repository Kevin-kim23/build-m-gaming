## 1. 보고서의 범위와 현재 결론

첫 광고 연결 및 그에 따른 Google Play 신고 수정, 공개 개인정보처리방침 갱신 내용을 기록한다. 제목의 ‘게시’는 실제 광고 수익 발생이나 Google 검토 승인 완료를 뜻하지 않는다.

**현재 완료된 것은 Google 테스트 광고 연결 빌드 준비, Play Console 신고 변경 저장, 공개 개인정보처리방침 개정 3 게시다. 새 AAB 업로드, Play 검토 제출, 운영 광고 활성화, 실제 유료결제 연결은 완료하지 않았다.**

| 구분 | 확인된 상태 |
|---|---|
| Google Mobile Ads / UMP | Android에 연결 완료 |
| 광고 종류 | Google 공식 샘플 보상형 광고 |
| 수익 광고 | 미활성화, 운영 ID는 빌드에 적용하지 않음 |
| 실기기 광고 재생 및 보상 확인 | 미검증 |
| Play 광고 포함 선언 | ‘예’로 변경 후 저장 |
| Play 광고 ID 선언 | ‘예’ 및 사용 목적 저장 |
| Play 데이터 보안 | 광고 SDK에 맞게 수정 후 저장 |
| 공개 개인정보처리방침 | 기존 주소에 개정 3 반영 확인 |
| Play 검토 제출 | 아직 하지 않음 |
| 새 AAB 업로드 | 아직 하지 않음 |
| 비공개 테스트 기존 버전 | 확인 시 `69003 (0.69.3)` |
| 실제 앱 내 결제 | 미연결, 기존 자동터치 테스트 지급 남아 있음 |

## 2. Play Console에서 실제로 수정한 내용

### 2.1 광고 포함 여부

- 이전: 광고 없음.
- 변경: **광고 포함 ‘예’**.
- 저장 완료. 게시 개요에 ‘광고 선언 업데이트’로 표시됨.
- 테스트 광고도 실제 광고 SDK가 외부 통신하므로 예전의 광고·수집 없음 신고를 그대로 쓰지 않도록 수정했다.

### 2.2 광고 ID

- 광고 ID 사용 여부: **예**.
- 선택한 목적: **애널리틱스, 광고 또는 마케팅, 사기 예방·보안·규정 준수**.
- ‘출시 오류 사용 중지’는 체크하지 않았다.
- 저장 완료. 게시 개요 하단에 ‘광고 ID 선언이 업데이트되었습니다’ 표시를 확인했다.
- 광고 ID 선언은 광고 선언·데이터 보안과 달리 게시 개요의 검토 제출 건수에 별도 1건으로 합산되지 않았다.

### 2.3 데이터 보안 공통 답변

| 질문 | 저장한 답변 및 판단 |
|---|---|
| 사용자 데이터 수집·공유 | 예 |
| 전송 중 암호화 | 예, 공식 SDK 공개 안내의 TLS 근거 |
| 앱 내 계정 생성 | 제공하지 않음 |
| 외부 계정으로 로그인 | 제공하지 않음 |
| 데이터 삭제 요청 관련 선택 문항 | 아니요. Google SDK 데이터 삭제를 운영자가 보장할 수 없음 |
| 로컬 게임 기록 삭제 | 앱 삭제/앱 데이터 지우기로 가능. 위 SDK 데이터 삭제 문항과 구분 |

### 2.4 데이터 유형별 답변

아래 네 유형 모두 **수집됨 + 공유됨**, **일시적으로만 처리되는 데이터 아님**, **선택적 수집**으로 저장했다. 각 유형의 수집 목적과 공유 목적 모두 애널리틱스, 광고 또는 마케팅, 사기 예방·보안·규정 준수를 선택했다.

| 유형 | 근거 및 범위 |
|---|---|
| 대략적인 위치 | SDK의 IP 주소 기반 일반 위치 추정. GPS/정밀 위치 권한 추가를 뜻하지 않음 |
| 앱 상호작용 | 앱 및 광고와의 상호작용 |
| 진단 | 실행 시간, 멈춤 비율, 에너지 사용 등 SDK 진단 정보 |
| 기기 또는 기타 ID | 광고 ID, 앱 세트 ID 등 SDK 식별자 |

- 선택적 수집 판단은 광고 버튼을 눌러야 동의 조회와 광고 요청이 시작되고, 광고 없이 기본 게임을 진행할 수 있는 현재 구현에 근거한다. 시작 시 SDK 자동 초기화 등으로 동작이 바뀌면 이 답변도 재검토해야 한다.
- 공식 SDK 25.5.0 공개 안내와 Play 데이터 유형 정의를 비교했다. 실행 시간·멈춤 비율·에너지 사용은 진단으로 분류했다.
- 별도의 비정상 종료 로그나 기타 앱 성능 데이터를 추가 수집한다고 확인하지 못했으므로 해당 항목을 중복 선택하지 않았다. 향후 SDK/진단 서비스 변경 시 다시 확인한다.
- 금융 정보·구매 내역·게임 진행 기록을 광고 수집 항목으로 추가하지 않았다. 현재 실제 결제나 게임 서버가 없다.
- 최종 미리보기에서 답변을 확인하고 저장했다.

### 2.5 대상 연령

- 기존 설정은 **13~15세, 16~17세, 만 18세 이상**으로 확인했다.
- 연령을 임의로 올리거나 바꾸지 않았다.
- 대상 연령 안내에는 국가별 아동 기준이 다를 수 있다는 설명이 있었다.
- 광고 소재 등급 T 제한만으로 모든 지역의 미성년자 동의·광고 요건을 충족한다고 판단하지 않는다. 실제 운영 전 제공 국가, 동의 연령, 연령 처리 방식을 점검해야 한다.

### 2.6 게시 개요에서 확인한 결과

- ‘변경사항이 아직 검토를 위해 제출되지 않음’ 상태.
- **‘검토를 위해 변경사항 2개 제출’** 버튼 표시.
- 두 항목: 광고 선언 업데이트 / 데이터 보안 설문지 작성.
- 별도 안내: 광고 ID 선언 업데이트.
- 확인 시 자동 빠른 검사 진행 중, 최대 10분 남음으로 표시되었다. 검사 완료나 통과를 확인한 것은 아니다.
- **관리형 게시가 사용 중지됨**으로 표시되었다. 이전 기록과 다를 수 있으므로 이후 제출 시 현재 설정을 다시 확인한다.
- 최근 게시일은 2026-10-08로 표시되었다.
- 제출 버튼을 누르지 않았고, 새 AAB도 올리지 않았다. 신고 저장과 검토 제출·승인·배포를 구분해야 한다.

## 4. 이 신고의 근거가 되는 0.70.0 광고 구현

상세 구현은 [AdMob 연결 문서](../ADMOB_INTEGRATION.md)에 있다.

- Google Mobile Ads `25.5.0`, UMP `4.0.0` 추가. 미디에이션·Firebase·결제 SDK는 추가하지 않음.
- 물약 광고 버튼 → UMP 동의 상태 갱신 → 필요한 동의 화면 → `canRequestAds` 확인 → SDK 초기화 → 광고 로드/표시.
- 동의 확인 실패, 로드 실패·시간 초과, 취소에는 보상 없음.
- Google의 보상 완료 콜백에서 지급 자격을 얻고, 광고 종료와 게임 복귀 이후 선택한 빨강/파랑 물약 1개를 저장.
- 중복 요청 차단. 광고 중 게임 일시정지와 저장 잠금 복귀를 고려.
- 웹의 가짜 광고 무료 지급 제거. 웹은 광고 미지원 안내.
- 게임 설정에 광고 개인정보 선택 변경 기능 추가.
- 광고 소재 등급 T 이하 제한.
- 서버 측 보상 검증 및 강제 종료 시 미완료 보상 복구는 없음. 유료 상품 지급 구조로 그대로 재사용하면 안 됨.
- 실제 저장 기록을 테스트 기록으로 덮어쓰지 않음. 저장 형식 33 유지.

## 6. 실제 결제와 아직 남은 작업

### 자동터치 결제

- 자동터치의 예정 가격 4,900원과 실제 청구 없는 테스트 지급 기능은 아직 남아 있다.
- Google Play Billing 연결, 상품 등록/활성화, 구매 검증·승인·복원은 이번 작업에서 하지 않았다.
- 유료결제를 연결한 뒤 앱 내 구매 관련 표시와 데이터 보안·방침을 실제 구현에 맞게 다시 점검해야 한다.
- 기존 테스터에게 무료 지급된 자동터치를 정식 결제 전환 후 유지할지 여부도 결정이 필요하다.
- 비공개 테스트 참여와 결제 라이선스 테스터 등록은 별개다. 결제 테스트 전에 라이선스 테스터 설정을 확인한다.

### 다음 진행 순서

1. 실제 폰에서 테스트 광고 로드, 완료 후 물약 1개 지급, 중도 취소 0개, 중복 클릭, 인터넷 끊김, 홈 복귀, 재시작 후 보유량을 확인한다.
2. 위 0.70.0 AAB를 기존 비공개 테스트 트랙에 업로드한다. 기존 앱 데이터 보존과 버전·서명을 확인한다.
3. 게시 개요에서 새 빌드와 신고 변경을 검토한 뒤 Google 검토를 위해 제출한다. 현재 관리형 게시가 꺼져 있다는 점도 확인한다.
4. 실제 결제는 별도 작업으로 구현하고 테스트한다. 결제가 추가되면 신고·방침도 함께 갱신한다.
5. 수익 광고 전환 전 AdMob 승인, 스토어 연결, app-ads.txt, 지역별 UMP 메시지, 미성년자 처리, 국외 처리 안내를 점검한다. 테스트 기기 설정을 사용해 운영 광고 부정 클릭을 피한다.

## 8. 다음 작업자가 혼동하면 안 되는 사항

- 신고를 **저장한 것**과 Google에 **검토 제출한 것**, **승인된 것**, 새 버전을 **배포한 것**은 서로 다르다.
- 이번 신고 수정은 자동으로 AAB를 교체하지 않는다.
- 샘플 광고는 수익 광고가 아니지만 실제 SDK 네트워크 통신은 한다.
- Wi-Fi 연결만으로 과거 APK가 새 광고 코드로 바뀌지 않는다. 해당 코드가 들어 있는 새 APK/AAB가 필요하다.
- 공개 방침 주소가 없다는 과거 메모는 현재 상태와 다르다. 기존 Google 문서 URL이 있고 개정 3을 공개했다.
- ‘모든 법적 문제 해결’, ‘운영 광고 승인’, ‘실기기 광고 성공’, ‘실제 유료결제 완료’라고 기록하면 안 된다. 아직 확인되지 않은 사항이다.
- 이 보고서 추가는 문서 작업이며 앱 기능·버전·저장 데이터는 변경하지 않는다.
