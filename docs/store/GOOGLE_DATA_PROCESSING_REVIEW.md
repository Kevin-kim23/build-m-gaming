# Google 광고 처리 정보 확인

2026-10-09 · 부대 키우기 0.72.3 · 공개 방침에 일괄 적용하기 전 근거 기록

## 계약 법인

사용자가 연 AdMob 지급 화면에서 결제 계정 '애드센스(대한민국)'을 확인했다. 대한민국용 약관 제1항의 Google은 **Google Asia Pacific Pte. Ltd.**다. 공개 약관 페이지의 초기 조회 국가는 미국이었으며 대한민국으로 조회 선택만 변경했다. 계정 국가나 계약 동의를 변경하지 않았다. 계약 법인을 개인정보의 유일한 수령자나 유일한 처리 국가로 동일시하지 않는다.

- [대한민국용 약관](https://www.gstatic.com/adsense/tc/2022-v1/google_sgp/ko.html)
- [Google 계약 법인 확인 방법](https://support.google.com/admob/answer/2772511?hl=ko)

## 공개 자료에서 확인한 보관 기준

Google 광고 전용 보관 정책은 **Google 계정에 저장되지 않는 정보**의 서버 로그에 대해 다음을 설명한다. 이 조건과 예외를 생략하여 앱 전체의 단일 보관기간으로 쓰지 않는다.

| 정보/목적 | 공식 설명 | 적용 주의 |
|---|---|---|
| 광고 서버 로그의 IP | 9개월 후 주소 일부 제거 | 모든 자료의 완전 삭제를 뜻하지 않음 |
| 로그·광고 게재 DB의 쿠키/광고 ID | 18개월 후 제거하여 로그 추가 익명화 | 진단·UMP 등 모든 항목에 자동 적용하지 않음 |
| 쿠키/광고 ID와 연결된 실시간 광고 프로필 DB | 18개월 후 삭제 또는 익명화 | 현재 앱은 비맞춤형 요청. 해당 DB 처리 여부도 구분 |
| 사기 방지·차단한 광고 재노출 방지 등 | 위 기간보다 오래 보관할 수 있음 | 예외를 숨기지 않고 유형별 확인 필요 |

[Google Ads User Data Retention Policy](https://business.safety.google/adsretention/)

일반 Google 보관 안내의 삭제 소요기간·백업 보관 설명은 삭제 절차에 관한 것이다. 이를 수집 후 보유기간으로 바꾸지 않는다. [일반 보관 안내](https://policies.google.com/technologies/retention?hl=ko).

AdMob의 보고서 보관은 또 다르다. User Activity는 90일, Ads Activity·Cohort·Privacy & messaging 보고서는 2,555일이라는 공식 안내가 있다. 이는 게시자 보고서의 보관 범위이며 이용자 원시 개인정보 전체의 삭제 시점을 뜻하지 않는다. 보고서 숫자를 방침의 단일 보관기간으로 복사하지 않는다. [보고서 보관](https://support.google.com/admob/answer/16585829?hl=en).

## 처리 국가와 역할

Google 일반 방침은 거주 국가 밖의 전 세계 서버에서 처리될 수 있다고 설명한다. 이 자료만으로 한국 AdMob 이용자의 실제 처리 국가 목록을 확정할 수 없었다. 데이터 센터가 존재하는 모든 국가를 우리 앱의 이전 국가로 나열하거나 싱가포르만 적지 않는다. [Google 방침의 데이터 이전](https://policies.google.com/privacy?hl=ko).

약관 제10항은 Controller-Controller 보호 약관을 참조한다. 해당 약관은 독립적 처리자 역할과 적용 범위를 설명하며 서비스 목록은 AdMob을 포함하되 일부 Processor 기능을 제외한다. 실제 기능별 관계 및 한국법상 제공/위탁 판단은 별도 확인한다. [보호 약관](https://business.safety.google/adscontrollerterms/), [서비스 목록](https://business.safety.google/adsservices/).

## Google 지원에 보낼 질문 — 미발송

제목: 한국 AdMob 앱의 개인정보 처리 국가·보관기간 확인 요청

> 대한민국 만 14세 이상 대상 Android 게임을 운영합니다. 결제 계정 국가는 대한민국이며 관련 약관의 계약 법인은 Google Asia Pacific Pte. Ltd.입니다. Google Mobile Ads SDK 25.5.0과 UMP 4.0.0을 사용하고, 모든 이용자에게 비맞춤형 광고를 요청하며 14~18세에는 setTagForUnderAgeOfConsent(true)를 적용합니다.
>
> 한국 이용자의 개인정보 고지를 위해 다음을 확인하고 싶습니다.
> 1. 이 구성에서 개인정보를 받거나 처리하는 Google 법인, 처리 국가, 연락처를 확인할 수 있는 공식 자료를 안내해 주세요. 계약 법인의 소재지와 실제 처리 국가를 구분한 답변이 필요합니다.
> 2. 광고 ID/IP/상호작용/진단/UMP 동의 정보 및 미성년자 제한 신호 각각의 보관·익명화·삭제 기준과 예외를 확인할 수 있는 자료가 있나요?
> 3. Google Ads User Data Retention Policy의 9개월 IP 부분 삭제 및 18개월 쿠키/광고 ID 제거 기준이 위 AdMob 구성에 적용되는 범위와 적용되지 않는 항목은 무엇인가요?
> 4. 게시자 또는 이용자가 각 정보의 열람·삭제를 요청할 공식 경로와 게시자가 직접 처리할 수 있는 범위를 안내해 주세요.
>
> 한국 개인정보처리방침에 정확히 기재하기 위한 문의입니다. 공개 자료로 제공할 수 없는 항목은 그 사실과 대신 인용할 수 있는 자료를 알려 주세요.

AdMob 도움말의 문의하기에서 지원 수단을 확인해 접수할 수 있다. 문의 경로·응답 가능 여부는 계정 상태에 따라 확인해야 한다. 이번에는 질문을 작성했으며 실제 문의·개인정보 전송은 하지 않았다. 비밀번호, 결제 상세 주소, 고객의 실제 정보는 첨부하지 않는다.

## 반영 상태

계약 법인과 보관 기준 조사에 진전이 있었으나 구체 국가·모든 유형의 기간·한국법상 근거/별도 동의 검토는 남았다. 앱 방침6·Google 공개 문서·Console 응답은 이번 조사로 수정하지 않았다. 회신과 적용 범위가 확인되면 방침 원본과 공개 문서를 함께 갱신한다. 계정 승인·광고 공급·유료결제 작업은 별도 보류 상태다.
