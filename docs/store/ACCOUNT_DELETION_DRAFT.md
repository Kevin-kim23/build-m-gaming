# 부대 키우기 계정 삭제 안내 — 작성 중 초안

**게시용 최종본이 아니다.** 실제 운영 삭제 검증과 공개 요청 URL은 미완료다. 이 문서는 1단계에서 삭제 범위를 맞추기 위한 내부 초안이며 4단계에서 사용자가 게시할 최종 안내를 준비한다. 공개 Google 방침·Play Console을 이번에 변경하지 않는다.

## 이용자에게 안내할 내용

부대 키우기(운영자 김동환·동람코)의 서버 계정 삭제는 Google 계정 자체를 삭제하지 않습니다. 서버에 직접 저장한 진행과 기기에만 있는 기록은 삭제 방법이 다릅니다.

- 앱을 이용할 수 있으면 **설정 → 구글 계정 연결 → 서버 계정·기록 삭제**에서 요청합니다. 다른 사람의 계정을 삭제하지 않도록 최근 Google 로그인이 필요할 수 있습니다.
- 앱을 이용할 수 없으면 현재 개인정보 문의 주소 `dong760630@naver.com`으로 계정 삭제 요청임을 알려 주세요. 요청 계정의 소유자인지 필요한 최소 정보로 확인하며 Google 비밀번호·인증 토큰·신분증 전체 사본은 요구하지 않습니다. 이 이메일 경로가 실제로 접수·확인·처리·회신되는지는 운영 검증 대상으로 남아 있습니다.
- 삭제 대상은 Firebase 인증 계정, 게임 프로필·닉네임 소유권, 서버 게임 기록, 직전 백업·최초 연결 검토 기록, 해당 계정이 신고자 또는 대상인 신고입니다. 추후 랭킹이 추가되면 랭킹 연결 자료도 삭제 대상에 포함하여 검증합니다.
- 일부 삭제가 실패하면 완료라고 안내하지 않고 재처리를 위한 계정 식별자·요청 시각·처리 상태 등 최소 기록을 유지합니다. 실패 중 요청을 일정 기간이 지났다는 이유만으로 지우지 않습니다.
- 모두 삭제된 뒤에는 처리 확인 기록만 완료 후 **90일** 보관하고 정리합니다. 반복 요청으로 90일 시작점을 다시 잡지 않습니다. 게임 진행이나 닉네임·신고를 90일 더 보관한다는 뜻이 아닙니다.
- 앱을 삭제하거나 앱 데이터를 지우면 해당 기기의 진행·복원 전 백업을 제거할 수 있습니다. **서버 계정 삭제만으로 기기 기록과 복구 백업은 지워지지 않습니다.** 운영체제 백업은 기기의 백업 서비스에서 별도로 관리해야 합니다.
- Firebase가 관리하는 인증 시스템·백업, Google 계정 자체·광고 정보에는 해당 서비스의 처리 기준이 적용됩니다. 게임 운영자가 모든 Google 정보의 즉시 삭제를 보장하지는 않습니다. 자세한 내용은 최종 개인정보처리방침에 연결합니다.

## 공개 전에 운영자가 확인할 것

1. 운영 테스트 계정으로 삭제 성공·부분 실패·재시도·완료90일 정리·신고자/대상 관련 신고 삭제를 검증한다. 실제 이용자/개발 만렙 계정으로 시험하지 않는다.
2. 앱 없이 요청할 때의 최소 본인 확인 방법·담당자·회신 절차를 실제로 운영 가능하게 정하고 공개 문안에 반영한다. 이메일 주소만 있다는 사실로 처리 체계 완료라고 하지 않는다.
3. 앱/개발자명·삭제 방법·대상·보관하는 자료 및 기간을 포함하는 페이지를 공개하고 로그인 없는 브라우저에서 열어 확인한다. 아직 게시할 웹 주소를 정하거나 공개 페이지를 만들지 않았다.
4. 해당 실제 웹 링크를 Play Console의 계정 삭제 URL에 반영한다. 제출은 사용자 확인 후 진행한다. [Play 계정 삭제 요구사항](https://support.google.com/googleplay/android-developer/answer/13327111?hl=ko).

삭제 프로그램의 예약 실행과 실제 운영 배포는 2단계 비용 추정·사용자 승인 후 별도 작업이다. 현재는 코드·초안 준비 상태이며 삭제 서비스가 운영 중이라고 표시하지 않는다. 정책 동기화 필요.
