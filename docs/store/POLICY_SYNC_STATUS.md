- AdMob 개인정보 보호 및 메시지: 유럽/미국 모두 ‘새 메시지 만들기’ 표시. 게시된 운영 동의 메시지를 확인하지 못했다.

## 미완료 사항 — 무조건 문제없다고 답하지 말 것
- 실제 Console 스토어 설명에도 개인정보 미수집, 무조건 오프라인, 시설10종, 특전원수 문구를 발견했다. 광고 SDK 처리/기본 게임 오프라인/시설19종/부사령관으로 수정해 임시보관했다. 아직 게시·검토 제출한 설명은 아니다. 나머지 스크린샷 등 전체 자산 검수는 별도다.
- 개인정보 보호책임자 또는 실제 고충 처리 부서 표기. 사용자 성명은 요청에 반문한 상태이며 공개하지 않음. 새 부서를 임의로 만들지 않음.
- 한국 국외 처리의 관계·법적 근거·구체 정보 확인. Google 직접 수집인지 제공/위탁인지에 따라 판단이 달라질 수 있다.
- 이용 연령 확정, 실제 연령 확인과 미성년자 광고 처리. ‘만15세 이상’ 표시만으로 면제되지 않음.
- UMP 운영 메시지 구성·게시 및 지역별 테스트. Google 샘플 앱 ID에서의 테스트는 운영 앱 메시지를 검증하지 않는다.
- SDK 시작 시 처리와 선택적 수집 신고의 일치 검증. 앱 시작 시 동의 갱신을 권고하는 Google 안내와 현재 광고 버튼 시점 호출 차이도 검토한다. 동의 흐름 변경 시 방침·신고를 함께 갱신한다.
- 실폰 광고 완료/취소/실패/재접속 테스트.
- 운영 광고 전환 시 실제 ID, app-ads.txt, 앱 인증·승인 및 개인정보 설명 재점검.
- 유료결제는 미구현. 약관·구매 검증·복원·환불·미성년자 계약 처리 별도 작업.
