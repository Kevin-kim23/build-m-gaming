- 국외 처리: Google의 직접 수집/운영자의 제공·위탁 관계와 법적 근거를 먼저 확인하고 필요한 수신자·국가·항목·시기·방법·목적·기간·거부 방법을 확정한다. 추정 국가나 기간을 써 넣지 않는다.

- 그림: 코드로 직접 그린 픽셀 그림이라 외부 그림 저작권 위험은 낮습니다. 실제 무기를 닮은 모양이 있을 수 있으나 "모양을 베끼지 않았다"는 주석만 있고 법적 판단은 못했습니다.
- 소리: 합성 효과음, Suno 배경음악 4곡, 승인된 로고 영상 내 ElevenLabs 효과음이 있습니다. 유료 생성 증빙은 비공개 보관하며 `npm run audio:verify`로 자산을 확인합니다.
- 라이브러리: 설정 → 게임 정보 → 오픈소스 라이선스에서 오프라인 열람. 실제 배포 runtime 의존성/POM 및 Google SDK 내장 고지를 추출했습니다. Capacitor MIT, AndroidX Apache-2.0 등 실제 조건을 구분하며 Google SDK 자체는 Android SDK License입니다. Vite 등 개발 도구는 앱 고지에서 제외했습니다. 재생성: `docs/licenses/README.md`.
- 이름 상표: "부대 키우기"는 평범한 말이라 등록 상표와 겹칠 수 있습니다. "동람코", "아스테라", "세르딘", "이스트라" 같은 고유명칭도 마찬가지입니다. **특허정보검색서비스(KIPRIS)와 Google Play 검색으로 직접 확인**해야 합니다. 저는 확인하지 못했습니다.
- 앱 아이콘과 스토어 이미지는 AI로 만들었다면 해당 도구의 이용 약관(상업적 이용 여부)을 기록해 두세요.

### 4. 군사·폭력 소재 정책
- 허구 세계의 픽셀 전투라 허용 범위로 보이나, 최종 판단은 Google 심사입니다.
- 피하세요: 실제 국기·군복 마크·실제 분쟁·테러 표현, 실제 지명, 실제 무기 상표 이름.
- ICBM, 레일건 같은 이름은 일반 용어입니다. 문제 소지는 낮지만 설명에서 실제 국가를 암시하는 말은 쓰지 마세요.
- 적 표식이 십자 모양입니다. 혐오 상징으로 오해될 모양이 아닌지 스크린샷으로 한 번 더 보세요.
- 이등병·대원수 같은 계급은 한국 군대 용어를 따옵니다. 실제 군 조직을 홍보하거나 사칭하는 표현은 없습니다. 병무청·국방부 이름은 쓰지 마세요.

### 5. 한국 게임 관련 법규 (확인 필요)
- 게임물 등급: Play 스토어 배포 게임은 Google의 IARC 등급 설문으로 등급이 붙는 방식이 일반적입니다. 정확한 현재 규정은 직접 확인해야 합니다.
- 광고 수익 및 실제 결제 도입 전 사업자·세금·통신판매 관련 적용 요건을 관할 기관과 확인합니다. 테스트 광고 연결이 사업 요건 검토를 대신하지 않습니다.
- 개인 개발자가 Play에 등록하면 **개발자 이름·주소·이메일이 스토어에 공개**될 수 있습니다. 사업자라면 해당 사항을 계정 설정에서 확인하세요.

### 6. Google Play 테스트 규칙
- 개인 계정은 12명 이상이 14일 연속 참여해야 정식 출시 신청이 가능합니다. 일정표와 맞는지 날짜를 세어 두세요.
- 테스터 가입 이메일을 모으면 그 이메일은 개인정보입니다. 모집 글에 목적을 적고 테스트 후 폐기하세요.

### 7. 기타
- 앱 이름·설명에 "공식", 다른 게임 이름, 인기 게임 이름을 넣으면 정책 위반(키워드 스팸)입니다.
- 스토어 문구에서 "누구나 대원수가 될 수 있다" 같은 과장은 피하세요. 성장 속도에 대한 약속은 하지 마세요.
- 서명 키(upload.p12, JSON)를 잃으면 업데이트가 막힙니다. 외부에 백업하세요.
