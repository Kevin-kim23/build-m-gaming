# 출시 전 법적·정책 위험 점검 · 0.54.0

변호사 검토가 아닙니다. 아래는 코드·문서를 읽고 정리한 **위험 목록과 확인 못한 것**입니다. 법적 문제가 없다고 보장하지 않습니다.

## A. "가상 세계" 표시 현황 (0.55.0 반영)
- 게임 정보 화면에 허구 안내 문장이 들어갔고, 스토어 설명 초안에도 같은 취지의 문장이 있습니다.
- 첫 화면이나 스크린샷에도 보이게 할지는 선택입니다. 스크린샷 한 장에 정보 화면을 넣으면 좋습니다.

## B. 위험 목록 (높음 → 낮음)

### 1. 광고·결제를 넣을 때 (지금은 없음, 넣는 순간 위험 증가)
- 개인정보처리방침, 데이터 보안 양식, 광고 ID 선언, 대상 연령 설정을 모두 다시 해야 합니다.
- 보상형 광고 SDK는 기기 식별자를 수집합니다. 지금 문서의 "수집 없음"이 거짓이 됩니다.
- 유료 아이템이 확률형이면 한국 게임산업법의 확률 공개 의무가 생깁니다. (개인 장비에 확률 요소가 있으므로 결제와 묶지 마세요.)
- 광고를 2배 보상으로 연결하는 구조는 괜찮지만, 광고 시청을 **강제**하지 않아야 합니다.

### 2. 개인정보·데이터 안전
- 사실상 수집이 없어서 위험이 낮습니다. 단, 방침 내용과 실제 앱이 어긋나면 정책 위반입니다.
- `AndroidManifest.xml`에 **INTERNET 권한이 있습니다.** 지금 코드는 네트워크 요청을 하지 않으므로 필요 없는 권한일 가능성이 큽니다. 권한이 있으면 "인터넷을 쓰는 앱"으로 보여 질문을 받을 수 있습니다. 제거 후 실기기에서 정상 실행되는지 확인하는 것을 권장합니다. (아직 변경하지 않았고 실기기 확인도 못했습니다.)
- `allowBackup="true"`: 게임 저장이 Android 백업에 포함됩니다. 방침 4항에 적어 두었습니다. 끌지 켜 둘지는 선택입니다.

### 3. 저작권·상표
- 그림: 코드로 직접 그린 픽셀 그림이라 외부 그림 저작권 위험은 낮습니다. 실제 무기를 닮은 모양이 있을 수 있으나 "모양을 베끼지 않았다"는 주석만 있고 법적 판단은 못했습니다.
- 소리: 0.52.0부터 직접 합성한 효과음만 사용합니다. ElevenLabs 생성 음원은 앱에 없습니다. 출시 전 `npm run audio:verify`로 다시 확인하세요.
- 라이브러리: Capacitor, Vite 등 MIT 라이선스. `public/THIRD_PARTY_NOTICES.txt`에 고지문이 있습니다. 앱 안에서 이용자가 볼 수 있는지는 확인하지 못했습니다.
- 이름 상표: "부대 키우기"는 평범한 말이라 등록 상표와 겹칠 수 있습니다. "동람코", "아스테라", "세르딘", "이스트라" 같은 고유명칭도 마찬가지입니다. **특허정보검색서비스(KIPRIS)와 Google Play 검색으로 직접 확인**해야 합니다. 저는 확인하지 못했습니다.
- 앱 아이콘과 스토어 이미지는 AI로 만들었다면 해당 도구의 이용 약관(상업적 이용 여부)을 기록해 두세요.

### 4. 군사·폭력 소재 정책
- 허구 세계의 픽셀 전투라 허용 범위로 보이나, 최종 판단은 Google 심사입니다.
- 피하세요: 실제 국기·군복 마크·실제 분쟁·테러 표현, 실제 지명, 실제 무기 상표 이름.
- ICBM, 레일건 같은 이름은 일반 용어입니다. 문제 소지는 낮지만 설명에서 실제 국가를 암시하는 말은 쓰지 마세요.
- 적 표식이 십자 모양입니다. 혐오 상징으로 오해될 모양이 아닌지 스크린샷으로 한 번 더 보세요.
- 이등병·대원수 같은 계급은 한국 군대 용어를 따옵니다. 실제 군 조직을 홍보하거나 사칭하는 표현은 없습니다. 병무청·국방부 이름은 쓰지 마세요.

### 5. 한국 게임 관련 법규 (확인 필요)
- 게임물 등급: Play 스토어 배포 게임은 Google의 IARC 등급 설문으로 등급이 붙는 방식이 일반적입니다. 정확한 현재 규정은 직접 확인해야 합니다.
- 무료 게임 + 광고 없음 상태에서는 통신판매업 신고 등의 부담이 작습니다. 수익이 생기면 사업자 등록·세금 확인이 필요합니다.
- 개인 개발자가 Play에 등록하면 **개발자 이름·주소·이메일이 스토어에 공개**될 수 있습니다. 사업자라면 해당 사항을 계정 설정에서 확인하세요.

### 6. Google Play 테스트 규칙
- 개인 계정은 12명 이상이 14일 연속 참여해야 정식 출시 신청이 가능합니다. 일정표와 맞는지 날짜를 세어 두세요.
- 테스터 가입 이메일을 모으면 그 이메일은 개인정보입니다. 모집 글에 목적을 적고 테스트 후 폐기하세요.

### 7. 기타
- 앱 이름·설명에 "공식", 다른 게임 이름, 인기 게임 이름을 넣으면 정책 위반(키워드 스팸)입니다.
- 스토어 문구에서 "누구나 대원수가 될 수 있다" 같은 과장은 피하세요. 성장 속도에 대한 약속은 하지 마세요.
- 서명 키(upload.p12, JSON)를 잃으면 업데이트가 막힙니다. 외부에 백업하세요.

## C. 확인하지 못한 것

- 실기기 화면, 실제 스토어 이미지, 앱 안 고지문 노출 여부
- 상표 검색 결과와 법률 전문가 의견
