## 출전과 난이도

- 일병부터 메뉴를 볼 수 있다. 실제 출전은 대위 이상이면서 군사 장비를 보유해야 한다. 홈 보관 상태인 장비도 출전 가능하며, 적어도 하나를 선택해야 한다.
- 권장 전력은 출전 제한이 아니다. 순서대로 점령했다면 일찍 도전하거나, 더 성장한 뒤 재도전할 수 있다. 소령·준장 진급의 별도 병력 조건은 유지한다.
- `src/campaign-progression.js`의 기준점을 사용해 전력은 등비, 강화·출격 주기는 선형 보간한다. 지역별 전력은 계속 증가한다.
- 1~5지역은 견인포만 가진 대위의 연습 구간이다. 적은 해당 지역 권장 계급에서 해금되는 장비만 사용한다. 적 구성은 초기 생성 후 재사용한다.
- 후반 적 기갑·공중 부대는 레일건 전차·항공모함·공중요새를 간헐적으로 사용한다. 새 적 장비의 기본 피해는 기지 즉사를 막도록 별도로 보정한다. 아군 장비 능력치는 바꾸지 않는다.
- 적 본부 체력은 권장 전력과 장비 화력에 맞춰 보정한다. 후반 적 구성에 따른 방어 시간도 반영하므로 본부 체력 자체가 매 지역 증가하는 방식은 아니다. 수도는 직전 지역보다 전력 대비 체력이 높고 요새 방어 효과를 유지한다.
- 일반 45~90초, 수도 90~150초를 목표로 한다. 전투 제한 시간은 기존 3분이다. 권장 강화에 +11 이상이 있으면 사단기도 그 단계를 열 수 있도록 강화해야 한다.

## 보상

| 보상 | 승리 시 초당 수입 기준 |
| --- | ---: |
| 일반 지역 최초 점령 | 900초(15분) |
| 20·40·60·80 수도 최초 점령 | 3,600초(1시간) |
| 모든 재도전 | 30초 |

- 별 1개는 기본, 2개는 1.25배, 3개는 1.5배. 승리 1별 + 빠른 승리 또는 본부 체력 50% 이상이면 2별 + 둘 다면 3별이다. 빠른 승리는 일반 75초, 수도 120초다.
- 새 지역마다 영구 초당 수입 +1%p, 총 80%를 유지한다. 재도전에서는 중복 적용하지 않는다. 보상 골드는 새 점령 효과가 적용된 초당 수입으로 계산한다.
- 준비 화면은 1별 기본 보상을 표시한다. 실제 지급은 승리 시 수입·별 성적·골드 상한에 따라 정산한다. BigInt 공통 연산을 사용하고 1,000경 상한을 지킨다.
- 과거 완료한 수도 보상을 소급 지급하지 않는다. 이미 지급된 골드를 회수하지 않는다. 기존 최고 별은 더 나은 기록을 얻을 때만 바꾼다.

## 검증과 한계

`node tools/campaign-sim.mjs`는 실제 저장과 무관한 부대로 80지역을 계산한다. 해당 계급에서 가능한 모든 장비를 종류별 1문, 권장 강화로 보유하고 기본 추천 덱을 사용한다. 약 0.5초마다 마나·대기가 허용하는 장비를 가장 가까운 적의 레인에 출격한다. 수동 플레이에서 놓칠 수 있는 적을 항상 인지하는 모델이므로 사용자 체감과 같다는 뜻은 아니다.

결과는 `campaign-simulation-0.65.json`에 보관한다. 권장 장비를 덜 보유했거나 강화가 낮다면 더 어려울 수 있다. 일반 52.25~89.95초, 수도 90.05/102.15/122.3/100초에 승리한다. 수도에서 중앙만 공격하는 모델은 4곳 모두 패배하며, 최종 수도는 전력 1/4로 승리하지 못한다.

폰 테스트에서는 첫 견인포의 레인 선택, 첫 수도 난이도, 새 장비 획득 전후의 시간, 1~3별 보상의 체감 가치를 확인한다. 우선 이 기준으로 배포 전 플레이 피드백을 받고 조정한다.
