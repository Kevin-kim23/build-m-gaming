# 저장·작은 화면 검증

## 개인 장비 확률 강화

`npm run qa:personal` 실행 후 http://127.0.0.1:4199/__personal-check 를 엽니다. 실제4173과 분리되며 앱에 포함되지 않는 도구입니다.

1. **이전 형식18**: 게임 확인 → 장비 → 개인 장비의4종이Lv.1, 원래 지급 계급 표시. 기존 군사 장비7종20강·배치4종 유지.
2. **전체Lv.1**: 상세보기 → 강화는100% 성공. 정확한 비용 소모, 다음 확률95%, 재접속 후Lv.2 유지.
3. **전체Lv.9**:30%의 실제 난수로 강화. 실패는 비용 소모·Lv.9 유지, 성공은Lv.10·추가 강화 없음. 결정적 성공/실패 경계는 자동 검사로 확인합니다.
4. **골드 부족/대령 잠금**: 부족 버튼 비활성, 미보유 장군검에 강화 시도 없음.
5. **전체Lv.10**: 지휘봉 중령까지100명, 장군검120초, 사단기20강, 리볼버150초·500회. 홈에서 스킬 시작·재접속 후 남은 시간 확인.
6.320×568와390×844에서 상세/확률표/스킬 이름이 가로로 넘치지 않는지 확인합니다. 검증 페이지의 그림50종으로 단계별 외형도 비교합니다.
7. 문서 생성 `npm run docs:personal`. `npm test`가 공개 문서와 실제 정의의 일치를 검사합니다.

8. **형식19 유료Lv.7**: 기존4종 Lv.7 보존, 언월도만 Lv.1, 새 군사 장비 미보유.
9. **대장 신규 장비 / 준원수 신규 장비**: 계급별 레일건/ICBM 구매·잠금·강화·배치/보관을 확인합니다.
10. **새 장비20강 배치**: 연병장 HTML 이름표와 전투 상면/자동 공격 확인. 갤러리에는 두 군사 장비의0/5/10/15/20강 비교도 있습니다.

## 저장 오류

`npm run qa:save` 실행 후 http://127.0.0.1:4198/__save-check 를 엽니다.
실제 플레이용 4173과 별도 저장 공간이며 4198에서만 테스트 기록을 만들 수 있습니다.
이 설정은 개발 서버 전용이고 앱 빌드에는 포함되지 않습니다.

1. **정상 준원수** → 게임 확인: 320×568 / 390×844 화면에서 장군검·리볼버 이름, 사용 중 타이머, 배경 버튼이 겹치거나 잘리지 않는지 확인합니다. 버튼 높이는 44px 이상, 홈 가로 넘침은 없어야 합니다.
2. **손상 + 보조 복구** → 게임 확인: 복구 안내, 준원수·큰 금액을 확인합니다. 저장 확인에서 `save.parse`의 원인 코드가 보이고 문의용 정보에 저장 원문이 없어야 합니다.
3. **둘 다 손상** → 게임 확인: 진행이 막히고 저장 확인 → 안내·문의용 정보 복사·저장 다시 확인이 보여야 합니다. 원본을 초기화하는 버튼은 없습니다.
4. **새 버전 기록**: 기존 보조 저장으로 되돌리지 않고 업데이트 안내와 진행 잠금을 확인합니다.
5. **주 저장 누락**: 남아 있는 보조 저장에서 준원수를 복구해야 합니다.

자동 검사: `node --test tests/save-diagnostics.test.js tests/session.test.js tests/info-panel.test.js`.
금액·저장·이전 버전 호환을 포함한 전체 검사는 `npm test`, 출시용 웹 검사는 `npm run build`입니다.

손상 원본 보관 키는 `budae-kiugi-recruits-v3-recovery`입니다. 보조 저장으로 복구할 때 덮어쓰기 전에 최근 손상 원문 1개를 보관합니다. 이 공간에도 쓸 수 없으면 원본 교체를 중단합니다. 둘 다 손상됐거나 미래 버전이면 원래 저장을 그대로 두고 진행을 막습니다. 원문은 문의용 로그에 포함되지 않습니다. 이 보관 키는 자동 복원이나 과거 장비 수량 환급 기능이 아닙니다.

## 원수 계열·최고 사령부 (0.38)

npm run qa:marshal → http://127.0.0.1:4197/__marshal-check. 실제4173과 다른 저장 공간에서 네 계급 그림·상위 건물 비교, 계급별 기록과 진급 직전 기록을 선택합니다. 검증용 게임에서 1명 모집으로 경계 진급과 새 훈장, 연병장·계급 안내·진급식을 확인합니다.320/390px 작은 화면, 새로고침과 기존 형식20 자산 보존도 확인합니다. 이 도구는 앱 빌드에 포함되지 않습니다.

## 효과음 검증 (0.51.2)

`npm run audio:verify`는 효과음40개의 파일/해시와 불필요한 음원 잔존 여부를 확인합니다. `npm run android:sync`는 이 검사와 빌드 후 복사합니다. 과거 음악 폴더가 남으면 먼저 삭제해야 합니다. 제작·복원은 [AUDIO_SETUP.md](../docs/AUDIO_SETUP.md)를 참고하세요.

## 0.52.0 현재 오디오·안드로이드 도구

현재 audio:verify는 음원 복원을 요구하지 않고 과거 녹음 파일/ZIP 혼입을 차단합니다. android:doctor/key/apk/release 명령은 docs/ANDROID_RELEASE.md를 참고하세요. 과거 음원 가공 도구는 출시 경로에서 사용하지 않습니다.

## 성장 밸런스 (0.54)

`npm run balance:simulate -- --minutes=7.5 --battles`는 실제 저장에 접근하지 않는 메모리 시뮬레이션입니다. `--minutes=5`/`--minutes=10`으로 활동 시간을 비교하고, `--battles`를 빼면 전투 없는 시나리오입니다. 무한 반복전·개인 장비 유료 강화·광고는 포함하지 않으므로 실제 도달 기간을 보장하지 않습니다. 규칙과 비교 표는 [GROWTH_BALANCE.md](../docs/GROWTH_BALANCE.md)에 있습니다. 준장부터 배경은 자동으로 시멘트가 되며 예전 수동 배경 버튼 검사는 더 이상 적용하지 않습니다.


## 회사 로고와 터치 시작 화면 (0.61.0)

`npx vite --config tools/opening-qa.config.mjs` → `http://127.0.0.1:4205/__opening-check`.
실제 게임과 다른 저장 영역에서만 최초 설치·새 기록·2시간 복귀·특전원수 기록을 만들 수 있습니다.

1. 최초 설치: 로고 → 시작 그림, 문구 중하단 중앙, 게임은 아직 조작 불가. 저장 변경·골드 증가·팝업 없음.
2. 소리 켬/끔: 로고가 설정을 따름. 브라우저가 유성 자동 재생을 거절하면 같은 영상을 무음으로 재생.
3. 시작 터치: 게임에 들어가지만 터치 골드는 지급하지 않음. 복귀 기록은 시작 후 보상 팝업이 열림.
4. 백그라운드 전환/복귀: 같은 화면을 이어가고 영상·세션·타이머를 중복 시작하지 않음.
5. 320×740 / 390×844 / 740×320 가로에서 글자·영상 비율·버튼·화면 넘침 확인.
6. 특전원수 기록: 시작 후 복원된 전투 지도의 국가·지역 이동과 출전 확인.

`npm run audio:verify`는 이 영상 한 개와 시작 이미지의 SHA-256을 검사하며 다른 음원·영상 혼입을 거부합니다. 자산을 정식 교체할 때에는 출처를 확인하고 `docs/opening-assets.json`도 갱신합니다.
