# 부대 키우기

동람코의 Android 부대 성장·점령 게임입니다. 터치와 부대 수입으로 병력을 모집하고, 시설·장비를 강화하며 전투 지역을 점령합니다. 현재 버전은 `package.json`이 기준입니다.

## 실행과 검증

```sh
npm ci
npm run dev
npm test
npm run build
npm run audio:verify
npm run android:release
```

- 웹 주소: http://127.0.0.1:4173/ · Android ID: `com.dongramco.budaekiugi`.
- Android 빌드 환경·서명은 `tools/android-build.ps1`이 확인합니다. 기존 서명 키와 승인된 음악·로고 원본은 비공개 로컬 파일이며 Git에 없습니다.
- 음원 복원은 [음악 안내](docs/MUSIC_SETUP.md), 출시는 [첫 업로드](docs/store/FIRST_UPLOAD.md)를 참고하세요.
- 효과음은 `src/audio-synth.js`로 합성합니다. 배경음악은 승인된 Suno 4곡을 사용합니다.

## 현재 동작과 유지할 규칙

- 저장 키 `budae-kiugi-recruits-v3`, 저장 형식35. 이전 저장 이전 처리를 유지합니다. 실제 사용자 기록으로 테스트하지 않습니다.
- 골드 상한 1,000해: 큰 금액은 `money.js`와 `serializeSave`로 처리합니다.
- 개인 장비 Lv.30 확정 강화, 군사 장비 최대40강. 수치·가격·해금 조건은 각 `src` 공통 정의가 기준입니다.
- 1시간 이상 자리 비움 수입은 최대8시간 정산. 일반 받기 또는 광고 완료 후2배 받기, 동일 보상은 한 번만 지급합니다.
- 광고는 Android에서 별도 선택 동의 후 요청합니다. 현재 release/debug 모두 Google 샘플 광고 ID. 미성년자 보호 설정을 유지합니다. 광고 공급·승인은 AdMob 상태에 달려 있습니다.
- 실제 유료결제는 아직 없습니다. 기존 무료 자동터치 보유는 유지하며 신규 운영 무료 지급은 종료했습니다.
- 설정에서 소리, 게임 정보, 개인정보처리방침 및 오픈소스 라이선스를 확인합니다.

## 0.73.0 은하 계급·사관학교·두 번째 대륙

- 부사령관 이후 은하 준장~은하 원수 5계급과 군사 장비 5종을 추가했습니다. 보라색 금테 계급장에 구릿빛 별 1~5개를 표시합니다.
- 은하연대·은하 사단 이름을 적용하고, 이후 상위 편제는 같은 건물 8개로 성장합니다. 신규 건물 5종과 모든 편제의 전투용 위에서 본 그림을 제작했습니다.
- 은하 사관학교 Lv.1~5는 진급과 골드 조건으로 확장하며 다음 은하 계급 병력의 모집을 엽니다.
- 에테리온 대륙의 4개 국가·80개 지역을 추가했습니다. 새 지역당 초당 수입 +2%, 두 대륙 전체 점령 시 +240%입니다.
- 장비별 발사·반동·연속 사격·충전 모션과 본부 붕괴 연출, 합성 효과음을 보강했습니다. 전투의 아군 본부는 보유한 최대 편제를 사용합니다.
- 계급·편제 안내 전력은 가장 큰 한글 단위까지만 표시합니다. 실제 전력과 진급 계산은 그대로 유지합니다.
- 골드 단위를 해까지 확장하고 보유 상한을1,000해로 올렸습니다. 해·경 단위로 표시하며 저장·구매·복귀 보상은1G까지 정확히 계산합니다.
- 저장34 이전 처리와 정확한 큰 금액 연산을 포함합니다. 검증 결과·서명 빌드·실기기 미확인 사항은 [검증결과](검증결과.md), 설계 수치는 [확장 기록](docs/GALACTIC_EXPANSION.md)을 참고하세요.

## 0.73.1 비공개 테스트 광고 전환

- 물약 지급·복귀2배 보상용 release 광고를 Google 공식 샘플 ID로 전환했습니다. 테스트 광고이며 수익은 발생하지 않습니다.

## 0.73.2 광고 중 배경음악·효과음 정지

- 물약·복귀2배 광고를 요청하기 전에 게임 오디오를 일시 정지합니다. 광고 중 게임 갱신이나 앱 복귀 이벤트가 음악을 다시 켜지 못하도록 잠금을 유지합니다.
- 광고 종료·실패·취소 후 현재 음량/앱 활성 상태에 따라 복원하며 음악 위치와 사용자 설정을 보존합니다. 테스트 광고 설정 및 보상 조건은 그대로입니다.
- 재현 테스트·전체 검사·서명 AAB 결과는 검증결과.md. 실폰에서 배경음악을 켜고 광고 영상과 보상 지급을 다시 확인해야 합니다.
