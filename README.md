응답 원문 없이 가드 차단·통신 오류 종류·HTTP 상태·검사 이름을 구분합니다. 근거 부족은 구분 불가로 남기며 허용 경로는 바꾸지 않았습니다. 회사500/403 이력과 전체 목록 후보는 docs/HOME_RUN_DIAGNOSTICS.md에 정리했습니다. 실제 재조회·배포/.env는 별도 승인입니다. 정책 영향 없음.

## 0.83.11 전 지역 자원 읽기 가드

## 실행과 검증

2026-10-13 집 PC가 서버 담당으로 전환되었습니다. Node22.23.3에서 설치·전체938개 테스트·웹 빌드를 통과했습니다. 보호 도구는 [재작성 사전 검토](docs/HOME_GUARD_REBUILD_REVIEW.md)까지만 완료했고, 제작·Git 보관은 사용자 승인 대기입니다. 로그인과 .env는 도구 검증 후 사용자 직접, 배포는 별도 최종 승인 후 진행합니다. 기능/버전0.83.1·방침11·약관8 변경 없음, 정책 영향 없음입니다.

```sh

npm run android:release
```

- 웹 주소: http://127.0.0.1:4173/ · Android ID: `com.dongramco.budaekiugi`.
- Node 22를 권장합니다(Functions 기준). 루트 `npm ci`의 postinstall이 서버의 별도 잠금 파일로 `npm ci --prefix server`도 실행합니다. `npm test`는 pretest에서 Git 제외 폴더 `server/game`을 앱 소스로 준비한 뒤 검사를 시작하므로 최초 복제에도 수동 준비가 필요 없습니다. 서버 의존성을 앱 번들에 추가하는 변경은 아닙니다.
- `--ignore-scripts`를 선택하면 위 자동 준비는 생략됩니다. 이 경우 `npm ci --prefix server`, `node tools/prepare-server.mjs`를 명시적으로 실행해야 합니다. 루트와 서버 잠금 파일은 모두 유지하며 install 명령은 네트워크 연결이 필요할 수 있습니다.
- 배포·결제·콘솔 변경과 release/AAB 생성은 별도 승인 전 실행하지 않습니다. [미실행 배포 초안](docs/DEPLOY_RUNBOOK_DRAFT.md)의 개발→운영 순서와 중단 조건을 먼저 확인합니다.
- Android 빌드 환경·서명은 `tools/android-build.ps1`이 확인합니다. 기존 서명 키와 승인된 음악·로고 원본은 비공개 로컬 파일이며 Git에 없습니다.
- 음원 복원은 [음악 안내](docs/MUSIC_SETUP.md), 출시는 [첫 업로드](docs/store/FIRST_UPLOAD.md)를 참고하세요.
- 효과음은 `src/audio-synth.js`로 합성합니다. 배경음악은 승인된 Suno 4곡을 사용합니다.
