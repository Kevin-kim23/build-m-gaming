# 부대 키우기 · 장성 장비와 연병장 0.20

## 기본 플레이

빈 땅과 0골드로 시작합니다. 화면을 터치해 골드를 모으고 상점에서 병력을 모집합니다. 이번 단계는 기능 구현과 밸런스 확인이 목적이며 그림과 화면 배치는 임시입니다.

| 병력 | 모집 해금 | 1명당 초당 수입 | 1명당 터치 보상 증가 | 1명당 전력 | 최초 모집비 |
|---|---|---:|---:|---:|---:|
| 일반병 | 시작부터 | 1G | 10G | 1 | 50G |
| 하사 | 부사관학교 Lv.1 | 50G | 300G | 10 | 10,000G |
| 중사 | 부사관학교 Lv.2 | 150G | 1,000G | 20 | 50,000G |
| 상사 | 부사관학교 Lv.3 | 1,000G | 6,000G | 40 | 300,000G |
| 원사 | 부사관학교 Lv.4 | 4,000G | 24,000G | 80 | 1,500,000G |
| 소위 | 사관학교 Lv.1 | 15,000G | 100,000G | 160 | 8,000,000G |

홈에는 해금했거나 보유한 병종의 실제 인원을 표시합니다. 병종이 많아지면 가로로 밀어 확인하며 연병장 높이를 더 줄이지 않습니다. 일반병의 녹색 헬멧, 하사·중사·상사·원사의 남색·갈색·보라색·적갈색 베레모와 줄 수, 소위의 푸른 모자와 밝은 마름모로 구분합니다. 그림은 직접 작성했습니다.

총 전력은 각 병종의 보유 수 × 전력 합계입니다. 초당 수입과 터치 보상도 각 병종의 표 수치에 배치 장비 보너스를 더합니다. 기본 터치 1G는 유지합니다. 예를 들어 일반병 160명·하사 1명은 전력 170, 초당 210G, 터치 1,901G입니다.

## 군사학교와 모집 가격

상점은 **군대 모집 / 장비 구매 / 개인 장비 / 군사학교** 네 분류입니다. 군대 모집에서 부사관 4종은 시작부터 잠금 상태와 필요한 학교 레벨을 보여줍니다. 계급으로 모집을 해금하지 않습니다. 소위 카드는 부사관학교 Lv.5부터 공개합니다. 학교는 한 채씩 즉시 건설·확장하며 자체 수입이나 전력은 없습니다.

| 시설·목표 레벨 | 해당 단계 비용 | 해금 |
|---|---:|---|
| 부사관학교 Lv.1 | 30,000G | 하사 모집 |
| 부사관학교 Lv.2 | 300,000G | 중사 모집 |
| 부사관학교 Lv.3 | 3,000,000G | 상사 모집 |
| 부사관학교 Lv.4 | 15,000,000G | 원사 모집 |
| 부사관학교 Lv.5 | 60,000,000G | 사관학교 건설 공개 |
| 사관학교 Lv.1 | 150,000,000G | 소위 모집 |

부사관학교는 별도 계급 조건 없이 골드로 순서대로 확장합니다. **사관학교는 부사관학교 Lv.5와 소장 이상을 모두 충족**해야 건설할 수 있습니다. 전력이 충분해도 하사 40명 조건을 채우지 못해 실제 계급이 대위라면 건설할 수 없습니다. 사관학교는 현재 Lv.1까지입니다.

병종별 현재 보유 수 N만 가격 계산에 사용하며 서로 독립적입니다. 하사·중사는 이전보다 최초 비용과 증가 폭을 낮췄습니다. 수입은 유지하므로 같은 골드로 더 많이 모집할 수 있습니다.

| 병종 | 모집 가격(G) |
|---|---|
| 일반병 | 50 × 1.2^N과 50 + 50N + 0.05N² 중 작은 값을 10G 단위로 올림 |
| 하사 | 10,000 + 2,000N + 200N² |
| 중사 | 50,000 + 8,000N + 600N² |
| 상사 | 300,000 + 40,000N + 2,500N² |
| 원사 | 1,500,000 + 150,000N + 8,000N² |
| 소위 | 8,000,000 + 600,000N + 25,000N² |

일반병은 중령의 지휘봉으로 100명 일괄 모집도 가능합니다. 비용은 현재 N명부터 N+99명까지 100회 가격을 합한 값이며 골드와 전력 공간이 모두 충분할 때만 처리합니다. 대령의 지휘봉 Lv.2부터는 하사도 100명 일괄 모집할 수 있으며 부사관학교 Lv.1이 필요합니다. 나머지 간부는 1명씩 모집합니다. 병력을 서로 교환하거나 소모하지 않습니다. 최대 총 전력은 1,310,720(야전군 4개)입니다. 학교·신규 병종 밸런스는 첫 시제품 수치이며 장기 플레이 검증은 남아 있습니다.

## 계급별 공개와 장비

| 항목 | 처음 보이는 계급 (잠금) | 해금·지급 계급 | 최초 가격 |
|---|---|---|---:|
| 견인포 | 중위 | 대위 | 1,000,000G |
| 전차 | 대위 | 소령 | 5,000,000G |
| 자주포 | 소령 | 중령 | 15,000,000G |
| 공격헬기 | 중령 | 대령 | 45,000,000G |
| 개인 장비 지휘봉 Lv.1 | 소령 | 중령 | 무료 자동 지급 |
| 지휘봉 Lv.2 | 지휘봉 안내 | 대령 | 무료 자동 확장 |
| 개인 장비 장군검 Lv.1 | 대령 | 준장 | 무료 자동 지급 |

장비와 개인 장비는 기존처럼 해금 계급의 바로 이전 계급부터 잠금 공개합니다. 아직 공개되지 않은 장비는 구매·관리 목록에 나오지 않습니다. 부사관과 소위의 모집 해금은 위 군사학교 규칙을 따릅니다.

견인포·전차·자주포·공격헬기는 종류별 1대씩 보유하고 각각 최대 10강까지 강화합니다. 구매 즉시 연병장 하단 왼쪽부터 견인포 → 전차 → 자주포 → 공격헬기 순서로 배치합니다. 두 대 이상일 때 터치 안내를 장비 아래로 옮겨 겹침을 방지합니다. 별도 장비 구역은 없습니다.

| 장비 | 0강 초당 / 터치 보너스 | 1강마다 추가 | 10강 초당 / 터치 보너스 |
|---|---|---|---|
| 견인포 | 500 / 3,000G | 100 / 600G | 1,500 / 9,000G |
| 전차 | 2,500 / 15,000G | 500 / 3,000G | 7,500 / 45,000G |
| 자주포 | 8,000 / 50,000G | 1,600 / 10,000G | 24,000 / 150,000G |
| 공격헬기 | 25,000 / 150,000G | 5,000 / 30,000G | 75,000 / 450,000G |

장비 탭에서 종류를 선택해 강화·보관·재배치합니다. 배치한 장비의 보너스만 합산합니다. 보관해도 강화 단계는 유지되며 다른 장비의 상태를 바꾸지 않습니다. 장비는 진급 전력에 포함되지 않습니다.

강화 성공률은 100%, 실패·파괴 없이 한 단계씩 진행합니다. 현재 L강일 때 다음 강화 비용은 **구매 가격 ÷ 4 × 1.4^L**을 10,000G 단위로 올림합니다. 첫 강화는 견인포 25만, 전차 125만, 자주포 375만, 공격헬기 1,125만 골드입니다. 네 장비 모두 매 단계 외형이 변하고, 견인포의 바퀴·전차의 낮은 포탑·자주포의 높은 포탑과 긴 포신으로 구별합니다. 이 가격과 보너스는 초기 테스트 밸런스입니다.

**개인 장비 지휘봉**은 소령 때 잠금으로 처음 공개하고, 중령 이상이면 Lv.1을 자동으로 보유해 일반병 100명 모집을 해금합니다. 대령부터 Lv.2로 자동 확장되어 하사 100명 모집을 추가하며 일반병 기능도 유지합니다. 실제 하사 40명 조건을 포함한 계급 판정을 사용하며, 이미 중령 이상인 기존 저장에도 적용됩니다. 구매나 수령 버튼을 누를 필요가 없습니다. 현재는 별도 장착·해제·수동 강화 기능이 없고 전투 장비로 출전시키지 않습니다. 보유 여부를 계급에서 계산해 중복 저장이나 중복 지급을 만들지 않습니다.

## 진급과 편제

진급은 **일반병으로 환산한 전력**으로 계산하며, 소령 이상은 **실제 하사 40명 보유**도 필요합니다. 전력 640 이상이어도 하사가 39명이면 대위에 머뭅니다. 일반병이나 중사로 하사 보유 조건을 대신할 수 없습니다. 홈과 상점에 두 조건을 함께 표시합니다. 일반병 230명에 하사 1명을 추가하면 전력 240으로 중위에 진급합니다.

| 계급 | 필요 전력 | 편제 기준 |
|---|---:|---|
| 이등병 | 0 | 시작 |
| 일병 | 4 | 병사 4명 |
| 상병 | 10 | 병사 10명 |
| 병장 | 15 | 병사 15명 |
| 하사 | 20 | 1개 분대 |
| 중사 | 40 | 2개 분대 |
| 상사 | 60 | 3개 분대 |
| 원사 | 80 | 4개 분대 |
| 소위 | 160 | 2개 소대 |
| 중위 | 240 | 3개 소대 |
| 대위 | 320 | 4개 소대 |
| 소령 | 640 | 2개 중대 + 하사 40명 |
| 중령 | 1,280 | 4개 중대 |
| 대령 | 5,120 | 4개 대대 = 1개 연대 |
| 준장 | 10,240 | 일반병 5,000명 + 하사 300명 |
| 소장 | 20,480 | 4개 연대 = 1개 사단 |
| 중장 | 81,920 | 4개 사단 = 1개 군단 |
| 대장 | 327,680 | 4개 군단 = 1개 야전군 |

분대 20 → 소대 80 → 중대 320 → 대대 1,280 → 연대 5,120 → 사단 20,480 → 군단 81,920 → 야전군 327,680 전력으로 합칩니다. 각 편제 4개가 모이면 다음 편제 1개가 됩니다. 준장은 전력 10,240과 일반병 5,000명·하사 300명 조건의 계급이며 별도 여단 편제는 이번에 추가하지 않았습니다.

실제 일반병·하사 인원은 소비하지 않습니다. 계급·보유 인원·수입은 전체 전력과 실제 인원으로 계산하고 연병장 그림만 간소화합니다.

| 가장 큰 편제 | 연병장에 표시하는 최소 단위 |
|---|---|
| 중대 미만 | 일반병·하사 개별 그림 |
| 중대 / 대위부터 | 분대 |
| 대대 | 소대 |
| 연대 | 중대 |
| 사단 | 대대 |
| 군단 | 연대 |
| 야전군 | 사단 |

예를 들어 일반병 339명은 중대 1개만 보이고, 340명이 되면 중대 1개와 분대 1개가 보입니다. 숨긴 19명도 실제 보유 수와 수입에는 포함됩니다.

건물·병력은 **큰 편제부터 왼쪽 위 → 오른쪽 → 다음 줄** 순서로 정렬합니다. 상위 건물이 생기면 하위 건물은 상대적으로 더 작아집니다. 장비는 건물 정렬에서 분리해 같은 연병장 하단 왼쪽에 놓습니다. 공간이 부족하면 같은 종류를 대표 그림과 수량으로 묶고 크기를 조정합니다. 별도 장비 구역은 없습니다.

## 도전과제와 훈장

분대부터 야전군까지 아래 **8개 편제를 처음 달성하면 훈장을 각각 1개씩 자동 획득**합니다. 기준은 실제 보유 병력을 환산한 총 전력이며, 화면에 남아 있는 건물 수나 현재 계급으로 판정하지 않습니다. 소령 이상 진급에 필요한 하사 40명 조건도 훈장 획득에는 적용하지 않습니다.

| 처음 달성한 편제 | 훈장 이름 | 필요 총 전력 |
|---|---|---:|
| 분대 | 분대장 | 20 |
| 소대 | 소대장 | 80 |
| 중대 | 중대장 | 320 |
| 대대 | 대대장 | 1,280 |
| 연대 | 연대장 | 5,120 |
| 사단 | 사단장 | 20,480 |
| 군단 | 군단장 | 81,920 |
| 야전군 | 야전군사령관 | 327,680 |

하위 건물이 상위 편제로 합쳐져도 이미 받은 훈장은 계속 보유합니다. 예를 들어 전력 80으로 소대가 생기면 분대 훈장을 유지하면서 소대 훈장을 받습니다. 한 번에 여러 조건을 충족하면 해당 훈장을 모두 받으며 같은 훈장을 반복 지급하지 않습니다. 훈장에는 추가 골드나 능력치 보너스가 없습니다.

홈에는 **획득한 훈장만, 획득 순서대로 왼쪽 위부터 오른쪽으로** 표시합니다. 한 줄은 10개이며 다음 줄도 왼쪽부터 채웁니다. 표시 공간은 두 줄·최대 20개로 준비하고 현재 도전과제는 8개입니다. 도전과제 목록에서 8개의 달성 상태와 필요 전력을 확인할 수 있습니다. 기존 저장도 현재 전력으로 충족한 조건의 훈장을 자동으로 받습니다.

## 스테이지 전투

전투 메뉴는 **일병부터 표시**하며 작전 목록을 볼 수 있습니다. 실제 출전은 **중령부터** 가능합니다. 기존 진급 조건인 실제 하사 40명도 충족해야 합니다. 상대는 가상 국가 **아르덴 연방**이며, 위에서 내려다보는 세로 전장에서 아군은 아래, 옅은 붉은색 적군은 위에 배치합니다.

| 스테이지 | 작전 이름 | 권장 계급 | 적 본부 체력 |
|---|---|---|---:|
| 1·2 | 대대 전투1·2 | 중령 | 1,280 |
| 3·4 | 연대 전투1·2 | 대령·준장 | 5,120 |
| 5·6 | 사단 전투1·2 | 소장 | 20,480 |
| 7·8 | 군단 전투1·2 | 중장 | 81,920 |
| 9·10 | 야전군 전투1·2 | 대장 | 327,680 |

1부터 순서대로 클리어하면 다음 스테이지가 열리며 완료한 스테이지는 재도전할 수 있습니다. 권장 계급은 난이도 안내이고 별도 입장 제한은 아닙니다. 같은 편제의 두 번째 전투는 적 인원·강화·공격 보정이 더 높습니다. 강화와 터치 빈도에 따라 승패가 달라지는 초기 밸런스입니다.

- **출전 준비:** 일반병·하사·중사를 실제 보유 수 안에서 병종별 0~10명 선택하고 보유 장비를 선택합니다. 선택한 병력·장비는 자동 배치합니다. 보관 중인 장비도 출전할 수 있고 홈의 배치 설정은 바뀌지 않습니다. 병력이나 장비를 하나 이상 선택해야 합니다.
- **본부:** 아군 체력은 보유한 가장 큰 **단일 편제의 전력**입니다. 중령의 대대 본부는 1,280, 대령·준장의 연대 본부는 5,120입니다. 총 보유 전력은 병력·장비 공격력에 비례 반영하므로 같은 본부를 쓰는 준장도 대령보다 강해집니다.
- **사격:** 전장을 터치하면 선택한 보병 전원이 일제 사격합니다. 최소 연사 간격은 0.15초입니다. 견인포·전차·자주포·공격헬기와 적군은 자동 공격합니다. 장비는 0~10강의 매 단계마다 공격력과 공격속도가 모두 올라갑니다. 전투 시작 시 확정한 인원·강화·전력으로 해당 전투를 진행합니다.
- **판정:** 이번 전투에서는 모두 상대 본부를 직접 공격합니다. 상대 본부 체력을 먼저 0으로 만들면 승리하고, 아군 본부가 먼저 0이면 패배합니다. 동시에 파괴되거나 진행 시간 3분 안에 승부가 나지 않으면 무승부입니다. 병사·장비의 개별 파괴와 영구 손실은 없습니다.
- **경제·보상:** 전투 보상은 아직 없습니다. 전투 터치는 골드를 주지 않으며 기존 홈 수입 계산은 그대로입니다. 전투 중에도 방치 수입은 쌓입니다. 승리는 클리어 진행도만 기록하며 병력·장비를 소모하지 않습니다.
- **중단:** 일시정지하거나 창을 숨기면 전투가 멈춥니다. 같은 화면으로 돌아온 뒤 직접 계속하기를 눌러 재개합니다. 다른 창이 조작 권한을 가진 동안에는 전투를 진행할 수 없습니다. 전투 메뉴를 닫거나 새로고침하면 진행 중 전투는 끝나며 다시 출전해야 합니다. 전투 중 체력·시간·출전 선택은 저장하지 않습니다.

## 진급 축하

실제 모집으로 계급이 올라갈 때 새 계급과 자체 제작 날개가 상점 위에 나타납니다. 날개가 펼쳐지고 빛 입자가 퍼진 뒤 마지막 구간에서 서서히 사라지며, 총 3초 후 자동으로 닫힙니다. 높은 계급일수록 표시 크기·계급장 크기·빛 입자 수·축하음의 음량과 음 수가 증가합니다. 일병 표시 폭 228px에서 대장 356px까지 증가하며 작은 화면에서는 화면 폭에 맞춰 제한합니다.

일반 모집이나 새로고침에는 축하가 반복되지 않습니다. 효과음 끄기 설정을 존중하며, 소리는 직접 합성한 짧은 상승 음과 화음입니다. 모션 줄이기 설정에서는 날개·입자 움직임을 생략하고 3초간 부드러운 등장·퇴장만 유지합니다. 다른 화면으로 떠나면 연출과 소리를 정리합니다.

## 저장

현재 저장 형식은 **11**입니다. 장군검 사용 시각 `swordActivatedAt`(미사용 null)을 추가하여 효과와 재사용 대기시간을 보존합니다. 형식 2~10은 미사용 상태로 이전합니다. 형식 10에서는 공격헬기 슬롯 `equipment.helicopter`를 추가했고 이전 형식 2~9에는 미보유(null)로 초기화합니다. 형식 9의 학교·간부·자산은 그대로 보존합니다. 형식 9에서 ncoSchoolLevel(0~5), officerSchoolLevel(0~1), masterSergeants, sergeantMajors, lieutenants를 추가했습니다. 사관학교 보유 기록은 부사관학교 Lv.5가 필요합니다. `earnedAchievements`에 획득한 훈장의 ID를 순서대로 저장해 상위 편제로 합쳐진 뒤에도 기록을 보존합니다. 모집으로 새 훈장을 얻으면 모집 거래와 함께 저장하며, 같은 ID를 중복 지급하지 않습니다.

`battleCleared`에는 연속으로 클리어한 스테이지 수 0~10을 계속 저장합니다. 승리 시 바로 저장하고 유효한 직전 저장을 백업합니다. 중복 승리로 추가 보상을 지급하거나 진행도를 낮추지 않으며 순서를 건너뛰는 기록은 거부합니다.

저장 키 **budae-kiugi-recruits-v3**와 기존 `parseSave` 이전 처리를 유지합니다. 형식 **2~10을 11로 이전**하며 현재 전력에 해당하는 훈장을 자동 수여합니다. 형식 7~8의 전투 진행도는 보존하고, 형식 2~6의 전투 진행도는 0으로 시작합니다. 기존 형식에 존재하는 골드·병력·장비 강화와 배치·터치 횟수·효과음·정산 시간·초 미만 수입·저장 순서를 보존하며, 아직 없던 병종은 0명·장비는 미보유로 채웁니다. 형식 2의 초기 터치 저장도 기존 방식으로 읽습니다. 이번 훈장 추가로 기존 경제 수치나 보유 기록을 초기화하지 않습니다. 계급은 전력과 하사 보유 조건에서 계산하므로 중복 저장하지 않습니다.

이전 형식 6에서는 중사 수·전차·자주포를 추가했습니다. 형식 5의 견인포와 형식 3·4의 병력도 계속 이전합니다. 과거 전력만으로 소령 이상이었던 저장은 하사 40명 조건에 따라 계급을 다시 계산하지만 병력·골드·장비는 유지합니다.

모집·장비 구매·강화·보관·재배치 전까지의 수입은 변경 전 보너스로 먼저 정산합니다. 앱을 다시 열 때의 방치 수입은 **최대 8시간**까지 지급하고 초과 시간은 이월하지 않습니다. 초 미만 수입은 보존합니다. 시계를 과거로 돌려도 정산 시간을 되돌리지 않아 같은 구간을 중복 지급하지 않습니다. 서버 검증이 없어 반복적으로 시계를 미래로 옮기는 조작까지 막는 기능은 아닙니다.

홈 터치는 메모리에서 처리하고 **2초 간격으로 묶어 저장**합니다. 구매·강화·배치·소리 설정 변경·전투 승리는 즉시 저장하고 직전의 유효한 저장을 백업합니다. 화면 숨김과 pagehide에서도 경제 기록을 동기적으로 저장합니다. 갑작스러운 프로세스 종료·전원 차단으로 종료 이벤트가 실행되지 않으면 마지막 저장 이후 약 2초의 홈 터치가 유실될 수 있습니다. 저장 장치 오류나 브라우저 타이머 지연이 있으면 더 길어질 수 있으며 오류는 화면에 표시합니다.

Web Locks를 사용해 조작 가능한 창 하나가 저장 권한을 유지합니다. 다른 창은 기록을 표시하되 터치·구매·전투 진행을 차단하며, 기존 창을 숨기거나 닫으면 저장 후 권한을 넘깁니다. 매 터치마다 잠금을 새로 얻거나 저장을 읽지 않습니다. 저장 실패 시 해당 페이지의 미저장 기록을 유지하고 재시도하며, 다른 창에 권한을 넘겨 덮어쓰지 않습니다. 잠금 미지원 환경은 단일 창만 지원합니다. 브라우저 데이터를 삭제하면 기록이 사라집니다. 서버 저장은 아직 없습니다.

0.10에서는 저장 형식 6을 유지하면서 터치 저장을 2초 묶음 처리로 바꾸고 오프라인 보상을 8시간으로 제한했습니다. 0.11은 이 동작을 유지하며 전투 진행도 때문에 저장 형식을 7로 올렸습니다.

0.12에서는 상점 분류와 100명 모집을 추가하면서 저장 형식 7과 기존 저장 키를 유지했습니다. 지휘봉은 현재 계급에서 보유 여부·현재 레벨을 계산하므로 새 저장 필드가 필요 없습니다. 0.13은 영구 훈장 기록을 추가하면서 저장 형식만 8로 올리고 기존 골드·병력·장비·전투 진행도와 이전 저장 호환을 유지합니다.

이전 저장은 기존에 중사를 보유했거나 소령 이상이면 부사관학교 Lv.2, 하사를 보유했거나 소위 이상이면 Lv.1을 인정합니다. 나머지는 미건설이며 새 상사·원사·소위와 사관학교는 미보유로 시작합니다. 신규 형식 9에서는 계급만으로 학교를 자동 지급하지 않습니다.

## 공격헬기 0.15

대령부터 한 대 구매합니다. 중령에서는 잠금으로 공개하고 소령 이하에서는 숨깁니다. 실제 계급 조건에는 하사 40명도 포함합니다. 기본 공격 간격은 1.8초이며 공격력은 기준 전력 1,280당 16입니다. 기존 장비와 같은 전력 배율·강화 공식을 사용합니다. 적군 장비는 견인포·전차·자주포 3종을 명시하여 새 상품 추가로 기존 스테이지 난이도가 자동 변경되지 않게 했습니다.

`src/helicopter-art.js`는 직접 그린 가상 공격헬기 옆모습과 위에서 본 모습입니다. 단계별 장갑·로켓 포드·미사일·센서·안테나가 추가됩니다. 장비 그림과 전투 배경은 기존 캐시를 재사용하며 새 애니메이션 타이머나 저장 루프는 없습니다.

## 개인 장비와 장군 진급 0.17

장군검은 대령 때 잠금 상태로 공개하고 준장부터 Lv.1을 자동 지급합니다. 홈 또는 개인 장비 탭의 사용 버튼을 누르면 **30초 동안 홈 터치 골드가 2배**입니다. 사용 시점부터 **10분 뒤** 재사용하며, 방치 수입·전투 사격에는 적용하지 않습니다. 효과와 대기시간은 앱을 닫아도 실시간으로 지나가며 새로고침으로 초기화되지 않습니다. 지휘봉의 모집 기능은 그대로 유지됩니다.

준장 이상은 **전력 10,240 이상 + 실제 일반병 5,000명 + 실제 하사 300명**을 모두 요구합니다. 소장 이상은 각 계급의 전력 기준과 동일한 인원 조건을 적용합니다. 간부 환산 전력은 실제 인원을 대신하지 않습니다. 5,000명과 300명만으로는 전력 8,000이므로 추가 전력 2,240이 필요합니다. 홈·상점에 각 조건의 현재 값을 함께 표시합니다.

새 조건은 기존 저장에도 적용합니다. 하사가 300명 미만인 기존 장군은 계급이 대령으로 다시 계산될 수 있으나 골드·병력·학교·구매 장비·훈장·전투 기록은 삭제하지 않습니다. 개인 장비의 보유는 현재 계급에서 계산하고, 장군검 사용 시각만 형식 11에 저장합니다. 시계가 과거로 바뀌어도 마지막 정산 시각 이전으로 효과 시간이 되돌아가지 않게 합니다. 서버 시간 검증 없이 기기 시계 조작 전체를 방지하는 것은 아닙니다.

그림은 `src/personal-art.js`에서 192×256 좌표의 자체 픽셀 도형으로 생성·캐시합니다. 장군검은 검은 칼집·금색 장식·붉은 술, 지휘봉은 명암·금속 띠·장식으로 구분합니다. 참고 사진이나 로고는 포함하지 않았습니다.

100명 모집은 해당 병종의 현재 가격부터 100회 가격의 합계이며 할인·무료 지급이 아닙니다. 병종별로 인원이 바뀔 때만 가격 합계를 다시 계산합니다. 하사 100명에는 전력 1,000의 여유가 필요하며 금액·한도가 부족하면 전체 모집을 거절합니다. 기존 거래·백업·한 창 조작 처리를 재사용합니다. 개인 장비 화면·자체 SVG는 `src/personal-panels.js`로 분리했습니다.

## 0.18 픽셀 아트 개선

병력 6종·편제 건물·학교·훈장·장비·전투 그림에 명암과 세부 장식을 추가. 캔버스 원본은 기존 격자의 3배 해상도로 만들고 종류/강화별 캐시를 재사용합니다. 헬기 옆모습은 오른쪽 기수. 계급장에 위관 은빛 날개, 영관 금빛 잎, 장성 월계 장식을 추가하고 홈 계급 배경도 계급군에 맞춰 변경합니다. 게임 규칙·저장 형식11은 유지합니다.

## 0.20 장성 장비와 연병장

- 다연장 로켓포는 대령 때 잠금으로 공개하고 준장부터 1억 5천만 G에 1대 구매합니다. 0강 초당 75,000G·터치 450,000G, 강화당 초당 15,000G·터치 90,000G를 추가하며 최대 10강입니다. 강화 비용은 기존 장비 공식을 공유합니다. 전투 기본 공격력은 전력 1,280당 48, 주기는 4.2초이며 기존 전력·강화 배율을 적용합니다. 기존 적군 장비는 그대로입니다. 수치는 초기 테스트 밸런스입니다.
- 연병장은 장비 최대 4대입니다. 빈자리가 있으면 구매 즉시 배치하고, 가득 차면 새 장비를 보관합니다. 보관 중인 장비를 배치하려면 먼저 다른 장비를 보관해야 합니다. 강화는 유지하며 배치 장비에만 골드 보너스가 적용됩니다. 이 제한은 연병장에만 적용하고 전투 출전 선택은 기존 방식입니다.
- 준장부터 홈의 연병장 배경 선택으로 흙/회색 시멘트를 무료 전환합니다. 기존 배경을 기본으로 유지하며 선택은 저장합니다. 실제 계급이 준장 미만이면 흙 배경을 표시합니다.
- 장군검 홈 버튼은 도전과제 아래로 옮겼습니다. 아이콘과 ‘장군검 사용’만 표시하며 사용 중/대기 중에는 버튼의 색·활성 상태와 접근성 이름으로 구분합니다. 상세 능력 설명은 개인 장비 상점에 유지합니다.
- 지휘봉 Lv.3(준장)부터 중사 100명 모집을 추가합니다. 부사관학교 Lv.2도 필요하며, 현재 중사 수부터 100회 단건 가격을 합산하고 전력 2,000의 여유가 필요합니다.
- 저장 형식12: 기존 키를 유지합니다. 형식11 이하의 자산·전투·훈장·장군검 사용시각을 보존하면서 새 장비 미보유와 흙 배경을 추가합니다. 새 코드의 저장은 구버전 앱에서 읽지 못하므로 다른 컴퓨터도 최신 코드를 받아 사용합니다.
