# 부대 키우기

동람코의 Android 부대 성장·점령 게임입니다. 터치와 부대 수입으로 병력을 모집하고, 시설·장비를 강화하며 전투 지역을 점령합니다. 현재 버전은 `package.json`이 기준입니다.

## 실행과 검증

```sh
npm ci
npm run dev
npm test
npm run build
npm run audio:verify
npm run android:release
```

- 웹 주소: http://127.0.0.1:4173/ · Android ID: `com.dongramco.budaekiugi`.
- Android 빌드 환경·서명은 `tools/android-build.ps1`이 확인합니다. 기존 서명 키와 승인된 음악·로고 원본은 비공개 로컬 파일이며 Git에 없습니다.
- 음원 복원은 [음악 안내](docs/MUSIC_SETUP.md), 출시는 [첫 업로드](docs/store/FIRST_UPLOAD.md)를 참고하세요.
- 효과음은 `src/audio-synth.js`로 합성합니다. 배경음악은 승인된 Suno 4곡을 사용합니다.

## 현재 동작과 유지할 규칙

- 저장 키 `budae-kiugi-recruits-v3`, 저장 형식42. 이전 저장 이전 처리를 유지합니다. 실제 사용자 기록으로 테스트하지 않습니다.
- 골드 상한 1,000해: 큰 금액은 `money.js`와 `serializeSave`로 처리합니다.
- 개인 장비 Lv.30 확정 강화, 군사 장비 최대40강. 수치·가격·해금 조건은 각 `src` 공통 정의가 기준입니다.
- 1시간 이상 자리 비움 수입은 최대8시간 정산. 일반 받기 또는 광고 완료 후2배 받기, 동일 보상은 한 번만 지급합니다.
- 광고는 Android에서 별도 선택 동의 후 요청합니다. 현재 release/debug 모두 Google 샘플 광고 ID. 미성년자 보호 설정을 유지합니다. 광고 공급·승인은 AdMob 상태에 달려 있습니다.
- Google Play 일회성 구매로 자동터치·스타터팩을 제공합니다. 실제 가격은 Play 조회값을 사용하며, 기존 무료 자동터치 보유는 유지하고 신규 운영 무료 지급은 종료했습니다. 실결제 검증과 배포 상태는 검증결과.md를 참고하세요.
- 설정에서 소리, 게임 정보, 개인정보처리방침 및 오픈소스 라이선스를 확인합니다.

## 0.79.0 무한 방어전 3단계 (카드·진화)

- 카드: 시작할 때 1장, 웨이브를 막을 때마다 1장씩 쌓임(최대 3장). 왼쪽 금색 카드 버튼을 누르면 전투가 멈추고 3장 중 1장 고르기(등급 색 일반·희귀·전설, 다시 뽑기 판당 1번).
- 진화: 진화권(희귀 카드)을 얻으면 왼쪽에 '진화권' 버튼. 누르면 진화할 수 있는 장비가 파랗게 빛나고, 장비 패널에서 '진화 → 다음 장비'(2차는 두 갈래 버튼). 레벨은 그대로. 지원 칸도 Lv20부터 진화권으로 갈래 진화.
- ICBM: 카드로 얻으면 버튼 표시(준비/남은 초). 누른 뒤 전장을 누르면 그곳에 폭발. 지뢰 카드는 길 위 지뢰 3개로 보임.
- 장비 그림이 레벨에 따라 본편 강화 외형(부품·금장·홍금·성운·은하단)으로 바뀜.
- 시험: tests/defense-cards-ui.test.js(4개). 1080×2340 카드·장비 화면 촬영. 미확인: 실제 폰.
