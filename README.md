# 부대 키우기

동람코의 Android 부대 성장·점령 게임입니다. 터치와 부대 수입으로 병력을 모집하고, 시설·장비를 강화하며 전투 지역을 점령합니다. 현재 버전은 `package.json`이 기준입니다.

## 실행과 검증

```sh
npm ci
npm run dev
npm test
npm run build
npm run audio:verify
npm run android:release
```

- 웹 주소: http://127.0.0.1:4173/ · Android ID: `com.dongramco.budaekiugi`.
- Android 빌드 환경·서명은 `tools/android-build.ps1`이 확인합니다. 기존 서명 키와 승인된 음악·로고 원본은 비공개 로컬 파일이며 Git에 없습니다.
- 음원 복원은 [음악 안내](docs/MUSIC_SETUP.md), 출시는 [첫 업로드](docs/store/FIRST_UPLOAD.md)를 참고하세요.
- 효과음은 `src/audio-synth.js`로 합성합니다. 배경음악은 승인된 Suno 4곡을 사용합니다.

## 현재 동작과 유지할 규칙

- 저장 키 `budae-kiugi-recruits-v3`, 저장 형식33. 이전 저장 이전 처리를 유지합니다. 실제 사용자 기록으로 테스트하지 않습니다.
- 골드 상한 1,000경: 큰 금액은 `money.js`와 `serializeSave`로 처리합니다.
- 개인 장비 Lv.20 확정 강화, 군사 장비 최대30강. 수치·가격·해금 조건은 각 `src` 공통 정의가 기준입니다.
- 1시간 이상 자리 비움 수입은 최대8시간 정산. 일반 받기 또는 광고 완료 후2배 받기, 동일 보상은 한 번만 지급합니다.
- 광고는 Android에서 별도 선택 동의 후 요청합니다. release 운영 ID / debug 샘플 ID. 미성년자 보호 설정을 유지합니다. 광고 공급·승인은 AdMob 상태에 달려 있습니다.
- 실제 유료결제는 아직 없습니다. 기존 무료 자동터치 보유는 유지하며 신규 운영 무료 지급은 종료했습니다.
- 설정에서 소리, 게임 정보, 개인정보처리방침 및 오픈소스 라이선스를 확인합니다.

## 0.72.4 자리 비움 광고 연결과 배포 고지 정리

- 개발용 광고 대체 경로를 실제 Android 보상형 광고에 연결했습니다. 동의·시청 완료·앱 복귀 확인 후에만2배 지급합니다. 취소·실패 시 일반 보상을 유지합니다.
- 게임 정보에 오픈소스 라이선스 메뉴를 추가했습니다. 실제 배포 의존성·Google SDK 내장 고지에서 생성하고 개발 도구를 제외했습니다.
- 미사용 mp3 효과음 재생기·카탈로그와 관련 테스트를 정리하고 합성 효과음 검증은 유지했습니다.
- 큰 기록 문서를 `docs/history/`로 보관했습니다. 방침7·약관4에 자리 비움 광고 보상을 반영했습니다.
- 검증 결과와 실기기·공개 문서 동기화 상태는 [검증결과](검증결과.md)와 [동기화 상태](docs/store/POLICY_SYNC_STATUS.md)를 확인하세요.

## 0.72.5 물약 광고 로딩 안내

- 아이템 광고 버튼을 누르면 선택한 물약 카드에 ‘광고가 곧 재생되어요!’와 회전 스피너를 즉시 표시합니다. 대기 중 중복 요청을 막고 완료·취소·실패 시 해제합니다.
- 직접 작성한 CSS 애니메이션이며 외부 자산/라이브러리 추가 없음. 광고 처리·권한·방침·저장 변화 없음.
- 검증: 전체 테스트 및 웹 빌드 결과는 검증결과.md. 실폰 광고 표시 시점 확인은 별도입니다.

## 0.72.6 계급장 SVG 참조 충돌 수정

- 숨겨진 상점과 계급 안내가 같은 SVG ID를 공유하여 색상·별이 누락되는 오류 수정. 캐시된 원본 그림은 유지하고 화면 인스턴스별 참조만 분리.
- 재현 테스트 추가. 전체 테스트·웹 빌드 및 화면 검증 결과는 검증결과.md. 실기기 확인은 별도.
