# 부대 키우기 · 중사·전차·자주포 시제품 0.9

## 기본 플레이

빈 땅과 0골드로 시작합니다. 화면을 터치해 골드를 모으고 상점에서 병력을 모집합니다. 이번 단계는 기능 구현과 밸런스 확인이 목적이며 그림과 화면 배치는 임시입니다.

| 병력 | 모집 해금 | 1명당 초당 수입 | 1명당 터치 보상 증가 | 1명당 전력 |
|---|---|---:|---:|---:|
| 일반병 | 시작부터 | 1G | 10G | 1 |
| 하사 | 소위 이상 | 50G | 300G | 10 |
| 중사 | 소령 이상 | 150G | 1,000G | 20 |

홈에는 **일반병·하사·중사의 실제 보유 인원**을 따로 표시합니다. 하사·중사는 공개 계급에 도달하면 보입니다. 일반병은 녹색 헬멧, 하사는 남색 베레모·짙은 군복·금색 표식으로 구분합니다. 중사는 갈색 베레모와 금색 줄 표식을 사용합니다. 모두 직접 작성한 픽셀 그림입니다.

**총 전력 = 일반병 수 + 하사 수 × 10 + 중사 수 × 20**입니다. 초당 수입은 **일반병 수 + 하사 수 × 50 + 중사 수 × 150 + 배치 장비의 초당 보너스**, 터치 보상은 **1 + 일반병 수 × 10 + 하사 수 × 300 + 중사 수 × 1,000 + 배치 장비의 터치 보너스**입니다. 기본 터치 1G는 유지합니다. 예를 들어 일반병 160명·하사 1명은 총 전력 170, 초당 210G, 터치 1,901G입니다.

## 해금과 모집 가격

모집 병력과 장비는 **해금 계급의 바로 이전 계급에서만 처음 공개**하고 잠금으로 표시합니다. 해금 후에는 계속 보입니다. 원사 전에는 하사 카드를 숨기고, 원사에서는 잠금으로 표시합니다. 화면 표시뿐 아니라 실제 모집 계산에서도 계급을 검사합니다. 전력 159에서 일반병을 모집해 소위가 되면 상점을 닫지 않아도 바로 해금됩니다. 해금 후에는 골드가 충분해야 모집할 수 있습니다.

일반병 가격에는 **현재 일반병 보유 수 N**만 사용합니다. 두 값 **50 × 1.2^N**, **50 + 50N + 0.05N²** 중 작은 값을 10G 단위로 올림합니다.

하사 가격에는 **현재 하사 보유 수 H**만 사용합니다. 가격은 **100,000 + 30,000H + 3,000H²**G입니다. 처음부터 100,000 → 133,000 → 172,000 → 217,000 → 268,000G 순서로 증가하며, 일반병보다 증가 폭이 큽니다. 후반이 지수 가격으로 막히지 않도록 제곱식으로 조정했습니다.

중사 가격은 현재 중사 보유 수 M에 따라 **1,000,000 + 350,000M + 50,000M²**G입니다. 100만 → 140만 → 190만 → 250만 순서입니다.

세 종류의 가격은 서로 독립적입니다. 일반병을 모집해도 하사 가격은 변하지 않고, 하사를 모집해도 일반병 가격은 변하지 않습니다. 기존 하사는 그대로 유지하며 현재 보유 수에 맞춘 새 가격을 적용합니다.

모집은 골드만 소모하며 일반병을 하사로 바꾸거나 기존 병력을 소모하지 않습니다. 현재 시제품의 최대 총 전력은 1,310,720 (야전군 4개)입니다.

## 계급별 공개와 장비

| 항목 | 처음 보이는 계급 (잠금) | 구매·모집 해금 | 최초 가격 |
|---|---|---|---:|
| 하사 | 원사 | 소위 | 100,000G |
| 견인포 | 중위 | 대위 | 1,000,000G |
| 중사 | 대위 | 소령 | 1,000,000G |
| 전차 | 대위 | 소령 | 5,000,000G |
| 자주포 | 소령 | 중령 | 15,000,000G |

이등병 상점에는 일반병만 나옵니다. 아직 공개되지 않은 장비는 장비 탭의 선택 목록에도 나오지 않습니다. 해금한 이전 항목은 계속 구매·관리할 수 있습니다. 상사는 향후 확장을 위한 예시이며 이번에는 모집 항목으로 추가하지 않았습니다.

장비는 종류별 1대씩 보유하고 각각 최대 10강까지 강화합니다. 구매 즉시 연병장 하단 왼쪽부터 견인포 → 전차 → 자주포 순서로 배치합니다. 두 대 이상일 때 터치 안내를 장비 아래로 옮겨 겹침을 방지합니다. 별도 장비 구역은 없습니다.

| 장비 | 0강 초당 / 터치 보너스 | 1강마다 추가 | 10강 초당 / 터치 보너스 |
|---|---|---|---|
| 견인포 | 500 / 3,000G | 100 / 600G | 1,500 / 9,000G |
| 전차 | 2,500 / 15,000G | 500 / 3,000G | 7,500 / 45,000G |
| 자주포 | 8,000 / 50,000G | 1,600 / 10,000G | 24,000 / 150,000G |

장비 탭에서 종류를 선택해 강화·보관·재배치합니다. 배치한 장비의 보너스만 합산합니다. 보관해도 강화 단계는 유지되며 다른 장비의 상태를 바꾸지 않습니다. 장비는 진급 전력에 포함되지 않습니다.

강화 성공률은 100%, 실패·파괴 없이 한 단계씩 진행합니다. 현재 L강일 때 다음 강화 비용은 **구매 가격 ÷ 4 × 1.4^L**을 10,000G 단위로 올림합니다. 첫 강화는 견인포 25만, 전차 125만, 자주포 375만 골드입니다. 세 장비 모두 매 단계 외형이 변하고, 견인포의 바퀴·전차의 낮은 포탑·자주포의 높은 포탑과 긴 포신으로 구별합니다. 이 가격과 보너스는 초기 테스트 밸런스입니다.

## 진급과 편제

진급은 **일반병으로 환산한 전력**으로 계산하며, 소령 이상은 **실제 하사 40명 보유**도 필요합니다. 전력 640 이상이어도 하사가 39명이면 대위에 머뭅니다. 일반병이나 중사로 하사 보유 조건을 대신할 수 없습니다. 홈과 상점에 두 조건을 함께 표시합니다. 일반병 230명에 하사 1명을 추가하면 전력 240으로 중위에 진급합니다.

| 계급 | 필요 전력 | 편제 기준 |
|---|---:|---|
| 이등병 | 0 | 시작 |
| 일병 | 4 | 병사 4명 |
| 상병 | 10 | 병사 10명 |
| 병장 | 15 | 병사 15명 |
| 하사 | 20 | 1개 분대 |
| 중사 | 40 | 2개 분대 |
| 상사 | 60 | 3개 분대 |
| 원사 | 80 | 4개 분대 |
| 소위 | 160 | 2개 소대 |
| 중위 | 240 | 3개 소대 |
| 대위 | 320 | 4개 소대 |
| 소령 | 640 | 2개 중대 + 하사 40명 |
| 중령 | 1,280 | 4개 중대 |
| 대령 | 5,120 | 4개 대대 = 1개 연대 |
| 준장 | 10,240 | 2개 연대 |
| 소장 | 20,480 | 4개 연대 = 1개 사단 |
| 중장 | 81,920 | 4개 사단 = 1개 군단 |
| 대장 | 327,680 | 4개 군단 = 1개 야전군 |

분대 20 → 소대 80 → 중대 320 → 대대 1,280 → 연대 5,120 → 사단 20,480 → 군단 81,920 → 야전군 327,680 전력으로 합칩니다. 각 편제 4개가 모이면 다음 편제 1개가 됩니다. 준장은 연대 2개 조건의 계급이며 별도 여단 편제는 이번에 추가하지 않았습니다.

실제 일반병·하사 인원은 소비하지 않습니다. 계급·보유 인원·수입은 전체 전력과 실제 인원으로 계산하고 연병장 그림만 간소화합니다.

| 가장 큰 편제 | 연병장에 표시하는 최소 단위 |
|---|---|
| 중대 미만 | 일반병·하사 개별 그림 |
| 중대 / 대위부터 | 분대 |
| 대대 | 소대 |
| 연대 | 중대 |
| 사단 | 대대 |
| 군단 | 연대 |
| 야전군 | 사단 |

예를 들어 일반병 339명은 중대 1개만 보이고, 340명이 되면 중대 1개와 분대 1개가 보입니다. 숨긴 19명도 실제 보유 수와 수입에는 포함됩니다.

건물·병력은 **큰 편제부터 왼쪽 위 → 오른쪽 → 다음 줄** 순서로 정렬합니다. 상위 건물이 생기면 하위 건물은 상대적으로 더 작아집니다. 장비는 건물 정렬에서 분리해 같은 연병장 하단 왼쪽에 놓습니다. 공간이 부족하면 같은 종류를 대표 그림과 수량으로 묶고 크기를 조정합니다. 별도 장비 구역은 없습니다.

## 진급 축하

실제 모집으로 계급이 올라갈 때 새 계급과 자체 제작 날개가 상점 위에 나타납니다. 날개가 펼쳐지고 빛 입자가 퍼진 뒤 마지막 구간에서 서서히 사라지며, 총 3초 후 자동으로 닫힙니다. 높은 계급일수록 표시 크기·계급장 크기·빛 입자 수·축하음의 음량과 음 수가 증가합니다. 일병 표시 폭 228px에서 대장 356px까지 증가하며 작은 화면에서는 화면 폭에 맞춰 제한합니다.

일반 모집이나 새로고침에는 축하가 반복되지 않습니다. 효과음 끄기 설정을 존중하며, 소리는 직접 합성한 짧은 상승 음과 화음입니다. 모션 줄이기 설정에서는 날개·입자 움직임을 생략하고 3초간 부드러운 등장·퇴장만 유지합니다. 다른 화면으로 떠나면 연출과 소리를 정리합니다.

## 저장

저장 형식 6에 중사 수·전차·자주포를 추가했습니다. 기존 형식 3·4·5의 골드·병력·터치 횟수·효과음·정산 시간·초 미만 수입·저장 순서를 보존합니다. 형식 5의 견인포 강화·배치 상태도 보존하며 새 병력은 0명, 새 장비는 미보유로 이전합니다. 형식 3에는 하사 0명을 추가합니다. 기존 전력만으로 소령 이상이었던 저장도 새 하사 조건에 따라 계급을 다시 계산하지만 병력·골드·장비는 유지합니다. 이전 저장 키를 유지하며 0.2 저장도 계속 읽습니다. 계급은 전력에서 계산하므로 중복 저장하지 않습니다.

모집·장비 구매·강화·보관·재배치 전까지의 수입은 변경 전 보너스로 먼저 정산합니다. 앱을 다시 열 때의 방치 수입과 초 미만 수입도 보존합니다. 보조 저장본과 다중 창 잠금을 사용하며 잠금 미지원 환경은 단일 창 사용을 기준으로 합니다. 브라우저 데이터를 삭제하면 기록이 사라집니다. 서버 저장·시계 조작 방지는 아직 없습니다.

## 코드 구성과 최적화

- src/equipment.js: 장비 해금·가격·강화·보너스를 공통 규칙으로 관리.
- src/equipment-art.js: 장비 3종의 강화별 그림 최대 33개를 캐시하고 같은 단계는 다시 그리지 않음.
- src/equipment-panels.js: 상점 장비 카드와 강화·배치 화면.
- src/units.js: 병력별 전력·초당 수입·터치 보상을 분리해 한 곳에서 관리.
- src/game.js: 가격·해금·잔액·한도를 공통 모집 판정으로 처리. UI와 실제 구매가 같은 규칙을 사용.
- src/shop.js: 공개된 병력에 공통 상점 카드 사용. 새 계급 진입 시 목록 갱신.
- src/formations.js와 src/ranks.js: 실제 인원을 보존하면서 야전군·대장까지 편제와 계급 계산.
- src/field-layout.js: 표시할 최소 편제, 상대 크기, 왼쪽 위 정렬, 작은 화면 수량 묶기를 담당. 저장·경제 규칙과 분리.
- src/art.js: 직접 작성한 픽셀 그림. 화면에 보이는 편제·배치 장비의 강화 단계·화면 크기가 같으면 전장을 다시 그리지 않음. 숨긴 일반병의 증가만으로는 그림을 다시 그리지 않음.
- src/main.js: 골드 갱신과 병력 화면 갱신을 분리. 병력·장비 단계·배치 상태가 바뀔 때만 계급·보유 수·편제·수입 표시를 갱신.
- src/promotion.js: 계급별 연출 설정과 3초 표시 수명 관리. CSS의 이동·크기·투명도로만 애니메이션하며 프레임마다 게임 화면을 갱신하지 않음.
- src/audio.js: 오디오 컨텍스트 1개 재사용, 종료 음원 연결 정리, 새 축하음이 시작되면 이전 음 중단.
- src/diagnostics.js: 오류 발생 위치를 로컬 콘솔에 기록. 외부 전송 없음.
- tests/: 진급·해금·가격·혼합 편제·수입·저장 이전 검사.
