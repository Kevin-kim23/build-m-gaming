# 부대 키우기 · 성장 밸런스와 안내 정리 0.54.0

> 최신 변경은 이 문서 **맨 아래**의 버전별 기록에 있습니다. 앱 버전은 `package.json` 한 곳에서만 올리며 안드로이드 `versionName`·`versionCode`와 게임 안 정보 화면이 같은 값을 읽습니다. 0.52부터 합성 효과음만 사용합니다. 과거 음원 ZIP은 복원하지 마세요.

## 골드 상한과 표시 (현재 0.33)

- 보유 골드 상한은 **1,000경 G(10,000,000,000,000,000,000)**입니다. 새 게임은 기존처럼 0G에서 시작합니다.
- 10억 미만은 쉼표 숫자, 10억~1,000억 미만은 만 단위(`12억 3,456만`), 1,000억 이상은 억 단위(`1,000억`, `1조 2,345억`, `100조`)로 표시합니다. 보유 골드·수입·터치는 표시에서만 **버림**, 가격과 부족 금액은 **올림**(`fmtGoldCost`)이라 가격 표시 금액 이상을 가지고 있으면 항상 살 수 있습니다. 1경 이상은 경·조로 표시합니다. 실제 수입·구매·저장은 1G 단위로 유지합니다.
- 홈 잔액·수입·터치 효과, 상점·학교·장비의 가격·강화비·부족 금액에 같은 금액 표시를 적용합니다. 병력·전력·체력·장비 수량은 기존 숫자 표기를 유지합니다.
- `src/format.js`의 공통 포맷터와 최대 256개 표시 결과 캐시를 재사용합니다. 같은 억 구간에서는 포맷을 재계산하지 않으며 홈 잔액 글자도 바뀔 때만 갱신합니다.
- 저장 키와 8시간 오프라인 보상 상한은 유지합니다. 저장 형식21은 안전 정수 범위 밖의 골드를 십진 문자열로 기록하고 읽을 때 BigInt로 복원합니다. 형식2~20의 기록도 이전합니다. 형식19의 유료 개인 장비 레벨은 유지하고 새 언월도만 Lv.1로 추가합니다. 개발용 골드 충전은 요청받은 브라우저 기록에만 적용하며 코드의 초기값에 넣지 않습니다.

상점은 **군대 모집 / 장비 구매 / 군사학교** 세 분류입니다. 장비 메뉴는 **군사 장비 / 개인 장비**로 나눕니다. 군대 모집에서 부사관 4종은 시작부터 잠금 상태와 필요한 학교 레벨을 보여줍니다. 계급으로 모집을 해금하지 않습니다. 소위~중령 장교 카드는 부사관학교 Lv.5부터 공개합니다. 학교는 한 채씩 즉시 건설·확장하며 자체 수입이나 전력은 없습니다.

고급 사관학교는 사관학교 Lv.5에서 공개하며, 각 단계의 계급 조건도 충족해야 합니다. 대령~대장 모집 카드의 해제 조건과 학교 상세보기에서 확인할 수 있습니다.

부사관학교는 별도 계급 조건 없이 골드로 순서대로 확장합니다. **사관학교 최초 건설은 부사관학교 Lv.5와 소장 이상을 모두 충족**해야 합니다. Lv.2~5에 추가 계급 제한은 없습니다. 단계별 비용은 누적 금액이 아니며 병력 모집비는 별도입니다. 소장 구간은 Lv.1~3, 중장 구간은 Lv.4, 대장 구간은 Lv.5를 목표로 가격을 설정했으므로 골드를 충분히 모으면 소장에서도 Lv.5까지 구매할 수 있습니다.

가격 기준: 소장 최소 전력에서 대위 96명을 모집하면 중장 전력에 도달하며, 그 모집비 합계는 2조 3,276억G로 Lv.4 확장비 2조 5,000억G보다 낮습니다. 중장 최소 전력에서 소령 192명으로 대장 전력에 도달하는 모집비는 6조 944억 9,600만G로 Lv.5 확장비 9조G보다 낮습니다. 이는 각 병종을 0명부터 모집하는 비교이며 장비 투자·혼합 병력·터치 빈도에 따라 실제 해금 시점은 달라집니다.

병종별 현재 보유 수 N만 가격 계산에 사용하며 서로 독립적입니다. 0.54에서는 아래 기준식에 일반병 최대8배(최초4명은1배, 보유4명마다+1배), 부사관12배, 소위~중령10배, 대령~대장12배를 적용합니다. 학교 투자와 모집을 번갈아 선택하도록 비용을 높였으며 수입은 유지합니다. [성장 비교와 가정](docs/GROWTH_BALANCE.md)을 확인하세요.

일반병은 중령 진급 보상 지휘봉 Lv.1로 100명 일괄 모집이 가능합니다. 비용은 현재 N명부터 N+99명까지 100회 가격의 합이며 골드와 전력 공간이 모두 충분해야 합니다. 지휘봉은 골드 확률 강화로 성장하며 Lv.2 하사, Lv.3 중사, Lv.4 상사, Lv.5 원사, Lv.6 소위, Lv.7 중위, Lv.8 대위, Lv.9 소령, Lv.10 중령 100명 모집을 차례로 추가합니다. 해당 학교 조건과 1명 모집은 유지하며 병력을 교환하거나 소모하지 않습니다. 최대 총 전력은 335,544,320(총군사령부 4개)입니다. 장기 플레이 밸런스 검증은 남아 있습니다.

강화 성공률은 100%, 실패·파괴 없이 한 단계씩 진행합니다. 현재 L강일 때 다음 강화 비용은 **구매 가격 ÷ 4 × 1.4^L**을 10,000G 단위로 올림합니다. 첫 강화는 견인포 25만, 전차 125만, 자주포 375만, 공격헬기 1,125만 골드입니다. 네 장비 모두 매 단계 외형이 변하고, 견인포의 바퀴·전차의 낮은 포탑·자주포의 높은 포탑과 긴 포신으로 구별합니다. 이 가격과 보너스는 초기 테스트 밸런스입니다.

**개인 장비**는 지휘봉(중령)·장군검(준장)·사단기(소장)·장군 리볼버(중장)·언월도(준원수)를 진급 보상 Lv.1로 자동 지급합니다. 카드는 상세보기만 제공하고 상세 화면 맨 위에서 골드 확률 강화를 합니다. 성공·실패 안내와 늘어나는 능력 설명은 강화 버튼 아래에 배치합니다. 보유 여부는 실제 계급, 레벨은 별도 저장값으로 판단합니다. 진급해도 레벨은 자동으로 오르지 않으며 전투 장비로 출전하지 않습니다. 최대 Lv.10, 실패 시 비용만 소모하고 레벨은 유지합니다. 단계별 확률·정확한 비용·능력은 [개인 장비 강화 확률표](개인장비-강화확률표.md)에 있습니다.

## 진급과 편제

진급은 **일반병으로 환산한 전력**으로 계산하며, 소령 이상은 **실제 하사 40명 보유**도 필요합니다. 전력 640 이상이어도 하사가 39명이면 대위에 머뭅니다. 일반병이나 중사로 하사 보유 조건을 대신할 수 없습니다. 홈과 상점에 두 조건을 함께 표시합니다. 일반병 230명에 하사 1명을 추가하면 전력 240으로 중위에 진급합니다.

| 계급 | 필요 전력 | 편제 기준 |
|---|---:|---|
| 이등병 | 0 | 시작 |
| 일병 | 4 | 병사 4명 |
| 상병 | 10 | 병사 10명 |
| 병장 | 15 | 병사 15명 |
| 하사 | 20 | 1개 분대 |
| 중사 | 40 | 2개 분대 |
| 상사 | 60 | 3개 분대 |
| 원사 | 80 | 4개 분대 |
| 소위 | 160 | 2개 소대 |
| 중위 | 240 | 3개 소대 |
| 대위 | 320 | 4개 소대 |
| 소령 | 640 | 2개 중대 + 하사 40명 |
| 중령 | 1,280 | 4개 중대 |
| 대령 | 5,120 | 4개 대대 = 1개 연대 |
| 준장 | 10,240 | 일반병 5,000명 + 하사 300명 |
| 소장 | 20,480 | 4개 연대 = 1개 사단 |
| 중장 | 81,920 | 4개 사단 = 1개 군단 |
| 대장 | 327,680 | 4개 군단 = 1개 야전군 |
| 준원수 · 별 5개 | 1,310,720 | 4개 야전군 = 1개 집단군 |
| 소원수 · 백색 별 1개 | 5,242,880 | 4개 집단군 = 1개 연합군 |
| 중원수 · 백색 별 2개 | 20,971,520 | 4개 연합군 = 1개 대연합군 |
| 대원수 · 백색 별 3개 | 83,886,080 | 4개 대연합군 = 1개 총군사령부 |

분대 20 → 소대 80 → 중대 320 → 대대 1,280 → 연대 5,120 → 사단 20,480 → 군단 81,920 → 야전군 327,680 → 집단군 1,310,720 → 연합군 5,242,880 → 대연합군 20,971,520 → 총군사령부 83,886,080 전력으로 합칩니다. 각 편제 4개가 모이면 다음 편제 1개가 됩니다. 준장 이상은 일반병 5,000명·하사 300명 조건도 유지하며 별도 여단 편제는 이번에 추가하지 않았습니다.

실제 일반병·하사 인원은 소비하지 않습니다. 계급·보유 인원·수입은 전체 전력과 실제 인원으로 계산하고 연병장 그림만 간소화합니다.

| 가장 큰 편제 | 연병장에 표시하는 최소 단위 |
|---|---|
| 중대 미만 | 일반병·하사 개별 그림 |
| 중대 / 대위부터 | 분대 |
| 대대 | 소대 |
| 연대 | 중대 |
| 사단 | 대대 |
| 군단 | 연대 |
| 야전군 | 사단 |
| 집단군 | 군단 |
| 연합군 | 야전군 |
| 대연합군 | 집단군 |
| 총군사령부 | 연합군 |

예를 들어 일반병 339명은 중대 1개만 보이고, 340명이 되면 중대 1개와 분대 1개가 보입니다. 숨긴 19명도 실제 보유 수와 수입에는 포함됩니다.

건물·병력은 **큰 편제부터 왼쪽 위 → 오른쪽 → 다음 줄** 순서로 정렬합니다. 상위 건물이 생기면 하위 건물은 상대적으로 더 작아집니다. 장비는 건물 정렬에서 분리해 같은 연병장 하단 왼쪽에 놓습니다. 공간이 부족하면 같은 종류를 대표 그림과 수량으로 묶고 크기를 조정합니다. 별도 장비 구역은 없습니다.

## 도전과제와 훈장

분대부터 총군사령부까지 **12개 편제를 처음 달성하면 훈장을 각각 1개씩 자동 획득**합니다. 기준은 실제 보유 병력을 환산한 총 전력이며, 화면에 남아 있는 건물 수나 현재 계급으로 판정하지 않습니다. 소령 이상 진급에 필요한 하사 40명 조건도 훈장 획득에는 적용하지 않습니다.

| 처음 달성한 편제 | 훈장 이름 | 필요 총 전력 |
|---|---|---:|
| 분대 | 분대장 | 20 |
| 소대 | 소대장 | 80 |
| 중대 | 중대장 | 320 |
| 대대 | 대대장 | 1,280 |
| 연대 | 연대장 | 5,120 |
| 사단 | 사단장 | 20,480 |
| 군단 | 군단장 | 81,920 |
| 야전군 | 야전군사령관 | 327,680 |

하위 건물이 상위 편제로 합쳐져도 이미 받은 훈장은 계속 보유합니다. 예를 들어 전력 80으로 소대가 생기면 분대 훈장을 유지하면서 소대 훈장을 받습니다. 한 번에 여러 조건을 충족하면 해당 훈장을 모두 받으며 같은 훈장을 반복 지급하지 않습니다. 훈장에는 추가 골드나 능력치 보너스가 없습니다.

홈에는 **획득한 훈장만, 획득 순서대로 왼쪽부터 오른쪽으로** 한 줄에 최대 19개 표시합니다. 현재 부대 성장 12개와 대륙 정복 7개의 도전과제가 있습니다. 전체 줄을 접거나 개별 훈장을 홈에서 숨길 수 있으며 도전과제 목록에는 계속 남습니다. 기존 저장도 현재 전력·점령 기록으로 충족한 훈장을 자동으로 받습니다.

## 대륙 정복 전투

전투 메뉴는 일병부터 대륙 지도를 보여주며 실제 출전은 기존처럼 중령부터 가능합니다. 가상 대륙 **아스테라**에 4개 국가, 국가마다 20개 지역을 직접 구성했습니다. 처음에는 세르딘만 열리고 다른 국가는 어둡게 잠깁니다. 한 나라의 20개 지역을 차례로 점령하면 다음 국가가 열립니다. 점령한 지역은 재도전할 수 있습니다.

| 국가 | 지역 수 | 첫 지역 권장 전력 | 수도 권장 전력 | 목표 구간 |
|---|---:|---:|---:|---|
| 세르딘 공국 | 20 | 10,240 | 81,920 | 준장~중장 |
| 벨로크 연방 | 20 | 96,000 | 327,680 | 중장~대장 |
| 이스트라 왕국 | 20 | 350,000 | 655,360 | 대장 이후 |
| 노르가드 제국 | 20 | 690,000 | 1,250,000 | 후반 최대 편제 |

**권장 전력은 입장 제한이 아닙니다.** 첫 국가 수도도 전력 81,920 미만에서 도전할 수 있으며, 장비 수량·강화·장교 편성·사격 빈도에 따라 공략 시점이 달라집니다. 첫 나라의 20번째 지역을 중장급 전력의 성장 목표로 잡았습니다.

- **지도:** 화살표로 큰 세로 대륙을 이동하고 +/−로 확대·축소합니다. 나라를 누르면 해당 국가로 확대하며 20개 지역 경계와 진격 순서를 표시합니다. 지역을 누르면 권장 전력·현재 전력과 진격 준비 버튼이 나옵니다. 미점령 후속 지역은 정보만 볼 수 있고 직전 지역 점령 후 출전합니다.
- **출전 준비:** 실제 보유 병력 중 병종마다 최대 10명, 보유 장비를 선택합니다. 장비는 보관 중이어도 출전하며 같은 종류의 추가 구매 수량은 공격력에 합산합니다. 홈의 배치 설정은 바꾸지 않습니다.
- **본부:** 아군 본부 체력은 총 병력 전력과 같습니다. 가장 큰 편제에 따라 본부 그림은 달라지지만 체력은 진급 경계에서 갑자기 4배 뛰지 않고 연속적으로 성장합니다. 적 본부는 지역별 요새 체력이며 일반 지역은 권장 전력의 5.5배, 수도는 7배입니다.
- **사격:** 전장 터치로 모든 출전 보병이 사격하며 연사 간격은 0.15초입니다. 선택한 장비와 적군은 자동 공격합니다. 0~20강의 공격력·속도 증가와 문수 합산을 적용합니다. 전술 수송기는 공격 대신 아군 본부를 회복합니다.
- **밸런스 검증 기준:** 첫 나라의 초반은 일반병~원사, 소장 이후는 일반병~대위 각 최대 10명(실제 장성 진급 인원 조건을 유지하도록 조정), 장비 5종 각각 +8 한 문, 초당 2회 사격입니다. 첫 수도는 전력 81,920으로 36.3초 승리(본부 약 34% 잔존), 같은 편성의 20,480/40,960/61,440은 패배합니다. 이후 나라는 권장 전력에서 장교 편성을 확장하고 장비 5종 +10 각각 세 문·초당 2회 사격을 기준으로 80개 지역 승리를 검사합니다. 장기 골드 성장 속도와 실제 터치 체감은 후속 밸런싱 대상입니다.

- **판정:** 이번 전투에서는 모두 상대 본부를 직접 공격합니다. 상대 본부 체력을 먼저 0으로 만들면 승리하고, 아군 본부가 먼저 0이면 패배합니다. 동시에 파괴되거나 진행 시간 3분 안에 승부가 나지 않으면 무승부입니다. 병사·장비의 개별 파괴와 영구 손실은 없습니다.
- **경제·보상:** 각 지역 최초 점령마다 초당 수입 +1%, 80개 지역 전체 점령 시 +80%입니다. 병력과 배치 장비의 기본 초당 수입 합계에 더하며 터치·리볼버 지급액은 올리지 않습니다. 재도전은 중복 보상이 없고 기존 점령 기록도 소급 적용합니다. 즉시 골드 보상은 없습니다. 전투 중에도 방치 수입은 쌓이고 점령 업적 훈장을 지급하며 병력·장비를 소모하지 않습니다.
- **중단:** 일시정지하거나 창을 숨기면 전투가 멈춥니다. 같은 화면으로 돌아온 뒤 직접 계속하기를 눌러 재개합니다. 다른 창이 조작 권한을 가진 동안에는 전투를 진행할 수 없습니다. 전투 메뉴를 닫거나 새로고침하면 진행 중 전투는 끝나며 다시 출전해야 합니다. 전투 중 체력·시간·출전 선택은 저장하지 않습니다.

## 진급 축하

실제 모집으로 계급이 올라갈 때 새 계급과 자체 제작 날개가 상점 위에 나타납니다. 날개가 펼쳐지고 빛 입자가 퍼진 뒤 마지막 구간에서 서서히 사라지며, 일반 계급은 3초 후 자동으로 닫힙니다. 준장 이상은 아래 0.25 전용 진급식을 사용합니다. 높은 계급일수록 표시 크기·계급장 크기·빛 입자 수·축하음의 음량과 음 수가 증가합니다. 일반 진급식은 일병 표시 폭 228px부터 대령 324px까지 증가하며 작은 화면에서는 화면 폭에 맞춰 제한합니다.

일반 모집이나 새로고침에는 축하가 반복되지 않습니다. 소리 끄기 설정을 존중하며, 0.51부터 ElevenLabs 생성 진급 효과음을 사용합니다. 기존 자체 합성음은 로딩·실패 시 대체 수단입니다. 모션 줄이기 설정에서는 날개·입자 움직임을 생략합니다. 일반 진급식은 3초간 부드러운 등장·퇴장만 유지하고 장성 진급식은 정적인 문장·계급만 표시합니다. 다른 화면으로 떠나면 연출과 소리를 정리합니다.

## 저장

현재 저장 형식은 **19**입니다. 개인 장비 레벨은 personalLevels에, 사용한 리볼버의 지속시간은 autoTouchDurationMs에 보존합니다. 형식2~18의 개인 장비는 Lv.1로 이전하며 골드·병력·군사 장비·진행 중 스킬은 유지합니다. 아래는 이전에 추가한 필드의 설명입니다. 대륙 진행은 `campaignCleared`(0~80)로 저장합니다. 기존 `battleCleared`(0~10)는 옛 전투 완료 기록으로 보존하고, 형식2~14에서 새 대륙 진행은 0부터 시작합니다. 형식14는 새 중위·대위·소령·중령 인원을 저장하고 사관학교 레벨은 0~5를 허용합니다. 형식 2~13에서 새 4종은 0명으로 이전하며 기존 학교 레벨은 유지합니다. 형식13부터 장비마다 `count`를 저장하며 이전 장비는 1문으로 이전합니다. 형식12는 연병장 배경과 다연장 로켓포를 추가했습니다. 형식11에서는 장군검 사용 시각 `swordActivatedAt`(미사용 null)을 추가하여 효과와 재사용 대기시간을 보존합니다. 형식 2~10은 미사용 상태로 이전합니다. 형식 10에서는 공격헬기 슬롯 `equipment.helicopter`를 추가했고 이전 형식 2~9에는 미보유(null)로 초기화합니다. 형식 9의 학교·간부·자산은 그대로 보존합니다. 형식 9에서 ncoSchoolLevel(0~5), officerSchoolLevel(0~1), masterSergeants, sergeantMajors, lieutenants를 추가했습니다. 사관학교 보유 기록은 부사관학교 Lv.5가 필요합니다. `earnedAchievements`에 획득한 훈장의 ID를 순서대로 저장해 상위 편제로 합쳐진 뒤에도 기록을 보존합니다. 모집으로 새 훈장을 얻으면 모집 거래와 함께 저장하며, 같은 ID를 중복 지급하지 않습니다.

`battleCleared`에는 연속으로 클리어한 스테이지 수 0~10을 계속 저장합니다. 승리 시 바로 저장하고 유효한 직전 저장을 백업합니다. 중복 승리로 추가 보상을 지급하거나 진행도를 낮추지 않으며 순서를 건너뛰는 기록은 거부합니다.

저장 키 **budae-kiugi-recruits-v3**와 기존 `parseSave` 이전 처리를 유지합니다. 형식 **2~14를 15로 이전**하며 현재 전력에 해당하는 훈장을 자동 수여합니다. 형식 7~8의 전투 진행도는 보존하고, 형식 2~6의 전투 진행도는 0으로 시작합니다. 기존 형식에 존재하는 골드·병력·장비 강화와 배치·터치 횟수·효과음·정산 시간·초 미만 수입·저장 순서를 보존하며, 아직 없던 병종은 0명·장비는 미보유로 채웁니다. 형식 2의 초기 터치 저장도 기존 방식으로 읽습니다. 이번 훈장 추가로 기존 경제 수치나 보유 기록을 초기화하지 않습니다. 계급은 전력과 하사 보유 조건에서 계산하므로 중복 저장하지 않습니다.

이전 형식 6에서는 중사 수·전차·자주포를 추가했습니다. 형식 5의 견인포와 형식 3·4의 병력도 계속 이전합니다. 과거 전력만으로 소령 이상이었던 저장은 하사 40명 조건에 따라 계급을 다시 계산하지만 병력·골드·장비는 유지합니다.

모집·장비 구매·강화·보관·재배치 전까지의 수입은 변경 전 보너스로 먼저 정산합니다. 앱을 다시 열 때의 방치 수입은 **최대 8시간**까지 지급하고 초과 시간은 이월하지 않습니다. 초 미만 수입은 보존합니다. 시계를 과거로 돌려도 정산 시간을 되돌리지 않아 같은 구간을 중복 지급하지 않습니다. 서버 검증이 없어 반복적으로 시계를 미래로 옮기는 조작까지 막는 기능은 아닙니다.

홈 터치는 메모리에서 처리하고 **2초 간격으로 묶어 저장**합니다. 구매·강화·배치·소리 설정 변경·전투 승리는 즉시 저장하고 직전의 유효한 저장을 백업합니다. 화면 숨김과 pagehide에서도 경제 기록을 동기적으로 저장합니다. 갑작스러운 프로세스 종료·전원 차단으로 종료 이벤트가 실행되지 않으면 마지막 저장 이후 약 2초의 홈 터치가 유실될 수 있습니다. 저장 장치 오류나 브라우저 타이머 지연이 있으면 더 길어질 수 있으며 오류는 화면에 표시합니다.

Web Locks를 사용해 조작 가능한 창 하나가 저장 권한을 유지합니다. 다른 창은 기록을 표시하되 터치·구매·전투 진행을 차단하며, 기존 창을 숨기거나 닫으면 저장 후 권한을 넘깁니다. 매 터치마다 잠금을 새로 얻거나 저장을 읽지 않습니다. 저장 실패 시 해당 페이지의 미저장 기록을 유지하고 재시도하며, 다른 창에 권한을 넘겨 덮어쓰지 않습니다. 잠금 미지원 환경은 단일 창만 지원합니다. 브라우저 데이터를 삭제하면 기록이 사라집니다. 서버 저장은 아직 없습니다.

0.10에서는 저장 형식 6을 유지하면서 터치 저장을 2초 묶음 처리로 바꾸고 오프라인 보상을 8시간으로 제한했습니다. 0.11은 이 동작을 유지하며 전투 진행도 때문에 저장 형식을 7로 올렸습니다.

0.12에서는 상점 분류와 100명 모집을 추가하면서 저장 형식 7과 기존 저장 키를 유지했습니다. 지휘봉은 현재 계급에서 보유 여부·현재 레벨을 계산하므로 새 저장 필드가 필요 없습니다. 0.13은 영구 훈장 기록을 추가하면서 저장 형식만 8로 올리고 기존 골드·병력·장비·전투 진행도와 이전 저장 호환을 유지합니다.

이전 저장은 기존에 중사를 보유했거나 소령 이상이면 부사관학교 Lv.2, 하사를 보유했거나 소위 이상이면 Lv.1을 인정합니다. 나머지는 미건설이며 새 상사·원사·소위와 사관학교는 미보유로 시작합니다. 신규 형식 9에서는 계급만으로 학교를 자동 지급하지 않습니다.

## 개인 장비와 장군 진급 0.17

장군검은 대령 때 잠금 상태로 공개하고 준장부터 Lv.1을 자동 지급합니다. 홈 또는 개인 장비 탭의 사용 버튼을 누르면 **Lv.1~4에 각각 30·40·50·60초 동안 터치 골드가 2배**입니다. 사용 시점부터 **10분 뒤** 재사용하며, 방치 수입·전투 사격에는 적용하지 않습니다. 효과와 대기시간은 앱을 닫아도 실시간으로 지나가며 새로고침으로 초기화되지 않습니다. 지휘봉의 모집 기능은 그대로 유지됩니다.

준장 이상은 **전력 10,240 이상 + 실제 일반병 5,000명 + 실제 하사 300명**을 모두 요구합니다. 소장 이상은 각 계급의 전력 기준과 동일한 인원 조건을 적용합니다. 간부 환산 전력은 실제 인원을 대신하지 않습니다. 5,000명과 300명만으로는 전력 8,000이므로 추가 전력 2,240이 필요합니다. 홈·상점에 각 조건의 현재 값을 함께 표시합니다.

새 조건은 기존 저장에도 적용합니다. 하사가 300명 미만인 기존 장군은 계급이 대령으로 다시 계산될 수 있으나 골드·병력·학교·구매 장비·훈장·전투 기록은 삭제하지 않습니다. 개인 장비의 보유는 현재 계급에서 계산하고, 장군검 사용 시각만 형식 11에 저장합니다. 시계가 과거로 바뀌어도 마지막 정산 시각 이전으로 효과 시간이 되돌아가지 않게 합니다. 서버 시간 검증 없이 기기 시계 조작 전체를 방지하는 것은 아닙니다.

그림은 `src/personal-art.js`에서 192×256 좌표의 자체 픽셀 도형으로 생성·캐시합니다. 장군검은 검은 칼집·금색 장식·붉은 술, 지휘봉은 명암·금속 띠·장식으로 구분합니다. 참고 사진이나 로고는 포함하지 않았습니다.

100명 모집은 해당 병종의 현재 가격부터 100회 가격의 합계이며 할인·무료 지급이 아닙니다. 병종별로 인원이 바뀔 때만 가격 합계를 다시 계산합니다. 하사 100명에는 전력 1,000의 여유가 필요하며 금액·한도가 부족하면 전체 모집을 거절합니다. 기존 거래·백업·한 창 조작 처리를 재사용합니다. 개인 장비 화면·자체 SVG는 `src/personal-panels.js`로 분리했습니다.

## 0.18 픽셀 아트 개선

## 0.20 장성 장비와 연병장

- 다연장 로켓포는 대령 때 잠금으로 공개하고 준장부터 1억 5천만 G에 1대 구매합니다. 0강 초당 75,000G·터치 450,000G, 강화당 초당 15,000G·터치 90,000G를 추가하며 최대 10강입니다. 강화 비용은 기존 장비 공식을 공유합니다. 전투 기본 공격력은 전력 1,280당 48, 주기는 4.2초이며 기존 전력·강화 배율을 적용합니다. 기존 적군 장비는 그대로입니다. 수치는 초기 테스트 밸런스입니다.
- 연병장은 장비 최대 4종류입니다. 빈자리가 있으면 구매 즉시 배치하고, 가득 차면 새 장비를 보관합니다. 보관 중인 장비를 배치하려면 먼저 다른 장비를 보관해야 합니다. 강화는 유지하며 배치 장비에만 골드 보너스가 적용됩니다. 이 제한은 연병장에만 적용하고 전투 출전 선택은 기존 방식입니다.
- 준장부터 홈의 연병장 배경 선택으로 흙/회색 시멘트를 무료 전환합니다. 기존 배경을 기본으로 유지하며 선택은 저장합니다. 실제 계급이 준장 미만이면 흙 배경을 표시합니다.
- 장군검 홈 버튼은 도전과제 아래로 옮겼습니다. 아이콘과 ‘장군검 사용’만 표시하며 사용 중/대기 중에는 버튼의 색·활성 상태와 접근성 이름으로 구분합니다. 상세 능력 설명은 개인 장비 상점에 유지합니다.
- 지휘봉 Lv.3(준장)부터 중사 100명 모집을 추가합니다. 부사관학교 Lv.2도 필요하며, 현재 중사 수부터 100회 단건 가격을 합산하고 전력 2,000의 여유가 필요합니다.
- 저장 형식12: 기존 키를 유지합니다. 형식11 이하의 자산·전투·훈장·장군검 사용시각을 보존하면서 새 장비 미보유와 흙 배경을 추가합니다. 새 코드의 저장은 구버전 앱에서 읽지 못하므로 다른 컴퓨터도 최신 코드를 받아 사용합니다.


## 0.21 장군검 성장과 장비 추가 구매

- 장군검은 준장1·소장2·중장3·대장4레벨로 실제 계급에 따라 자동 성장하며 외형 장식도 추가됩니다. 0.26부터 터치 골드2배 지속시간은 레벨마다 10초씩 늘어나며 재사용은10분입니다. 추가 구매 능력은 사단기 Lv.1로 이전했습니다.
- 지휘봉은 중령1 일반병 → 대령2 하사 → 준장3 중사 → 소장4 상사 → 중장5 원사 → 대장6 소위 순서로 100명 모집을 추가합니다. 이전 모집 버튼을 유지하며 해당 학교·골드·전력 한도를 검사합니다. 100회 개별 모집 가격 합계를 한 거래로 지불합니다.
- 소장/사단기 Lv.1 이상 + 해당 장비10강 이상일 때 상점과 장비 관리에서 1문씩 추가 구매합니다. 가격은 기본 구매비와 현재 강화 단계까지의 모든 강화비 합계입니다. 아래는10강 기준입니다. 견인포18,490,000G·전차92,300,000G·자주포276,830,000G·공격헬기830,430,000G·다연장 로켓포2,768,040,000G. 매 문 같은 가격이며 할인이나 가격 상승은 없습니다.
- 추가 장비는 현재 강화 단계 그대로이며 같은 종류의 수량에 합칩니다. 전체를 함께 보관·배치하며 배치 상태는 추가 구매로 바뀌지 않습니다. 종류별로 한 칸, 최대4칸입니다. 배치된 문마다 초당/터치 골드를 합산하며 전투에서는 같은 사격 간격에 수량만큼 피해를 더합니다. 보관 장비도 기존처럼 전투에서 선택할 수 있습니다. 적군 수량은1로 유지합니다.
- 저장 키는 유지하고 형식13에 장비 수량을 추가합니다. 형식2~12의 장비는1문으로 이전하며 자산·강화·배치·배경·학교·훈장·전투·장군검 대기시간을 보존합니다. 10강 미만의 복수 장비, 0/분수/문자 수량, 수치 안전 한도(종류별100,000문)를 넘는 기록은 거절합니다.
- 구매 규칙은 equipment.js/game.js, 추가 구매 화면은 equipment-repeat-ui.js, 개인 장비 성장 규칙은 personal-equipment.js에 있습니다. 연병장/전투 캐시 키에 수량을 포함하여 수량 변경 시만 다시 그립니다. CSS 대형 파일은 후속 화면 작업에서 기능별 파일로 나누는 것을 권장합니다.
## 0.24 장군검 시간 표시 · 전투 훈장

홈 장군검을 사용하면 아이콘 둘레에 12시 방향에서 시계 방향으로 소진되는 원형 표시와 남은 초를 보여줍니다. 저장된 사용 시각을 기준으로 계산하므로 화면 전환·새로고침 후에도 남은 시간이 이어집니다. 사용 종료 시 표시가 사라지며 레벨별30·40·50·60초 효과와10분 재사용 규칙을 따릅니다.

기존 부대 성장 훈장 8종에 대륙 정복 훈장 7종을 추가했습니다. 첫 승전(첫 지역), 선봉장(5개 지역), 진격의 지휘관(10개 지역), 세르딘·벨로크·이스트라·노르가드 정복자(각 국가 수도까지 완료)입니다. 같은 지역 재도전은 중복 집계하지 않습니다. 국가 훈장의 진행 숫자는 대륙 전체 누적 점령 수 20·40·60·80입니다.

승리 화면에서 새 훈장을 안내하고 홈 훈장 선반과 도전과제에서 그림·조건·진행도를 확인합니다. 기존 점령 기록에도 훈장을 자동 지급하며 훈장 자체에는 골드·능력치 보너스가 없습니다. 점령 수입 보너스는 0.27 규칙을 따릅니다. 저장 형식15의 기존 campaignCleared/earnedAchievements/swordActivatedAt을 재사용하여 저장 구조와 키를 유지합니다.

## 0.25 장성 전용 진급식

준장·소장·중장·대장 진급에는 금속 명암을 넣은 여러 겹의 금빛 날개, 월계 장식, 보석과 방패, 계급에 맞는 별1~4개가 등장합니다. 대장에는 왕관 장식도 추가합니다. 문구는 장성 진급 / 해당 계급 / 진급을 명합니다로 표시합니다.

양옆 예포가 포신 반동·발사 섬광·연기·불꽃을 내며 순차 발사됩니다. 준장부터 각 포3·4·5·6회, 표시 시간5.3·5.6·5.9·6.2초이며 부대로 돌아가기 버튼으로 바로 닫을 수 있습니다. 대령 이하는 기존 진급식을 유지합니다. 그림은 직접 제작한 SVG를 단계별로 캐시하며 CSS 애니메이션만 사용합니다. 추가 타이머·프레임 저장·경제 수치 변경은 없습니다.

소장 이상 팡파르의 여덟 번째 음이 빠졌던 오류도 수정했습니다. 효과음 설정과 화면 이탈 시 정리 동작은 유지하며, 모션 줄이기 설정에서는 예포·입자·날개 애니메이션을 생략합니다. 기존 저장 형식15 유지.

회복량도 전력·강화·문수에 비례합니다. 본부 최대 체력을 넘지 않으며 같은 순간 파괴된 본부를 되살리지 않습니다. 적군 구성과 기존80지역 난이도는 유지합니다. 항공 장비도4종류 연병장 규칙을 공유합니다. 장기 플레이 체감 밸런스는 추가 조정 대상입니다.

저장 형식16: 기존 키 유지, 형식2~15의 병력·학교·장비 문수·훈장·정복·골드를 보존합니다. 신규 항공 장비는 미보유, 개인 장비 보상은 실제 계급에서 파생합니다. 옛 활성 장군검은30초로 유지하고 다음 사용부터 새 지속시간을 적용합니다. 자동 터치는 사용시각과 지급 완료 횟수를 저장해 재접속/시계 역행/저장 재시도 시 중복 지급을 막습니다. 한 타이머로 스킬 활성 중300ms, 그 외1초 간격에 화면 수치를 갱신하고 기존2초 묶음 저장을 유지합니다.

## 0.27 점령 수입과 지도·스킬 표시

- 지도 이동·확대 버튼을 지도 아래 별도 조작줄로 옮겼습니다. 지도 위 국가명은 작은 화면에서도 17px 이상으로 보이게 조정하고, 현재 화면 중앙에 가까운 국가의 지역 수·수도 권장 전력·지형·잠금 조건을 지도 아래 12px 글씨로 표시합니다. 국가 지도 버튼으로 진입할 수 있습니다.
- 지역 정보에는 최초 점령 +1% 또는 이미 획득한 보너스를 표시합니다. 승리 결과·지도 진행도·홈 초당 수입에 누적 보너스를 표시합니다. 수입 계산은 campaign-rewards.js, 국가 설명은 campaign-brief.js에 분리했습니다.
- 장군검/리볼버 버튼은 도전과제 아래 64×56px로 통일하고 4px 간격으로 붙였습니다. 홈 행동 이름은 장군검 사용/리볼버 사용으로 유지하며, 사용 중 남은 시간과 기존 재사용 규칙을 보존합니다. 리볼버는 256×192 가로형 도형으로 다시 그려 긴 총열과 짧은 손잡이 비율로 바꿨습니다.
- 저장 키와 형식16은 유지합니다. 기존 campaignCleared에서 보너스를 계산하므로 새 필드나 지급 상태를 만들지 않습니다. 첫 승리 전까지 기존 수입으로 정산한 뒤 새 보너스를 적용하며, 저장·재접속·최대8시간 오프라인 수입에도 동일한 비율을 사용합니다.

## 0.27.1 다음 국가 바로 이동

20개 지역을 모두 점령한 국가 지도 위쪽에 ↑ 다음 나라 버튼을 표시합니다. 누르면 대륙 화면을 거치지 않고 다음 국가의 진격 가능한 지역으로 카메라가 자연스럽게 이동합니다. 기존 지역 재도전은 유지하며, 미완료 국가와 마지막 노르가드에는 버튼을 표시하지 않습니다. 저장·경제·전투 난이도는 변경하지 않습니다.

## 0.27.2 이전 국가 바로 이동

벨로크·이스트라·노르가드 지도 아래에 ↓ 이전 나라 버튼을 추가했습니다. 현재 국가를 아직 완료하지 않아도 점령 완료한 바로 아래 국가로 내려갈 수 있습니다. 지도 위의 다음 나라 버튼과 같은 카메라 전환을 사용하며 지역명을 가리지 않습니다. 첫 국가·대륙 지도에는 표시하지 않습니다.

## 0.29 상점 개편과 금액 표시

- **금액 표시**: 10억 미만은 쉼표 숫자, 10억~1,000억 미만은 만 단위(`12억 3,456만`), 1,000억 이상은 기존처럼 억 단위(`1,000억`, `1조 2,345억`, `100조`)로 표시합니다. 보유 골드·수입·터치는 표시에서만 **버림**, 가격과 부족 금액은 **올림**(`fmtGoldCost`)이라 가격 표시 금액 이상을 가지고 있으면 항상 살 수 있습니다. 실제 수입·구매·저장은 1G 단위 그대로입니다(`src/format.js`).
- **공통 상세보기 팝업**: `src/detail-popup.js` 하나를 군대 모집·장비·군사학교·계급 안내가 함께 씁니다.
- **군대 모집 칸**: 아이콘·이름·초당/터치 능력·가격·`1명`/`100명` 버튼만 표시하고 설명은 칸 모서리 ⓘ 상세보기 팝업(`src/unit-detail.js`)에 둡니다. 100명 버튼은 기존 지휘봉 조건을 그대로 따르며 해금 전에는 잠긴 버튼으로 보입니다. 잠긴 병종은 흐리게 + 필요 학교 레벨을 표시합니다(공개 규칙은 기존과 동일). 가격이 길면 칸이 아래로 늘어납니다.
- **장비 구매 칸**: 그림·이름·능력·가격·구매 버튼만 두고 나머지는 ⓘ 상세보기(`src/equipment-detail.js`, 칸은 `src/equipment-tiles.js`).
- **군사학교**: 카드에는 이름·레벨·다음 단계 비용·구매만 두고 레벨별 효과와 비용은 상세보기 팝업으로 옮겼습니다.
- **진급 조건·편제 안내**: 홈 좌측 상단 계급 버튼을 누르면 팝업(`src/rank-guide.js`)으로 열립니다(상점에서 제거).
- **테스트**: 금액 표시(경계값·가격 올림/보유 내림 불변식 4,000건·캐시 분리), 모집 칸 구성, 계급 팝업. 사관학교 가격 테스트의 기대값은 새 표시(`30억`, `200억`)와 상세보기 위치에 맞게 바꿨습니다.
- **확인하지 못한 것**: Android 실기기, ⓘ 버튼의 실제 터치 편의.

## 0.30 장비 탭·훈장·홈 화면 개편

- **군대 모집 3열**(처음 4열에서 변경)로 글자와 버튼을 키웠고, **장비 구매는 한 줄에 하나씩**(그림 왼쪽, 능력·가격·버튼 오른쪽) 가로 카드로 바꿨습니다.
- **장비 탭**: 군사 장비는 그림·배치/보관·강화·추가 구매만 두고 능력·외형·강화 설명은 `능력 상세` 팝업으로, 개인 장비는 그림·이름·상태·버튼 2개만 두고 효과 설명은 `상세보기` 팝업(`personalDetailMarkup`)으로 옮겼습니다. 장비 탭 높이(대장·풀세트 기준) 개인 장비 2421→1024px, 군사 장비 1537→1058px.
- **훈장 칸**: 15개를 한 줄로 표시합니다. 전체 `숨기기/보이기`, 도전과제 창의 훈장마다 `홈에서 숨기기/홈에 다시 보이기`(홈 줄에서만 빠지고 도전과제 창에는 계속 표시, 홈 훈장 칸에 `숨김 N` 표시)가 있습니다(`src/medal-visibility.js`, 기기 설정 키 `budae-kiugi-ui-medals-hidden`, `budae-kiugi-ui-hidden-medals`).
- **리볼버**: 사용 중에는 장군검처럼 남은 1분이 시계 방향으로 줄어드는 링을 표시합니다.
- **홈 화면 공간**: 병사 현황 줄을 없애고(보유 수는 상점 칸에 표시), 연병장 위의 장군검·리볼버 버튼과 연병장 배경 선택을 연병장 아래 한 줄(높이 40px)로 옮겼습니다. 연병장이 약 57~61px 커졌습니다.
- **테스트**: 훈장 숨김 4개, 리볼버 링, 장비 칸·상세보기, 개인 장비 카드 압축. 설명 문구가 팝업으로 옮겨져 기존 테스트 3개와 홈 구조 테스트 2개는 확인 위치만 바꿨고 검사 내용은 같습니다.
- **확인하지 못한 것**: Android 실기기, 훈장 숨김 설정이 앱 재실행 후 유지되는지.

## 0.32 안드로이드 세로 고정·뒤로가기·게임 정보

- **세로 고정**: `AndroidManifest.xml`에 `screenOrientation="portrait"`를 지정했습니다(가로로 돌리면 연병장이 56px로 찌그러지던 문제).
- **뒤로가기 버튼**: `@capacitor/app`(8.1.1)과 `src/back-button.js`가 처리합니다. 열려 있는 팝업(진급 축하 → 상세보기 → 전투 → 도전과제 → 상점/장비 순으로 가장 위)을 해당 팝업의 닫기 버튼으로 닫고, 팝업이 없는 홈에서는 첫 번째에 "한 번 더 누르면 게임이 종료돼요"를 띄우며 2초 안의 두 번째에서 저장하고 종료합니다. 브라우저에서는 플러그인이 없으므로 등록하지 않습니다. 앱 빌드 전에는 `npm run android:sync`로 안드로이드 쪽에 반영합니다.
- **게임 정보 화면(출시 후 문제 재현)**: 홈 맨 아래 `정보 · v버전` 버튼을 누르면 버전·실행 환경·저장 상태·저장 형식과 **최근 오류 기록**(최대 30개, 같은 오류는 횟수로 묶음)이 나옵니다. `문의용 정보 복사`로 한 번에 복사할 수 있고(자동 복사가 안 되면 글을 길게 눌러 복사) 기록을 지울 수 있습니다. `reportError`와 처리되지 않은 오류가 모두 `src/error-log.js`로 이 기기의 `budae-kiugi-error-log`에 남으며 게임 저장 내용(골드·병력 등)은 포함하지 않고 어디로도 전송하지 않습니다.
- **버전 동기화**: 앱 버전은 `package.json` 한 곳에만 있습니다. 게임 안 정보 화면은 빌드 때 `vite.config.js`가 그 값을 넣고(`src/version.js`), 안드로이드 `android/app/build.gradle`은 같은 `package.json`을 읽어 `versionName`을 그대로, `versionCode`를 `major×1,000,000 + minor×1,000 + patch`(예: 0.32.0 → 32000)로 계산합니다. 이전에는 안드로이드 쪽이 0.19.1(versionCode 1)에서 갱신이 멈춰 정보 화면(0.28.0)과 달랐습니다. `tests/version-sync.test.js`가 이 연결과 이 문서의 현재 버전 섹션을 확인합니다.
- **터치 영역 겹침 수정**: 훈장 줄의 보이지 않는 터치 영역이 `도전과제 ›` 링크·`효과음` 버튼·연병장 맨 위 가장자리까지 번지던 문제를 고쳤습니다.

- 추가 구매는 화면과 게임 규칙 양쪽에서 잠겼습니다. 기존 형식2~17 기록은 형식18로 읽으면서 보유 장비를 종류별 1문으로 정리합니다. 미보유 종류는 지급하지 않고 강화·배치·골드·병력·쿨다운은 유지합니다. 이미 현재 한도보다 높게 강화한 장비도 보존하지만 다음 강화는 새 한도를 따릅니다.

## 0.45.0 마나 출격 가로 전장 (전투 시스템 교체)

사용자와 설문으로 정한 방향입니다: ① 팔라독·카툰워즈처럼 마나가 차면 장비를 출격 ② 장비 종류마다 비용·재출격 대기 ③ 그림은 나중에 더 고퀄리티로 바꿀 수 있게 에셋 교체 지점을 한 곳에 둠. 기존 "위에서 보는 본부 대 본부 + 필살기" 전투는 이 버전에서 완전히 대체했습니다(필살기 코드와 `src/battle-art.js`, `tests/battle-art.test.js`는 삭제).

### 어떻게 싸우나요
- 화면은 옆에서 본 가로 전장입니다. 왼쪽이 우리 기지, 오른쪽이 적 기지입니다.
- **마나**: 전투 시작 40, 초당 +8, 최대 100. 출전 장비 카드(중령 3칸, 준장·중장·대장 +1칸, 최대 6칸)를 누르면 마나를 내고 장비 1대(보유 수량 전체가 한 부대)가 출격합니다. 같은 장비는 재출격 대기가 있습니다(견인포 3.5초 ~ ICBM 22초).
- **장비 부대**는 적 기지 쪽으로 전진하다가 사거리 안에 가까운 적 부대가 보이면 멈춰서 자동으로 쏩니다. 적 부대가 없으면 기지를 공격합니다. 체력은 전력·수량·레벨에 비례합니다.
- **특수 장비**: 전술 수송기는 주변 아군을 주기마다 최대 체력의 12% 회복(공격 없음), ICBM은 전진하지 않고 마나로 적 기지에 즉시 일제 타격(1회 공격력 ×2)입니다.
- **적**은 지역 유형(기갑 부대 → 포병 진지 → 항공 부대 순환)에 맞는 장비를 일정 간격으로 계속 출격시키고, 양쪽 기지에는 가까이 온 부대를 쏘는 포탑이 있습니다.
- **상성**: 공중 > 기갑 > 화력 > 공중. 유리하면 피해 ×1.3, 불리하면 ×0.8(나라가 뒤로 갈수록 ×1.4/0.7, ×1.5/0.65, ×1.6/0.6). 이제 적 부대가 실제로 그 분류로 나오므로 상성이 눈에 보입니다. 출전 준비 화면에서 이 지역의 유리한 분류와 장비별 마나·재출격·효과를 확인합니다.
- **수도 요새**: 기지가 더 단단하고 포탑이 강하며, 그 지역의 정석(counter) 분류 장비가 기지에 주는 피해가 40% 줄어듭니다(부대는 정석으로 잡고 기지는 다른 분류로 부수는 전략). 요새 그림은 나라별로 다릅니다.
- 별 평가는 승리 1개, 75초 이내 또는 우리 기지 체력 50% 이상 2개, 둘 다 3개입니다(전리품 ×1/×1.25/×1.5). 3분 안에 끝내지 못하면 무승부입니다.

### 코드 읽는 법

- 자동 테스트479개 통과, 빌드·음원 검사·Android 동기화 성공. 자세한 결과는 검증결과.md. 실제 폰 조작과 화면 픽셀 검수, APK/AAB 재생성은 미확인.

## 0.57.1 한 부대로 모이는 연병장

- 0.57.0의 장비/시설별 가로 페이지와 이동 버튼을 제거. 큰 본부를 왼쪽 위에 두고 학교·장비·시설을 같은 연병장의 빈자리에 함께 배치합니다.
- 화면 높이와 이름표 공간을 사용해 한 화면부터 채웁니다. 모두 들어가지 않을 때만 최소16px 단위로 가로 폭을 늘립니다. 폭이 남으면 확장하지 않습니다.
- 시설/장비의 보유량·수입·강화·저장 형식25는 유지. 스와이프/드래그와 키보드 좌우 이동, 터치 오인식 방지 유지.
- 전체 테스트480개·빌드·음원 검사·Android 동기화 통과. 검증: 작은 부대 한 화면, 대규모 부대 혼합 배치, 폭288~480px/높이180~660px에서 그림+이름표 충돌 검사. 브라우저 실제 보유 부대에서 폭319px/연병장496px와 페이지 버튼0개를 확인했습니다. 실제 Android 폰 조작은 미검증.

## 0.57.2 종류별 단으로 정돈한 연병장

- 위부터 부대→학교→시설→장비 순서. 큰 본부를 강조하고 지원 건물/장비는 종류별로 한곳에 모아 가로 최대3줄로 배치합니다.
- 수량이 늘면 종류별 그림 크기를 줄이고, 높이와 이름표를 고려한 뒤 필요한 만큼16px 단위 가로 확장. 구역별 페이지나 이동 버튼은 없습니다.
- 매우 낮은 화면에서는 이름표/본부를 뭉개지 않도록 같은 연병장에 세로 스크롤을 허용합니다. 일반 화면에서는 가로로 이어집니다.
- 테스트482개·빌드·음원 검사·Android 동기화 통과. 현재 브라우저에서 큰 본부, 학교1줄, 시설2줄, 장비2줄을 확인. 저장·수입·진급 연출 규칙은 그대로입니다. 실제 폰의 터치 체감은 미확인.
