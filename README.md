# 부대 키우기

동람코의 Android 부대 성장·점령 게임입니다. 터치와 부대 수입으로 병력을 모집하고, 시설·장비를 강화하며 전투 지역을 점령합니다. 현재 버전은 `package.json`이 기준입니다.

## 실행과 검증

```sh
npm ci
npm run dev
npm test
npm run build
npm run audio:verify
npm run android:release
```

- 웹 주소: http://127.0.0.1:4173/ · Android ID: `com.dongramco.budaekiugi`.
- Android 빌드 환경·서명은 `tools/android-build.ps1`이 확인합니다. 기존 서명 키와 승인된 음악·로고 원본은 비공개 로컬 파일이며 Git에 없습니다.
- 음원 복원은 [음악 안내](docs/MUSIC_SETUP.md), 출시는 [첫 업로드](docs/store/FIRST_UPLOAD.md)를 참고하세요.
- 효과음은 `src/audio-synth.js`로 합성합니다. 배경음악은 승인된 Suno 4곡을 사용합니다.

## 현재 동작과 유지할 규칙

- 저장 키 `budae-kiugi-recruits-v3`, 저장 형식35. 이전 저장 이전 처리를 유지합니다. 실제 사용자 기록으로 테스트하지 않습니다.
- 골드 상한 1,000해: 큰 금액은 `money.js`와 `serializeSave`로 처리합니다.
- 개인 장비 Lv.30 확정 강화, 군사 장비 최대40강. 수치·가격·해금 조건은 각 `src` 공통 정의가 기준입니다.
- 1시간 이상 자리 비움 수입은 최대8시간 정산. 일반 받기 또는 광고 완료 후2배 받기, 동일 보상은 한 번만 지급합니다.
- 광고는 Android에서 별도 선택 동의 후 요청합니다. 현재 release/debug 모두 Google 샘플 광고 ID. 미성년자 보호 설정을 유지합니다. 광고 공급·승인은 AdMob 상태에 달려 있습니다.
- 실제 유료결제는 아직 없습니다. 기존 무료 자동터치 보유는 유지하며 신규 운영 무료 지급은 종료했습니다.
- 설정에서 소리, 게임 정보, 개인정보처리방침 및 오픈소스 라이선스를 확인합니다.

## 0.76.7 자동터치 상품 소개 개선

- 사용자 설문에 따라 새 상품/부스터팩은 추가하지 않는다. 기존 스타터팩 구성과 가격을 유지하고 자동터치 소개를 개선했다.
- 자동터치는 편의 기능·초당5회·영구 보유·손가락 병용·홈 전용 조건을 명확하게 표시한다. 상점과 홈 독립 팝업은 같은 소개를 재사용한다.
- 커서/빛/파동은 CSS의 transform·opacity만 사용하고 실제 입력이나 골드를 발생시키지 않는다. 닫힌 창에서는 정지하며 기기 모션 줄이기 설정에서는 정지 그림이다.
- 직접 확인함: 코드/정책 자료 읽기 → 새 상품 추가 취소 설문 반영 → 소개/효과 변경 → 전체 검사 → 좁은 화면의 버튼 위치 개선 → 집중 재검사/빌드 순서로 진행했다. 오류·실패한 자동 검사는 없었다.
- 직접 확인함: npm test 764/764 통과. 이후 미보유 토글 숨김/중복 설명 정리를 반영한 관련13개 재검사 통과, 최종 npm run build 성공. 기존 라이선스 고지 청크 크기 경고는 유지한다.
- 직접 확인함:320×720/412×915에서 페이지와 창의 가로 넘침 없음. 412px에서는 가격/구매 버튼까지 한 화면에 표시된다. 320px에서는 구매 버튼까지 조금 스크롤해야 한다. 소개 그림을 줄이고 작동 예시와×5 간격을 보정했다. 보유 전 켜기/끄기 숨김, 보유 후 표시, 취소 무지급, 무료 확인 지급, 닫힌 상점의 animation-play-state=paused를 별도4207 시험 기록에서 확인했다.
- 직접 확인함: 상품은 기존 자동터치/스타터팩2종뿐이다. 효과는 opacity(투명도)와 transform(그림 이동/크기)만 바꾸고 입력·골드 거래를 호출하지 않는다. 모션 줄이기 CSS 규칙은 코드로 확인했으며 실제 기기 설정 검사는 미확인이다.
- 미리보기 재시작 중4208의 임시 모듈 불러오기 실패가1회 발생해 새로고침으로 다시 연결했다. 실제 게임/대령 기록을 시험용 지급 데이터로 덮어쓰지 않았다. 4207 시험 서버는 정리하고4196/4208만 유지한다.
- Google Play 결제 정책의 정확한 가격·조건 안내를 공식 문서로 확인했다: https://support.google.com/googleplay/android-developer/answer/9858738?hl=en . 허위 할인·마감·인기 수치는 넣지 않는다. 실제 결제/복원/출시 신규 지급은 기존 미연결·차단 상태다.
- 은행 비유: 기존 상품의 안내판과 진열을 고쳤으며 상품 가격이나 예금 장부(저장39)는 바꾸지 않는다. 서버·SDK·정책 원문/번호 변경 없음.

## 0.76.8 스타터팩 순서와 공통 창 높이

- 스타터팩을 상점 첫 상품으로 복원했다. 기존 구성/가격/지급 조건은 유지한다.

- 전문 용어: CSS는 화면 크기와 배치를 정하는 규칙이다. 은행 비유로 안내 책자가 길어져도 창구 크기는 유지하고 책장만 넘기도록 바꾼 것이다.
- 직접 확인함: npm test 764/764 통과, npm run build 통과. 웹518×1724에서 개인장비와 상점은 모두883.19px, 홈960px 안에 맞고 내용은 내부 스크롤한다. 320×640에서는 메뉴588.80px, 문서 너비320px로 확인했다. 상점 첫 상품도 스타터팩이다. 기존 큰 묶음 빌드 경고와 로컬 음악 누락 오류는 별도 잔존한다.

## 0.76.9 맥스 부스터와 부대 표시

- 맥스 부스터: 10분간 터치10배/초당20배, 다른 효과와 곱연산, 같은 종류는 시간만 연장. 광고 획득 불가. 스타터팩5,900원에 기존30개씩+맥스10개, 기존 수령 기록에도 저장39→40 이전 때 한 번 보충한다.
- 장군검 재사용60분, 홈6칸 축소, 큰 부대3종과 수량 표시. 은하 건물 색상 기운/은하단 검은 기운은 CSS로 표현해 매 프레임 캔버스 재그리기를 피한다.
- 직접 확인함: 관련 기존67개+새7개, 후속28개/17개/13개 검사와 빌드 통과. 첫 전체 검사에서 예전 장군검 시간 기준3건과 글자 최소10px 규칙1건이 실패해 기대 시간·글자/짧은 이름을 수정했다. 수정 후 npm test 771/771 통과(실패0), npm run build 성공. 마지막 웹 확인에서6개 사용 칸의 가로/세로 콘텐츠 넘침도0이었다. 실제 폰·실제 결제는 미확인이다. 기존826KB 묶음 빌드 경고는 남아 있다.
- 전문 용어: 저장 이전은 예전 기록을 새 항목에 맞춰 읽는 과정이다. 은행 비유로 기존 통장은 유지하고 새 혜택10개를 한 번 기록한다. 기존 저장키는 유지, 형식40으로 변경한다.
- 실수: 로컬 수정 도구가 텍스트 인코딩으로 중단되어 UTF-8을 명시하고 남은 변경만 재개했다. 변경된 사양에 맞춰 기존 검사도 갱신했다.
